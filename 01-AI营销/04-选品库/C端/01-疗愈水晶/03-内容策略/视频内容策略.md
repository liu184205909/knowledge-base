# 水晶项目视频内容策略

> **定位**：水晶品类在 Reels / TikTok / Shorts / Pinterest 等视觉平台的视频内容规划
> **适用场景**：决定做哪种视频、用什么工具、分发到哪个平台时查阅
> **边界与衔接**：不讲博客图文内容（→ [内容策略.md](./内容策略.md)）、不讲 SEO 文字优化（→ [SEO与GEO](../../../03-SEO与GEO/) 目录）

## 一、为什么水晶品类需要视频

| 维度 | 数据 / 证据 |
|---|---|
| **品类视觉性** | 水晶 = 高视觉密度产品（光泽、纹理、颜色），视频比单图更能传达"质感" |
| **目标人群活跃渠道** | 灵修 / 疗愈 / 玄学人群高度活跃在 Instagram、TikTok、Pinterest |
| **算法偏好** | IG Reels reach 是单图的 3-10x；TikTok 100% 视频分发 |
| **SEO 间接回报** | 社媒曝光 → 品牌搜索量上升 → Google 信任信号（详见 [17-新站信任建立期](../../../03-SEO与GEO/17-新站信任建立期与算法机制.md)） |

## 二、三个核心用例（按 ROI 排序）

### 用例 1：水晶功效知识卡片——信息图 → 视频双形态 ⭐ 主用例

**核心认知**：信息图和视频不是二选一，是**同一内容的两个分发渠道**。

| 形态 | 工具 | 主战场 | 优势 |
|------|------|--------|------|
| **信息图**（先做） | Canva / Figma 模板批量 | 博客内嵌 / 邮件 / Pinterest 静态分发 | 加载快、内容密度高、易分享 |
| **视频版**（后做） | HyperFrames HTML 模板 | **Pinterest 视频** / IG Reels / TikTok / YouTube Shorts | 触达所有视频优先渠道的算法推荐池 |

**Pinterest 也要做视频（关键数据修正）**：
- Video Pins 比图片多 **40% 网站流量**、**2x 收藏数**（[Searchlab 2026](https://searchlab.nl/en/statistics/pinterest-statistics-2026)）
- 2025 年 Pinterest 视频内容增长 **150%**
- 2026 算法 **actively prioritizes motion-based content**（[B2W TV](https://www.b2w.tv/blog/pinterest-video-strategy)）
- 推荐内容配比：**60-70% 竖屏视频 + 30-40% 静态图**（[Digital Applied](https://www.digitalapplied.com/blog/pinterest-statistics-2026-marketing-data-points)）
- 用户留存：视频 **95%** vs 文字 **10%**（[Sprout Social](https://sproutsocial.com/insights/pinterest-algorithm/)）

**信息图 vs 视频的真正分工**：
- 信息图：博客内嵌、邮件营销——加载快、内容密度高
- 视频：**Pinterest + IG + TikTok + YouTube Shorts**——所有视觉平台都已转向视频优先
- 信息图是**基础内容**，视频是**全渠道分发扩张**——不止是 Reels，Pinterest 也是

**生产流程**：
```
40 种水晶 × 5 个功效维度 = 200 个知识单元
  ↓
Step 1：Canva 信息图模板（一批 200 张）
  ↓ 博客 / 邮件 / Pinterest 静态版分发
Step 2：HyperFrames HTML 模板（套同一份内容数据）
  ↓ Pinterest 视频 + IG Reels / TikTok / Shorts 分发
```

**模板设计要素**：
- 石头图（高清，纯色背景）
- 名字（英文 + 中文）
- 1-3 个功效关键词
- 脉轮 / 元素 / 星座图标
- 末尾 CTA：`→ goearthward.com/[stone]-meaning`

### 用例 2：博客内嵌步骤视频（SEO 信号增强）

**核心认知**：Google 偏好含视频的页面——视频 carousel 命中 + 停留时间提升 = NavBoost goodClicks 信号。

**适用文章类型**：
- "How to cleanse amethyst"（如何净化）
- "How to program crystals"（如何充能）
- "How to make a crystal grid"（如何摆阵）
- 任何 3-7 步骤的教学型内容

**视频规格**：
- 时长：8-12 秒
- 形式：步骤动画（不用真人，HyperFrames 用 GSAP 做 UI 动效）
- 嵌入位置：文章 H2 下方，替代或补充图文步骤

**现状对照**：
- tiger-eye-and-citrine 页面平均停留 18 秒——危险信号
- 内嵌视频直接提升停留时间，是 NavBoost goodClicks 的修复手段

**与 SEO 知识库的衔接**：
- 视频提升停留时间 → NavBoost goodClicks → 排名提升
- Google 视频 carousel 命中 → SERP 占位更多 → CTR 提升机会
- 详见 [17-新站信任建立期](../../../03-SEO与GEO/17-新站信任建立期与算法机制.md) NavBoost 机制

### 用例 3：精选主打 SKU 的佩戴 / 能量效果视频

**核心认知**：不是 500 SKU 全覆盖，是精选 10-20 款主打产品做**差异化**视频。

**为什么不全覆盖**：
- 大部分水晶长得像（透明石头），500 条同质化视频用户分不清
- Etsy / Amazon 主流 PDP 都没用视频，靠大图轮播就够
- 维护成本高（产品下架、价格变动要更新视频）

**精选 10-20 款的标准**：
- 高 margin 产品（值得投入）
- 视觉差异大的品类（原矿 vs 球体 vs 手链 vs 摆件）
- 已有销售数据的畅销款
- 适合做"佩戴效果"或"能量场可视化"的款

**视频形式**：
- 佩戴效果（手链 / 项链上身的视觉）
- 能量场可视化（用 HyperFrames 做光晕 / 脉轮色动画，非实景）
- 30 度旋转展示（如果有多角度产品图）

**分发**：社媒为主，**不嵌产品页**——PDP 转化靠大图轮播，不需要视频

## 三、工具选择

| 场景 | 推荐工具 | 理由 |
|------|---------|------|
| **功效卡片视频版批量** | HyperFrames | 确定性 + HTML 模板批量 + Claude Code 集成 |
| **功效卡片信息图版** | Canva / Figma | 模板化批量、Pinterest 主战场 |
| **博客步骤动画** | HyperFrames | UI 动效精致，可与文章设计系统对齐 |
| **主打 SKU 佩戴视频** | 手机实拍 + CapCut 剪辑 | 佩戴效果必须真实，HyperFrames 做不了实景 |
| **能量场可视化** | HyperFrames | GSAP + 渐变 + 粒子，非实景 |

**核心原则**：
- 信息图用 Canva，视频版用 HyperFrames——**同一份数据源**驱动两个工具
- 实景内容（佩戴、开箱）用手机拍，**不要硬用 HyperFrames**
- HyperFrames 只做"HTML 能渲染的"内容（图文动效、数据可视化、UI 动画）

## 四、分发矩阵

| 平台 | 规格 | 内容形态 | 发布频率 | 主要 KPI |
|------|------|---------|---------|---------|
| **Instagram Reels** | 9:16 | 功效卡片视频版 | 3-5 条/周 | Reach + Profile Visits |
| **TikTok** | 9:16 | 功效卡片视频版 + 主打 SKU | 3-5 条/周 | Views + Link Clicks |
| **YouTube Shorts** | 9:16 | 功效卡片视频版 | 2-3 条/周 | Subscribers + Watch Time |
| **YouTube 普通** | **16:9 横屏** | 长视频（5-15 分钟）| 不用 HyperFrames，用 MoneyPrinterTurbo 或真人录制 | Watch Time + Revenue |
| **Pinterest** | 9:16（视频优先 60-70%）| 功效卡片视频版 + 信息图 | 5-10 条/周（视频为主） | Saves + Outbound Clicks |
| **博客** | 16:9 / 响应式 | 步骤动画内嵌 | 按文章节奏 | 停留时间 + NavBoost |

**关键**：Pinterest 2026 算法已转向视频优先——Video Pins 比图片多 40% 网站流量、2x 收藏数。推荐配比 60-70% 竖屏视频 + 30-40% 静态图。

## 四-A、跨平台素材策略：多版本而非一份发所有

### 一个素材发所有平台的 4 个陷阱

| # | 陷阱 | 严重性 | 解法 |
|---|------|--------|------|
| **1** | **水印降权**——TikTok 水印在 IG 被降权，反之亦然 | 高 | 用 HyperFrames 渲染的**原始 MP4 直接上传**，不从平台下载搬运 |
| **2** | **安全区不同**——每个平台 UI 遮挡区域不同（TikTok 底部 20% + 右侧 15%；IG 底部 caption；Shorts 底部标题；Pinterest 底部 Pin 描述） | 中 | CTA / 文字放在**中心 60% 安全区**，每个平台生成单独版本调整边距 |
| **3** | **重复内容检测**——TikTok / IG 有原创检测，同视频先在某个平台发过可能被识别为"搬运" | 中 | 自己原创无水印版本影响较小，但建议**错峰发布**（不要同一分钟 4 个平台一起发） |
| **4** | **内容风格差异**——TikTok 粗粝真实、IG 精致设计、Shorts 信息密度、Pinterest 唯美可保存 | 低（水晶品类影响小） | 水晶品类的视觉美感是跨平台通用的——这是品类优势 |

### HyperFrames 的正确用法：一个模板 → 多个平台版本

```
同一份水晶功效数据（如 Amethyst + 平静 + 第七脉轮）
  ↓
HyperFrames HTML 模板（带平台变量）
  ↓
按平台生成 4 个版本：
  ├─ TikTok 版（9:16，CTA 在中心安全区，TikTok 风格 caption）
  ├─ IG Reels 版（9:16，CTA 在中心，IG 风格 caption）
  ├─ YouTube Shorts 版（9:16，CTA 在中心，频道水印）
  └─ Pinterest 版（9:16，文字密度更高，末尾 Pin 描述预览）
```

**为什么 HyperFrames 适合做这件事**：
- **确定性**——同一模板渲染 4 个版本，每次输出一致
- **变量化**——HTML 模板用 `data-*` 属性传参，改 caption / CTA / 安全区边距只需改参数
- **批量**——200 个知识单元 × 4 个平台 = 800 个视频，一套脚本跑完

### 各平台规格速查

| 平台 | 推荐规格 | 时长 | 文件格式 | 最大体积 |
|------|---------|------|---------|---------|
| TikTok | 9:16 (1080×1920) | 15-60s | MP4 / MOV | 500MB |
| IG Reels | 9:16 (1080×1920) | 15-90s | MP4 / MOV | 650MB |
| YouTube Shorts | 9:16 (1080×1920) | ≤60s | MP4 / MOV / AVI | 256MB |
| Pinterest | 9:16 (1080×1920) 或 2:3 (1000×1500) | 15-60s | MP4 / MOV | 2GB（但 <100MB 更好） |

**HyperFrames 渲染规格建议**：统一用 1080×1920 / 30fps / H.264，所有平台通用。

### 不用 HyperFrames 的视频场景

| 场景 | 工具 | 理由 |
|------|------|------|
| YouTube 普通长视频（16:9） | MoneyPrinterTurbo / 真人录制 | HyperFrames 不做横屏长片 |
| 实景拍摄（佩戴 / 开箱 / 展会） | 手机 + CapCut / Premiere | HyperFrames 不做实景 |
| 需要真人出镜的教学 | 录制 | HyperFrames 只做 HTML 动画 |

## 五、生产 SOP

```
Step 1：内容选题
  → 从 [内容选题池.md](./内容选题池.md) 拉取水晶 × 功效矩阵
  → 优先级：40 种核心水晶 × 5 大功效 = 200 个单元

Step 2：信息图生产（先做）
  → Canva 模板批量产出 200 张
  → 分发 Pinterest / 博客 / 邮件

Step 3：视频版生产（后做）
  → HyperFrames HTML 模板（套用 Step 2 同一份数据）
  → Claude Code 装 HyperFrames 技能包：npx skills add heygen-com/hyperframes --full-depth
  → 自然语言指令产出 MP4

Step 4：分发
  → Reels / TikTok / Shorts 同步发布（可使用社媒分发工具）
  → 末尾统一 CTA → goearthward.com/[stone]-meaning

Step 5：效果追踪
  → 监控品牌搜索量（Google Trends）——上升 = 视频起作用
  → 监控 GSC 品牌词 CTR
  → 监控博客停留时间（嵌入视频的页面 vs 未嵌入的对照）
```
