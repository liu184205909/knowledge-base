# 物种维度扩展与 pSEO 矩阵修正

> **研究目的**：验证"犬种 × 病症 × 设备"pSEO 矩阵假设；评估猫、其他宠物（rabbit/bird/reptile/exotic）的可行性
> **数据源**：DataForSEO Labs `keyword_suggestions/live`，87 个种子词，2026-07-29
> **样本规模**：378 个唯一关键词（去重后）
> **关键性质**：本报告**推翻了之前的 pSEO 矩阵假设**，必须用本结论替换 `01-宠物理疗完整词云与pSEO矩阵设计.md` 第 5 节"犬种维度 pSEO"

---

## 1. 核心结论（推翻性发现）

### 1.1 犬种维度搜索需求完全不存在 ❌

**事实**：所有 11 个高发犬种 × IVDD/arthritis/hip dysplasia 种子词在 DataForSEO Labs 中**全部返回 0 结果**：
- `red light therapy for dachshund` = 0
- `ivdd in dachshund treatment` = 0
- `red light for french bulldog` = 0
- `red light therapy for german shepherd` = 0
- `hip dysplasia in german shepherd treatment` = 0
- `red light for golden retriever arthritis` = 0
- `red light for labrador hip dysplasia` = 0
- `red light therapy for pitbull` = 0
- `red light therapy for poodle` = 0
- `red light therapy for husky` = 0
- `red light therapy for corgi` = 0

**含义**：美国用户在 Google 上**不会按犬种搜索光疗设备**。他们搜的是 `red light therapy for dogs arthritis`（通用 + 症状），而不是 `red light therapy for dachshund with IVDD`。

**决策**：**不要做"by dog breed"页面**。原计划中 200+ 个犬种页面会被取消，避免内容产能浪费。

### 1.2 只有 3 个物种有商业级搜索需求 ✅

| 物种 | 唯一词数 | 聚合 SV | 商业意图 | 决策 |
|---|---:|---:|---|---|
| **Dog** | 279 | **46,130** | 高 | ✅ 必做 |
| **Horse**（已有数据） | 61 | 4,010 | 高 | ✅ 必做 |
| **Cat** | 65 | 2,870 | 中 | ✅ 必做（但策略不同） |
| Pet（generic） | 17 | 980 | 中 | ✅ 做（夹页/导航） |
| Reptile | 15 | 350 | 极低 | ❌ 赛道错位 |
| Bird | 1 | 20 | 无 | ❌ 放弃 |
| Rabbit | 1 | 0 | 无 | ❌ 放弃 |
| Small mammal | 0 | 0 | 无 | ❌ 放弃 |
| Exotic | 0 | 0 | 无 | ❌ 放弃 |

**结论**：99.7% 的搜索需求集中在 Dog + Cat + Horse 三个物种。**其他物种全部放弃**。

## 2. 各物种的战略差异（重要）

### 2.1 Dog：通用 + 症状 双驱动

**Top 25 关键词特征**：
- `red light therapy for dogs` SV **8,100**（绝对主词）
- `therapy laser for dogs` / `laser therapy for dogs` SV 3,600
- `cold laser therapy for dogs` SV 1,900
- `pemf therapy for dogs` SV 1,600
- `red light therapy for dogs arthritis` SV 1,300

**设备偏好**：
- Red Light / Laser: 85+110 词
- PEMF: 40 词（**占狗市场 16.8%**，PEMF 是狗的主设备）
- Cold Laser: 45 词

**症状分布**：Arthritis > IVDD > Hip Dysplasia > Post-surgery

### 2.2 Cat：Safety 主导，PEMF 缺席

**Top 关键词特征**：
- `red light therapy for cats` SV 720
- `red light for cats` SV 390
- `cold laser for cats` SV 260
- `is red light therapy good for cats` SV 90（信息型）
- `is red light bad for cats` SV 70（信息型）

**与 Dog 的三个根本差异**：

| 维度 | Dog | Cat |
|---|---|---|
| Safety 顾虑查询占比 | <2% | **10%+**（6 个 is-safe 类词） |
| PEMF 词数占比 | 16.8% | **1.0%**（仅 30 SV） |
| 症状驱动查询 | 多（arthritis/IVDD/hip） | 几乎没有（仅 kidney disease SV=20） |

**猫页面必须做的事**：
1. **第一屏回答安全性**（眼睛、皮肤、甲状腺、加热应激）—— 这是猫主的第一关切
2. **不要做"by symptom"页面** —— 猫主搜的是"red light for cats"，不是"red light for cats with arthritis"
3. **不要给猫做 PEMF 页** —— PEMF 在猫市场几乎不存在

### 2.3 Horse：形态维度独家

**已有数据**：61 词 / 4,010 SV
- `red light therapy for horses` SV **2,400**
- `red light therapy boots for horses` SV 90
- `red light therapy hock boots for horses` CPC $7.09

**Horse 独特点**：有专属形态词（boots / hock boots / leg / blanket），Dog/Cat 几乎没有。
**策略**：用形态 × 症状矩阵，而不是单纯的物种 × 设备矩阵。

### 2.4 Reptile 是错位赛道（关键澄清）

**数据**：bearded dragon 12 词、SV 350
**问题**：全部是"饲养灯"意图，不是"治疗设备"：
- `red light bulb for bearded dragon`
- `red basking light for bearded dragon`
- `red night light for bearded dragon`
- `red light for bearded dragon at night`

**竞品是 Zoo Med / Exo Terra（爬宠饲养品牌），不是宠物理疗设备品牌**

**决策**：**Reptile 完全放弃**。强行做会损害 E-E-A-T（用户想要 $9.9 灯泡，不是 $199 治疗设备，Google 会判定意图错配）。

## 4. 八个关键战略洞察

### 洞察 1：犬种维度被证伪（Critical）
原"30 犬种 × 5 症状 × 3 疗法 = 450 页"假设**完全错误**。美国用户不按犬种搜索光疗设备。**取消所有犬种 pSEO 规划**。

### 洞察 2：真实市场只有 3 物种（Critical）
Dog + Cat + Horse = 53,000 SV（占 99.7%）。Rabbit / Bird / Small mammal / Exotic 全部放弃。

### 洞察 3：猫市场 Safety 主导（High）
Cat Top 25 中 6 个 "is red light safe/good/bad for cats" 类查询（占 10%+）。**猫页面第一屏必须回答安全性**，否则跳出率极高。

### 洞察 4：PEMF 是狗专属设备（High）
狗市场 PEMF = 16.8%（7,760 SV），猫市场仅 1%（30 SV）。**PEMF 设备页只做 dog + horse**，不要给猫做。

### 洞察 5：`red light therapy for dogs` 是绝对主词（Critical）
SV 8,100 = 整个 Cat 市场的 2.8 倍。**狗红光主页面必须是全站投入最高的页**（内容深度、外链、内链全部优先）。

### 洞察 6：`luma pet red light therapy` 是品牌词线索（Medium）
SV 390，Luma 是赛道头部品牌之一。**做一篇 "Luma Pet vs [我们]" 对比页**吃品牌流量。

### 洞察 7：Cat 症状维度几乎不成立（High）
65 个猫词中仅 1 个明确症状词（`red light therapy for cats with kidney disease` SV=20）。**猫市场不做"by symptom"页面**，只做主指南 + 设备细分。

### 洞察 8：Reptile 是错位赛道（Medium）
Bearded dragon 关键词全是"饲养灯具"意图（bulb / basking / night light），竞品是 Zoo Med / Exo Terra。**强行做会损害 E-E-A-T**，完全放弃。
