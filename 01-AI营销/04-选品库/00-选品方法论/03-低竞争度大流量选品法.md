# 03-低竞争度大流量选品法

> **两个核心问题**：①如何**找到**低竞争大流量的词/品类？②如何**选择**（判据体系）？
>
> **来源**：外部方法源（Ahrefs / Semrush / Backlinko 官方方法文 + Seer Interactive / GSQi 行业数据，2026-09 调研）× 本库 2026-09 产品雷达 7 组实战判例（雷达分组档案已删除，**判例数据全部内嵌本文正文**，死因总档见 memory `product-radar-2026-09`）交叉提炼。
> **定位**：与 [00-词根调研法](./00-词根调研法.md)（词根=发现维度）、[02-关键词挖掘实操手册](./02-关键词挖掘实操手册.md)（工具操作）互补——本文回答"筛什么、怎么判"，不重复挖掘操作细节。
>
> **最后更新**：2026-09-15（新增路径六 Event SEO + 判据四外链生态证据法，来源：remove.bg 关站案例）

## 1. 定义与反直觉认知

**低竞争大流量 = 「可获得排名的词/品类」×「可布局的流量面」**。两个乘数各有一个主流误读，加上 2026 年的第三个，共三个反直觉认知：

### 1.1 低竞争 ≠ KD/SD 数字低（KD 是外链难度，不是商业难度）

**明文**：Ahrefs 官方定义 KD 仅基于"当前 top10 排名页面的外链画像"（[Ahrefs Keyword Difficulty](https://ahrefs.com/keyword-difficulty)）；Semrush KD% 是 0-100 百分比口径（[Semrush 官方](https://www.semrush.com/blog/keyword-difficulty/)）。**两者都不测量信任门槛、品牌垄断、SERP 特征切割。**

低 KD 陷阱三型（全部有本库实证）：

| 陷阱类型 | 机制 | 本库实证 |
|---|---|---|
| **信任型/YMYL 垄断** | 权威站外链少但信任度高，KD 显得低，实际进不去 | `kinase inhibitor` 位4-6 全是 Wikipedia/cancer.gov/NCBI，商业独立站仅位8（02-B端仪器组） |
| **品牌/导航词** | 词量归属品牌方，KD 低因品牌页外链少 | `hasbro action figures` SD17/PD2=官方垄断广告位；`game download` 池 80% 是品牌导航词；class ring 词池品牌词吞掉大半（jostens 18,100）（04 兴趣周边组/06 下载站组） |
| **低端不准** | 社区共识：KD 工具在量表低端最不准确 | Reddit r/SEO 讨论级证据 + 行业专家批判（[Omniscient Digital: The Case Against Keyword Difficulty](https://beomniscient.com/blog/case-against-keyword-difficulty/)：任何基于 KD 的优先级模型都有缺陷） |

### 1.2 大流量 ≠ 主词搜索量（词池深度才是可布局面）

**来自 [00-词根调研法](./00-词根调研法.md) §7.3（2026-09 选品收敛实战提炼）**：主词量大 ≠ 可布局词多，**词池深度（suggestionCount）直接换算页面数上限**。

- 情趣内衣：主词 135K，但意图过滤后可用池仅 ~1,500 = 30-50 页的生意
- 车载滤芯：主词量小一档，但池 25,037 = 千页级矩阵
- wallpaper：大词 1,220,000/月，但 784,891 池的 top 词几乎全是数字壁纸（cute/iphone/4k）——**大词池对家居选品无意义**，剥离后家居词族独立池 9,306 才是真实可布局面（03-家居组）

**推断**（基于上述判例归纳）：主词量决定"话题存在感"，词池深度决定"能建多少页、吃多少长尾总量"。选品口径一律以**剔污染后的词池深度**为准。

### 1.3 找到 ≠ 值得做：2026 年定义升级为"竞争 + AI 答案替代"双重可进

**行业数据（明文）**：
- 99.2% 触发 AI Overview 的词是 informational 意图（[iPullRank](https://ipullrank.com/everything-we-know-about-ai-overviews)）
- AIO 词 organic CTR 从 1.76% 跌至 0.61%（-61%，Seer Interactive 2025-09 研究；2026 年更新显示 CTR 已从底部反弹约 85%，侵蚀趋稳但未回原位——[Seer 2026 Update](https://www.seerinteractive.com/insights/aio-impact-on-google-ctr-2026-update)）
- Ahrefs：AIO 触发词流量潜力约低 8 倍

**本库判例（07-祝福语内容词族）**：birthday wishes 主词 246K/SD21、池 64,537、DA8 小站排位2、新站 5 个月 48K 流量——**2024 年标准下的完美"低竞争大流量"标的，2026 年砍**。栽在：4/4 抽词 SERP 全部 AIO 占位1（查询意图=短文本=AI 完美答案形态）。

> **结论**：2026 年的"低竞争"定义 = **SERP 可进 × AI 答案不可替代**。第一个乘数看错会浪费时间，第二个乘数看错会做出"排名上去但没点击"的站。

## 2. 如何找到——六条发现路径

六条路径解决"词从哪来"。每条含操作步骤、工具、案例、陷阱。来源分级：路径 1/3/5 的机制定义为官方文档级，路径 4 机制为行业专家分析（Glenn Gabe/GSQi），路径 2 为本库实战提炼，路径 6 为行业案例分析（remove.bg 关站）。

### 2.1 路径一：KD/SD 过滤法（工具内建路径）

**操作步骤**：
1. 种子词拉池（match_keywords / Keywords Explorer Matching Terms）
2. KD/SD ≤ 30 过滤（[Semrush 官方推荐阈值](https://www.semrush.com/blog/how-to-find-low-competition-keywords-with-semrush/)；社区实践更严：KD<10-15）
3. 按量 / Traffic Potential 降序排（Ahrefs 官方筛选公式：`KD ≤ 30 + Lowest DR filter + 按 Traffic Potential 排序`，[Ahrefs: Low-Competition Keywords](https://ahrefs.com/blog/low-competition-keywords/)）
4. **必须 SERP 人工复核**（Ahrefs 官方同样要求——KD 不含信任/品牌/SERP 特征维度，见 §1.1 三陷阱）

**本库实证案例**（Ubersuggest SD 口径，US 2840）：

| 词 | 量/月 | SD | 来源组 |
|---|---|---|---|
| rotary evaporator for sale | 260 | 11 | 02-B端仪器组 |
| zodiac 配对词（libra taurus 等 12×12） | 8,100-18,100 | 9-12 | 05-流量词工具内容组 |
| sudoku/tetris/bubble shooter 品类词 | 5,400-14,800 | 7-11 | 06-下载站组 |
| floral peel and stick wallpaper | 2,400 | 20 | 03-家居组 |

**陷阱标注**：本路径只做**粗筛**。低 SD 词过手后第一件事是查它是三类陷阱（§1.1）还是真缝隙——`hasbro action figures`（SD17）就是过滤器的反例。

### 2.2 路径二：词池长尾解剖（本库主力路径）

**操作步骤**：
1. 双种子拉池（同义主词各一次 match_keywords，池相加）
2. **词池剥离**：剔除品牌词/导航词/跨语义污染词（wallpaper→数字壁纸剥离；stockings 26,931 池过半是医疗袜/时装需求，情趣意图过滤后再算池——§7.3 实战纪律）
3. 看 suggestionCount 总深 + SD 分层分布（低 SD 带是否连续）
4. 换算页面数上限，对照目标站规模
5. **组合词逐个实测**：场景×品类组合词不能矩阵推断（honeymoon lingerie 1.9K 绿格 vs honeymoon stockings 0 死格——§7.3 明文纪律）
6. **型号/车型级有量判别式**（§7.3）：查"型号词"真实量，有量=可建型号级页面矩阵（A 型），0 量=只能做品牌级 hub（B 型）

**案例**：车载滤芯池 25,037 vs 冰箱水滤池 3,227 vs 情趣内衣池 ~1,500——三个品类的页面数上限直接差一个数量级，与主词量排序**相反**。

### 2.3 路径三：autocomplete / People Also Ask 挖矿

**操作步骤**：
1. **Alphabet soup**：种子词 + a-z 字母后缀逐位挖（[Google autocomplete 挖矿通行法](https://vocal.media/01/how-to-use-google-autocomplete-for-keyword-research-and-seo-strategy)，行业级）
2. **修饰词挖矿**：按 [00-词根调研法 §8 Seed Patterns](./00-词根调研法.md)（best X / X vs Y / X for [audience] / how to [verb] X / is X [adj]）
3. **PAA 问题链**：SERP 的 People Also Ask 直接是 Google 的需求清单（[AlsoAsked 类工具](https://alsoasked.com/) 或 serp_analysis 的 PAA 特征），问题词天然是内容页选题
4. 挖出词回到工具验量/验 SD

**本库增强——autocomplete 安全过滤探针**（§7.3 实战判据）：疑似成人/敏感品类先跑字母挖矿（抽 3 个字母位）：
- **零返回** = Google 在源头掐灭长尾分发，词池天花板被结构性锁死（sexy/babydoll lingerie 字母位零返回）
- **放行** = 换种子词根即可正常挖（stockings / fishnet stockings 放行 300+ 条）

这条探针把"能不能挖"变成了 autocomplete 层面的一分钟测试，避免敏感品类拉完大池才发现锁死。

### 2.4 路径四：forum / Reddit 缺口（内容质量缺口信号）

**机制**（行业专家分析，[Glenn Gabe / GSQi：Hidden Gems Update](https://www.gsqi.com/marketing-blog/beyond-reddit-and-quora-google-hidden-gems-update-forums-surge/)）：Google 自 2023-11 起系统性抬升一手经验内容（Hidden Gems 更新，超出 Reddit/Quora 的范围）→ **SERP 里 forum/Reddit 帖子占位 = Google 认为该 query 缺乏高质量编辑内容 = 内容质量缺口信号**。2024-03 core update 后排名有部分回摆（同源标注）。

**操作步骤**：
1. serp_analysis 查目标词 top20，数 reddit/forum/quora 占位数
2. forum 占位 ≥ 2 且无强独立站 → 该词存在"编辑内容缺位"机会，用一手经验/实测型内容进入
3. Reddit 帖排名高（如 fantasy name generator 词 reddit 排#2）另读一层信号：**用户已在主动找"真人推荐"**——对工具词意味着 ChatGPT 替代风险真实存在（05 组实证）

**陷阱标注**：forum 占位既是缺口信号也是分流方——占位过多说明 query 意图本身偏讨论型（社交型 query），独立站做不出讨论区土壤。本路径是**辅助信号**，不单独定案。

### 2.5 路径五：新词红利（趋势词 = 天然零竞争窗口）

**机制**：新词/新品类/新热梗词——工具库无难度数据、内容供给未跟上、SERP 无固化既得者 = **时间窗口型低竞争**。

**操作步骤**：
1. Google Trends：Related queries 切 **Rising** 标签，`Breakout` = 增长超 5000%（[Google 官方定义](https://support.google.com/trends/answer/4355000?hl=en)）
2. 新番/新平台/新热梗词直接 match_keywords 查量与 SD（工具对爆发中词汇的收录有滞后，需 Trends 互补）
3. 判意图形态再立项（热度词 ≠ 购买词）

**本库实证案例**（04-兴趣周边组遗留观察）：
- `kpop demon hunter cosplay costumes` 3,600/SD9/PD8 —— 2025 新番带出的竞争真空词；**每年新热门动画会复现此类窗口**（可复用机制，非孤例）
- `ai action figures` 9,900/SD33 —— AI 手办风图热度词，内容流量机会但非购买词（意图形态判定的示范）

**陷阱标注**：窗口会关闭（主流站跟进后 SD 快速抬升）；热度词须过 §3.4 变现判据（CPC≈0 的娱乐热度词不做）。

### 2.6 路径六：Event SEO（产品事件创造的新关键词，2026-09-15 新增）

> 来源：remove.bg 被 Canva 收购关站案例（余味joyofmay 公众号分析，行业专家级，2026-09）。

**机制**：SEO 机会并不总来自长期存在的关键词——**一次收购、关站、涨价、迁移，本身就会创造新的 Search Demand**。原 #1 退出后的流量重分配形成三层机会，价值排序与流量排序**相反**：

| 层 | 词族形态 | 量级 | 判定 |
|---|---|---|---|
| Head Term | 王座词（如 background remover 120 万/月） | 最大 | ❌ 不抢——"第一名空出来≠竞争消失"：SERP 下面 Adobe/PhotoRoom/Canva/Pixelcut 全站着。**人人看得懂的机会=大公司也看得懂的机会** |
| **Category Branch** | 巨头统治期没被产品化的具体 Job（product background=电商整条工作流/passport photo=合规照） | 中等 | ✅ 小团队最适合长期做——**大产品退出会把打包在一起的需求重新暴露** |
| **Alternative/Migration** | `{product} alternative / migration / api migration` | 小 | ✅ 抢时间窗口——**量小但意图极强**（搜 migration 的人在解决已存在的业务问题），上线速度>产品规模 |
| API Migration | api 词 + referring domains 生态 | 最小 | ✅ 价值可能最高（见 §3.4 外链生态证据法）——门槛也高，适合有开发能力的 B2B/Infrastructure 团队 |

**操作步骤**：
1. 监测巨头产品事件（sunset/收购/涨价）——**x-radar 每日雷达应将 Product Sunset 列为监测对象**
2. 保存事件站的核心关键词与页面级数据（外链/referring domains，关站前抓取）
3. 三层判定（上表）：不抢王座→找 Branch→抢 alternative 窗口→评估 API 生态
4. Event 词上线速度>产品规模（竞品已提前布局 alternative 内容时窗口收窄）

**反直觉内核**：产品消失≠需求消失。正确的问题不是"我能不能成为下一个 X"，而是"**X 统治这个 Category 时，哪些用户任务没有被充分产品化**"。这也是"先从 Search Intent 看到没被解决好的 Job，再决定产品形态"（与本文判据驱动同构）。

## 3. 如何选择——六判据体系

发现路径产词，判据体系定生死。六判据按裁决顺序排列（前两个是闸门，中间两个是实证，后两个是商业与政策落地）。

### 判据总表

| # | 判据 | 一句话判法 | 红线信号 | 来源 |
|---|---|---|---|---|
| 1 | **AI 抗性** | 答案是否必须到站获取？ | AIO 占位1 + 意图=短文本/单值答案 | 07-祝福语实战提炼 + 05 组单值答案测试 |
| 2 | **词池深度** | 剔污染后可用池能换算多少页？ | 池 <1,000 且无场景扩容 | 00-词根调研法 §7.3 |
| 3 | **SERP 生态** | DA<25 小站在 top10-20 占位吗？ | 三锁形态（巨头/AIO位1/商品卡切割） | 18 雷达各组 serp_analysis 实证 |
| 4 | **变现路径密度** | CPC/RPM/毛利撑得起流量？ | CPC≈0 娱乐词 / RPM 地板层 | 00-词根调研法 §7.1 + 07-祝福语 §五 |
| 5 | **thin content 风险** | 产出物是事实性内容还是可再生文本？ | 纯文本列表页=scaled content abuse 靶子 | Google 2024-03 spam policy 明文 |
| 6 | **供给/履约可行性** | 1688/POD/数字交付接得住？ | 重资产零售 / IP 词 / 版权执法方活跃 | 18 雷达各组 pSEO 适配节 |

### 3.1 判据一：AI 抗性（2026 核心判据，一票否决级）

**判法一句话：答案是否必须到站获取**（07-祝福语内容词族 §六实战提炼："决定这类站成败的不是词量、不是 SD、不是 pSEO 结构，而是答案是否必须到站获取"）。

**强抗性（可做）**：
- 事实性不可替代内容——游戏 codes 真码 AI 编不出，用户必须进站验证
- 多参数交互——计算器（gpa/卡路里）、60 题性格测试、星盘计算（出生数据+历法），AI 摘要给不了
- 强抗性实证：占星工具线 8 词抽查中 2 词**均无 AIO** 且独立站主导（05 组）

**弱抗性（砍）**：
- 短文本生成——祝福语 AI 随口生成，零点击必要性
- 单值换算——"how many oz in cup" 是一个数字，AIO 一口答（**单值答案测试**：05 组全组纪律"答案是单个数字/一句话的词全部不做"）
- 分层证据（明文数据）：omnicalculator（头部词全是换算型）两年 -69%，calculator.net（交互型）率先回升；nameberry 名字列表页 -89% 崩塌 vs astro-seek 星盘工具 V 型存活

**操作**：serp_analysis 直接看 AIO 占位状态（Ubersuggest 自带 AI Overview 位次）+ 意图形态判定。AIO 已占位1 且意图可摘要 = 一票否决，后续判据不再看。

### 3.2 判据二：词池深度（第一定量判据）

详见 §1.2 与 [00-词根调研法 §7.3](./00-词根调研法.md)。补充实战换算参考：

| 剔污染后可用池 | 页面数上限量级 | 判读 |
|---|---|---|
| > 10,000 | 千页级 | pSEO 大站生意（车载滤芯 25,037 / 油画 16,843 / calculator 族百万级） |
| 3,000-10,000 | 数百页 | 健康单站或综合站品类（墙纸家居族 9,306 / 人造植物 6,225） |
| 1,000-3,000 | 数十-百页 | 精品站/综合站子品类（class ring 2,052） |
| < 1,000 | < 50 页 | 单品类立项不足，须并入综合站或砍（键帽 464 / 交易卡 338 / 3D卡片 970 靠场景×收件人矩阵勉强支撑） |

### 3.3 判据三：SERP 生态判定（实证而非推断）

**核心动作**：serp_analysis 抽 3-4 个代表词（主词+长尾词+商业词），看 top10-20 构成。

**可进实证形态**（看到即可进，不是推断是证据）：
- **DA<25 小站占位**：lab glassware 前三全独立站（DA26-33 拿 93% 点击）；embroidery kit 第一页大半 DA15-32 小站、DA4 进前30；墙纸 floral 长尾 DA15 排位10、DA25 排第1；gpa calculator #1 是 DA34 单功能站
- **Amazon/巨头缺席或靠后**：rotary evaporator manufacturers 零 Amazon 零 Alibaba；wallpaper 大词 SERP 被家居电商主导（wallblush DA25 进 top20）
- **中国系同行缺席**：中国仪器商独立站 SEO 普遍空白（njningkai DA8 流量0）= 我方成熟打法进入即降维（02 组，推断级：基于参照站体检）

**三锁形态**（任一锁死即该词降级）：
1. **巨头锁**：DA55-94 垄断且零小站——`living room ideas` top29 最低 DA55（03 组）；software download 位3 起全是 DA76-93（06 组）
2. **AIO 锁**：AIO 占位1 且意图可摘要（祝福语 4/4 词，见判据一）
3. **商品卡/local pack 锁**：popular_products 切割自然位——artificial plants 4 个商品卡块+IKEA/Amazon 包围（03 组）；magnetic stirrer Amazon 位1 拿 37% 点击（02 组）

### 3.4 判据四：变现路径密度

四条变现通道各有密度指标：

| 通道 | 密度指标 | 正反例 |
|---|---|---|
| 广告（AdSense/RPM） | CPC 带宽 + 品类 RPM 口径 | 旋蒸 CPC $4.92 vs 祝福语 $0.01-0.17；祝福类 RPM $3-6（推断）vs 解梦 $10-20（库内 SEMrush 实测口径）——同样运营力度收入差一个数量级 |
| 询盘（B 端） | PD 值 + manufacturer 词族 | 旋蒸 PD=100（广告主重金争夺=商业价值实锤）；manufacturers 词族零 Amazon |
| 实物毛利 | 出厂价 vs 零售价差 | 墙纸 $1.35-1.52/㎡ 出厂 vs 欧美零售 $30-60/卷 |
| 付费报告/数字交付 | freemium 转化路径 | truity 多框架测试矩阵 freemium 被 DA70/153 万月访验证 |

**PD 双读法**（本库推断纪律）：PD 高=商业价值被广告主验证；但 **PD 极低（≈2）可能是品牌官方垄断广告位**（hasbro action figures PD=2），不是缝隙是死地。

**意图纪律**（[00-词根调研法 §7.1](./00-词根调研法.md)）：低流量高意图 > 高流量低意图（Parts 词根月流量 4.3K 但 Traffic Cost 5.3K，商业意图 73%+）。Commercial + Transactional > 60% 才值得优先。

**外链生态证据法**（2026-09-15 新增，来源 remove.bg 案例）：关键词数据之外的第二需求证据——**referring domains 结构**。`remove background api` 月搜仅 140，但 remove.bg 的 /api 页有 **500 个 referring domains**（代码仓库/Package/开发文档/自动化工具引用）= API 已进入真实开发者生态。API 用户迁移意味着改 Endpoint/重测/重算价格——**流量大小 ≠ 商业价值大小**：搜"api migration"的开发者背后是在线运行中的 workflow 要换基础设施，B2B 级价值远超其搜索量。适用场景：判 B2B/API 类小量词的真实价值时，先查目标站的页面级外链生态（backlinks/domain_overview 反链数），勿被三位数搜索量吓退。

### 3.5 判据五：thin content 风险（政策判据）

**明文**：Google 2024-03 spam policy 明确打击 scaled content abuse——"无论生产方式，规模化产出无独立价值内容"。

**判法**：问产出物的本质——
- **事实性不可替代内容**（codes 真码、型号参数、价格数据）→ 政策暴露面低，AI 批量管线安全
- **可再生生成性文本**（祝福语列表、泛泛产品描述）→ 教科书级靶子；**同一个 AI 批量管线，产出物的抗政策性天差地别**（07-祝福语裁决链明文）

**配套纪律**（[00-词根调研法 §5.5-5.6](./00-词根调研法.md)）：页面数量必须与域名权重匹配；同聚类关键词合并到单页避免同质化；聚合站每页须有真实介绍内容防 doorway 判定（06 组）；新站分批发布配套外链+社媒信号。

**对冲手段**：tool-hybrid——生成器/计算器工具层 + 内容层（祝福语若复活唯一形态是生成器工具站，07 组已明文）。工具层同时解决 AI 抗性（判据一）与政策风险（判据五），一箭双雕。

### 3.6 判据六：供给/履约可行性

词和流量都过了，最后问"货接不接得住"：

| 供给形态 | 判法 | 正反例 |
|---|---|---|
| 1688 产业带 | 供给条数+出口报价实查 | 墙纸 82,841 条/$1.35-1.52/㎡ ✅；义乌仿真花 1,139 家经营主体=供给极度过剩红海 ⚠️ |
| POD/轻定制 | 打样-量产-物流链路 | 交易卡纸卡印刷 POD 极轻 ✅；3D 卡片 SKU 开发需纸艺工程+刀模=重资产 ⚠️ |
| 数字交付 | 即时下载零物流 | embroidery designs 即卖即下载 ✅ 但单词量 30-110 微小 |
| 重资产否决 | 库存/渠道/资金门槛 | gundam 分销零售、action figure 库存、class ring 贵金属——SEO 可进但模式不匹配，砍 |
| IP 风险否决 | 词池 IP 词占比+执法方活跃度 | cosplay 90% 词=未授权 IP（Disney/任天堂积极执法）；键帽长尾全 IP 词——收款/广告/DMCA 三雷，砍 |

**判据来源说明**：供给判断标注为行业常识推断（18 雷达各组明文纪律："供给判断为行业常识推断，非本次数据源实测，深研时需 1688 实查核价"）。

## 4. 实战校验案例表（2026-09 雷达判例反证方法论）

八例覆盖进/砍/候补三态，全部来自 18-产品雷达-2026-09 已判例。每例一句话过判据链，验证 §3 体系的裁决力：

| 判例 | 判定 | 一句话过判据 |
|---|---|---|
| **家居墙纸** | 进 | 家居词族剥离后池 9,306（判据二✅）+ 长尾 SD12-35 带 + DA15-25 小站 top10 占位实证（判据三✅）+ Transactual 意图 + 1688 $1.35/㎡（判据四六✅）；风险注记：类目 2024→2026 流量回调，按当前基线建模 |
| **实验室仪器综合站** | 进 | lab glassware 前三全独立站 + manufacturers 词族零 Amazon（判据三✅）+ 旋蒸 CPC $4.92/PD100（判据四✅）+ 询盘模式客单 $2k-15k + 中国仪器商 SEO 空白=降维进入 |
| **油画复制品** | 进 | 池 16,843 全组最深（判据二✅）+ DA30 参照站 14K/月 + DA29-42 小站占前3（判据三✅）+ 公有领域名画数据可程序化 + 大芬村供给成熟（判据五六✅） |
| **刺绣 kit** | 进 | DA4 进前30 + 参照站 639 ref domains 做 8 万月流量=内容驱动实证（判据三✅）+ 无 IP 风险 + 轻小件物流友好（判据六✅）+ 内容护城河与 AI 规模化产能天然结合 |
| **占星工具线** | 进 | 配对 144 格词 SD9-12（判据二✅）+ 8 词抽查无 AIO 且独立站主导（判据一三✅）+ 星盘需多参数输入=AI 替代不了 + 水晶站资产三重协同 |
| **祝福语词族** | **砍** | 池 64K/SD21/DA8 进位2/5 个月 48K——判据二三四全优，**栽在判据一（4/4 抽词 AIO 占位1，短文本=AI 完美答案）+ 判据五（可再生文本=scaled content abuse 靶子）**：2024 年打法的胜负手恰是 2026 年的红牌 |

**判例的方法论价值**：祝福语与占星工具线是同一周内的一对对照实验——前者词池更深（64K vs 1.9K 池）、SD 更低（21 vs 57 主词）、pSEO 结构更完美，判定却相反。**分水岭只有一个判据：答案是否必须到站获取**。这坐实了 §3.1 把 AI 抗性排为 2026 年第一否决项的裁决顺序。

（其余判例：浏览器小游戏/性格测试/计算器=进，cosplay/action figure/软件下载站/综合站模式=砍或候补，裁决逻辑同表，见各组档案。）

## 5. 工作流：五路径 → 六判据 → 雷达式分组扫描

### 5.1 完整流程

```
【发现层】六路径并行扫词（词从哪来）
  路径1 KD过滤 ──┐
  路径2 词池解剖 ─┤
  路径3 挖矿探针 ─┼─▶  产出：候选词/品类清单
  路径4 forum缺口 ┤
  路径5 新词红利 ┤
  路径6 Event SEO（产品事件词）┘
        │
        ▼
【初筛层】双闸门（10 分钟淘汰赛）
  闸门1 AI抗性：AIO占位 + 意图形态（短文本/单值答案 → 直接砍）
  闸门2 词池深度：剔污染后 <1,000 且无扩容 → 并综合站或砍
        │
        ▼
【实证层】SERP 生态 + 参照站体检（数据说话）
  serp_analysis ×3-4：DA<25 小站占位？三锁形态？AIO/PAA/商品卡特征？
  domain_overview ×2-3：参照站 24 月流量曲线（活样本/死样本/衰退样本）
        │
        ▼
【商业层】落地三问
  变现密度够吗（CPC/PD/毛利）？
  产出物抗政策吗（事实性 vs 可再生文本）？
  供给接得住吗（1688/POD/数字交付/IP风险）？
        │
        ▼
【扫描层】雷达式分组扫描（18-产品雷达目录模式）
  按主题分组（定制实物/B端仪器/家居/兴趣周边/流量工具/下载站/内容词族）
  → 组内多候选一页内快判（判定总表+一句话理由）
  → 晋级候选另开深研档案（不阻塞组内其余候选）
```

### 5.2 雷达式分组扫描的执行纪律（18 目录模式复用）

1. **组文档结构**：判定总表（词池深度/主词量 SD/参照站流量/判定/一句话理由）→ 每候选五节（词池→SERP 抽查→参照站体检→pSEO 适配→判定）
2. **工具预算**：每组 Ubersuggest MCP ≤ 25+8 次调用（match_keywords + serp_analysis + domain_overview），查询口径统一 US locId=2840
3. **判定三态**：进（晋级深研）/ 候补（挂起，写明复活条件）/ 砍（写明栽在哪条判据，供方法论回写）
4. **判据回写闭环**：雷达产出的新判据（如 §7.3 的探针/判别式、祝福语的 AI 抗性判据）经验证后回写方法论文档——**方法论不是先验设计出来的，是判例反哺出来的**
5. **参照站三态读法**：活样本（健康流量曲线=可复制）/ 死样本（流量崩盘=模式未被验证或已被打击）/ 衰退样本（-50% 以上=赛道或政策风险信号，须归因后再用）
