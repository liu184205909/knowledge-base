## 正确的步骤 2C/2D 执行标准（项目级）

> RLM §2C/2D 通用规则见方法论执行版。本节定义本项目落地时的具体口径，AI 执行 2C/2D 时**必须先读本节**。

### 2C 执行口径

| 页面类型 | 依据包要求 | 参考来源 |
|---------|-----------|---------|
| **单页型**（About/Home/Contact/FAQ/Ethical Sourcing 等） | 完整页面级依据包（content-v1.md + ui-v1.md） | [02-网站规划/pages/](02-网站规划/pages/) |
| **模板矩阵型**（Crystal Single ×391 / Condition ×35 / Zodiac ×12 / Chakra ×7 / Color ×12 / Combinations ×207 / Compatibility ×78 / Tarot 690+） | 模板级依据包（[03-内容策略/内容Brief/模板-*.md](03-内容策略/内容Brief/)） | 见各 Brief 模板 |
| **工具型**（互动工具） | PRD + generate.js + seo-content.html | [07-互动工具/](07-互动工具/) |

**禁止项**（RLM §2C 强制）：
- 禁止占位文本（Lorem ipsum / "Coming Soon" / placeholder）
- 禁止图片复用（每石种/每主题独立生成）
- 禁止跳过依据包直接写内容
- 动态区数据源在构建时决定，不接受静态假卡片占位

### 2D 验收口径

**验收清单**（每页上传后必过）：
1. HTTP 200 + canonical 正确
2. Title / Meta Description / H1 齐全且含目标关键词
3. Mega Menu / 导航链接可达
4. 移动端首屏渲染正常（无横向滚动）
5. 动态区数据源生效（WooCommerce product_categories / WP Query 等真实数据，非静态卡片）
6. 图片 webp 加载 + alt 文本完整
7. 内链 3-5 条（指向同 Pillar 相关页面）
8. JSON-LD Schema 验证通过（Product / Article / BreadcrumbList 等）

**验收记录**：独立 2D 验收报告待建（当前散布在决策表和 2A 行内标注，待第三批整合）。
