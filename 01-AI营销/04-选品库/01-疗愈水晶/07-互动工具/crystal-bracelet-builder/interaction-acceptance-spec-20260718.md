# T17 v3 交互验收合同

本合同适用于 2D 编辑器的本地与测试环境验收。线上页面已运行 v3；2026-07-25 已回读插件 `0.1.30` 为启用状态，公开 CSS/JS 均加载 `?ver=0.1.30`。后续版本仍须分别回读线上插件和公开资源。

## 不变边界

- 只使用 2D 托盘和 2D 碰撞；不引入 Three.js、GLB 或全局珠径。
- 素材以独立 Variant 参与显示、占位长度、方向和服务端报价；前端不保存价格规则。
- 本地 fixture、竞品图和开发教程图均不可作为公开 Catalog、产品图或销售数据。
- 公开页面通过 `.ew-t17-ui[data-t17-ui]` 识别；`ew-t17-builder` 只用于历史兼容检查。

## 页面与卡片

- 桌面为约 55:45 的设计区/素材库；手机为设计优先的纵向布局，素材固定两列。
- 点击卡片或使用 Enter/Space 加入当前选中 Variant；`− / +` 只切换该卡片显示的尺寸，不改变数量。
- 单 Variant 卡片保留底部高度但不显示尺寸按钮；透明产品图保留自身轮廓与比例，卡片预览不改变实际尺寸、价格、占位长度或显示比例。
- 目录只显示 `Crystals` 与 `Accessories`。对美国消费者公开前，名称和分类必须为英文。

## 托盘与编辑

- 支持混搭尺寸。组装状态按实际占位和视觉尺寸分配圆环，不得重叠、越过托盘安全边界或改变配方顺序。
- 圆珠固定；配饰按数据自动使用切线、向外或显式方向。没有人工全局方向按钮。
- Release 状态允许拖动调整位置；Assemble 状态拖动重排。拖出托盘删除，Undo 恢复最近一次本地修改。
- 加料从桌面右侧或手机下侧进入托盘；碰撞、反弹与最终停靠必须在减少动态效果设置下仍保持有效。

## 手围与完成设计

- 显示长度、件数/目标件数、建议手围、总价；不再使用 Weight 字段。
- 手围和松紧只产生建议，不能静默增删、换尺寸或重排配方。
- 超过 300 mm 的本地保护上限时保留设计并明确报错；服务端报价必须有等价保护。
- Finish Design 只能提交由服务端 live Variant 重新报价后的配方。购物车与订单验收属于独立交易门禁。

## 验收清单

1. 在 320、375、390、425、768、1280、1440 px 检查托盘、两列/三列卡片、无横向溢出和主题控制不遮挡。
2. 验证加料、尺寸切换、20+ 混搭、Assemble/Release、拖拽重排、拖出删除/Undo、手围、保存/恢复和 Finish Design。
3. 运行 `node --check frontend/t17-builder-ui.js`、前端/后端/方向/数据合同检查。
4. 在测试环境验证公开 Catalog、正向报价、隐藏承载商品、结账、订单快照和退款；未完成前不得宣称交易闭环。
