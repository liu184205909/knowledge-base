# 页面内容策略指南

> 5 类高转化页面的内容框架与检查清单。解决"写什么"的问题（MCP 生产 SOP 解决"怎么搭"）。
> 来源：Shopify Blog、Baymard Institute、张友兵、RLM 实战。2026-07-21 合并自 5 个独立文档。

---

## 0. 通用原则（所有页面适用）

| 原则 | 要求 |
|---|---|
| **移动端优先** | B2C 60%+ 流量来自手机；B2B 高管通勤调研 |
| **5 秒规则** | 首屏必须传递核心价值，否则永远失去用户 |
| **可扫描** | 标题层级传递核心价值 + bullet list + 适度加粗；用户只读 20% 内容 |
| **一个核心目标** | 每个页面聚焦一个 CTA，不给太多选择 |
| **简单胜过创意** | 雅各布定律——用户期望网站跟他们用过的类似 |
| **真实 > 完美** | 真实照片/评价/数据 > 图库/AI 虚构 |
| **品牌一致** | 字体/颜色/语调与全站一致 |

## 1. Homepage（首页）

### B2B vs B2C 核心差异

| 维度 | B2B | B2C |
|---|---|---|
| **目标** | 获取销售线索 | 直接促购买 |
| **决策周期** | 长（数周~数月），多人决策 | 短（几分钟~几天），个人决策 |
| **首屏标题** | "We build high-converting B2B websites" | "Shop New Arrivals / Up to 40% Off" |
| **CTA** | Book a Demo / Request a Quote | Shop Now / Add to Cart |
| **社会证明** | 客户 logo 墙、Case Study、行业认证 | 评分/评论、UGC、达人推荐 |
| **内容重心** | 白皮书、行业洞察、ROI 数据 | 促销、新品、分期、生活方式 |
| **信任建议** | Case Study、认证 | 评论、退换政策、安全支付图标 |

### B2B 首页结构

```
[Hero + CTA(Book a Demo) + 客户 logo]
[3 个核心痛点]
[方案可视化]
[Case Study（必须含量化数据）]
[功能分解]
[FAQ + CTA(Book a Call)]
```

### B2C 首页结构

```
[全局促销 bar]
[Hero + CTA(Shop Now)]
[核心分类展示]
[Bestsellers / New Arrivals]
[品牌故事（中位置）]
[Editor's Picks / 个性化推荐]
[信任信号 + Footer]
```

### 首屏 5 秒回答三问

| 问题 | ❌ 错误 | ✅ 正确 |
|---|---|---|
| 你做什么？ | "We innovate solutions for growth" | "We build high-converting B2B websites" |
| 给谁用？ | 模糊行业描述 | "For SaaS companies doing $1M-$50M ARR" |
| 为什么信你？ | 无 | 客户 logo 墙 + "Trusted by 200+ companies" |

## 2. Landing Page（着陆页）

### 核心观念

**着陆页不是艺术品，是销售员。** 唯一任务是把访客变成客户。

> 电商着陆页平均转化率 6.6%，10%+ 属于高转化。（Shopify）

### 五大支柱（Shopify）

| 支柱 | 检查问题 |
|---|---|
| **价值主张** | "What's in it for me?" |
| **文案与故事** | 用户"get it"了吗？ |
| **UX 设计** | 路径清晰且无障碍吗？ |
| **认知轻松** | 页面让人"本能地"行动吗？ |
| **无摩擦感** | 有没有多余步骤/干扰？ |

### 页面结构（4 板块）

```
[首屏：利益标题 + 副标题 + 社会认同 + CTA + FUD消除]
[解决方案 + 优势：FABE展开 + 问题-煽动-解决框架]
[限时限量优惠 + 赠品策略]
[温馨提示 + FAQ + 底部 CTA]
```

### 首屏 5 要素

| # | 元素 | 要求 |
|---|---|---|
| 1 | 利益驱动标题 | 具体收益 + 时间/量化指标 |
| 2 | 清晰副标题 | 解释"如何实现" |
| 3 | 首屏社会认同 | 媒体 logo / 大数字 / 好评 |
| 4 | 突出 CTA | 颜色对比，文案说明获得什么 |
| 5 | 消除 FUD | "7天退款" / "已有10,000+用户" |

### 7 个设计秘诀

1. **5 秒规则**——首屏传递核心价值
2. **情感驱动**——图片放结果场景而非产品图
3. **结构 > 长度**——多价值主张 + 社会证明 + FUD + 竞争对比
4. **可扫描**——标题层级 + bullet list + 适度加粗
5. **真实社会证明**——姓名 + 头像 + 来源 + 具体场景
6. **视觉层次**——标题最大 → 副标题 → CTA → 正文灰色
7. **简单胜过创意**——选择越少转化越高

### 赠品策略

| 原则 | 说明 |
|---|---|
| 相关性强 | 赠品与主产品互补 |
| 感知价值高 | 标价明显高于实际成本 |
| 不可单独购买 | 只能随主产品获得 |
| 数量限制 | "仅限前100名" |

### 常见错误

| 错误 | 正确做法 |
|---|---|
| 首屏说"我们是谁" | 标题 = 具体收益 + 量化指标 |
| 轮播图藏内容 | 移动端直接展示 |
| 匿名社会证明 | 姓名 + 头像 + 来源 + 具体场景 |
| 给太多选择 | 每页聚焦一个核心目标 |

## 3. About Us（关于我们）

### 核心观念

**About Us 不是"关于我们"，而是"关于客户"——我们如何为客户创造价值。**

### 8 个必备要素

| # | 要素 | 做法 | 避坑 |
|---|---|---|---|
| 1 | **有态度的标题** | 传达品牌态度 | ❌ "About Us" ✅ "Our Mission: To Bring Sustainable Comfort" |
| 2 | **品牌故事** | 创始人故事 / 使命驱动 / 产品诞生 | 用具体细节，不说空话 |
| 3 | **使命与价值观** | Mission + Vision + Values，用行动证明 | ❌ "致力于高品质" ✅ "每件由工匠手工穿制" |
| 4 | **真实团队** | 创始人照片 + 团队工作场景 | 真实照片远比图库有说服力 |
| 5 | **产品/工艺价值** | 材料来源 + 制作工艺 + 设计哲学 | 具体细节胜过一百句"高质量" |
| 6 | **社会证明** | 真实评价 + 媒体 logo + UGC + 奖项 | 第三方声音 > 自卖自夸 |
| 7 | **行动号召** | 主 CTA → 核心产品 / 次 CTA → 社媒 | 不要让页面成为死胡同 |
| 8 | **联系方式** | 底部联系方式或链接 Contact 页 | B2B 有实体店地址极大增强信任 |

### WHOWE 写作框架

> 基于"痛点前置 → 情感连接 → 理性证据"的决策心理设计。

| 模块 | 英文标题 | 核心作用 | 占比 |
|---|---|---|---|
| **W** | Why we created [Brand]? | 抓注意力，锚定初心，戳痛点 | 15% |
| **H** | How we started (Our Story) | 建立情感连接，讲清缘起 | 20% |
| **O** | Our approach (How we make it) | 展现实力，对应痛点给方案 | 25% |
| **W** | Where we're heading | 价值升维，完成闭环 | 15% |
| **E** | [Brand] Experience | 硬实力信任状，促成转化 | 25% |

### 跨市场文化差异

| 市场 | 叙事偏好 | 敏感点 |
|---|---|---|
| **欧美** | 个人主义、自我表达、包容性 | 可持续、环保、社会责任 |
| **东南亚** | 性价比、家庭价值、社群认同 | 口碑、明星/KOL 背书 |
| **中东** | 品质、尊贵感、传统工艺 | 权威认证、王室/贵族背书 |

### 页面结构

```
[有态度的 Hero 标题]
[品牌故事（选 1-2 个角度深入）]
[使命与价值观]
[团队展示]
[产品/工艺价值]
[社会证明]
[CTA：主要 + 次要]
[联系方式]
```

## 4. Product Detail Page（产品详情页）

### 核心观念

**产品详情页是数字货架上的产品陈列。** 核心任务不是罗列参数，而是让用户确信"这就是我需要的"。卖点不在于数量，而在于精准组合（**不超过 5 个**）。

### FABE 法则

| 步骤 | 回答 | 示例（GORE-TEX 外套） |
|---|---|---|
| **F** Features | 这是什么？ | 面料采用 GORE-TEX |
| **A** Advantages | 比别的好在哪？ | 100% 防水同时透气 |
| **B** Benefits | 对我有什么用？ | 暴雨徒步内部干爽 |
| **E** Evidence | 你怎么证明？ | 暴雨实拍视频、SGS 认证 |

> **B（利益）是最重要的环节。** 用户买的是产品能解决的问题。

### 卖点三分类

| 类型 | 说明 | 展开程度 | 页面位置 |
|---|---|---|---|
| **独特型（USP）** | 人无我有 / 人有我优 | FABE 完整展开 | 首屏 / 核心区域 |
| **保障型** | 风险逆转（退换/质保/物流） | 重点 B+E | CTA 附近 |
| **通用型** | 品类基础期望 | 参数表一笔带过 | 折叠区 |

**组合**：独特型 2-3 + 保障型 1-2 + 通用型 0-1 = **不超过 5 个**

### 页面结构

```
[面包屑导航]
[首屏：产品主图/视频 + 核心卖点 + 价格 + CTA]
[尺码/颜色选择 + CTA + 分期 + 物流]
[独特型卖点 1-2：FABE展开]
[产品细节图/视频]
[用户评价（分类筛选 + UGC + FAQ）]
[交叉销售：Complete the Look]
[保障型卖点]
[通用型 / 参数表（折叠）]
[底部 sticky CTA（移动端）]
```

### AI 辅助详情页创作流程

1. **竞品评论挖掘**：收集 10-20 条竞品评论（差评找差异化、好评找核心价值、QA 找购买疑虑）
2. **产品信息整理**：名称、参数、材质、工艺、目标用户
3. **AI 卖点提炼**：从功能/情感/经济三维度分析，输出 5 个核心卖点
4. **卖点排序**：人无我有 > 人有我优 > 人优我异 > 通用型
5. **AIDA 结构设计**：Attention(Hero) → Interest(USP) → Desire(场景+证明) → Action(CTA+保障)
6. **各模块文案**：标题、痛点、方案、参数→利益转化、场景、信任、CTA

### CTA 优化

| 要素 | 要求 |
|---|---|
| 位置 | 紧跟尺码/颜色选择 |
| 移动端 | Sticky CTA 始终可见 |
| 文案 | 说明点击后获得什么 |
| 交叉销售 | "Complete the Look" 而非 "You May Also Like" |

### 常见错误

| 错误 | 正确做法 |
|---|---|
| 只列 Features 不说 Benefits | 每个卖点落到"对用户的价值" |
| 卖点堆砌超过 5 个 | 精选 5 个以内 |
| 通用型卖点放最前 | 独特型优先 |
| 保障型藏太深 | 放 CTA 附近 |

## 5. Checkout Page（结账页）

### 核心观念

**约 70% 的购物者在加购后放弃购物车。** 目标只有一个：**让用户尽可能轻松地完成付款。**

### 10 大最佳实践（Baymard Institute）

| # | 实践 | 错误做法 | 正确做法 | 数据 |
|---|---|---|---|---|
| 1 | **Guest Checkout 最显眼** | 只显示"新客户/老客户" | Guest 放最顶部 | 19% 因强制注册放弃 |
| 2 | **简化密码规则** | 要求大小写+数字+特殊字符 | 仅 6-8 字符 | 19% 因登录失败放弃 |
| 3 | **送达日期代替配送速度** | "2 Business Days" | "Delivers Thursday" | 48% 没做到 |
| 4 | **倒计时显示截止时间** | "Order by 9AM ET" | "Order in 43 minutes" | 83% 没做到 |
| 5 | **按钮修改数量** | 文本输入框 | +/- 按钮 | 97% 没做到 |
| 6 | **配送选择器列所有方式** | 只能回购物车切换 | 配送/自提同时可选 | 52% 没做到 |
| 7 | **同时标记必填和选填** | 只标记选填 | * 标必填，(optional) 标选填 | 61% 没做到 |
| 8 | **选填字段隐藏** | Company/Address2 直接显示 | 隐藏在链接后 | 32% 没做到 |
| 9 | **自适应错误信息** | "Your card is invalid" | "Your card number is incomplete" | 94% 没做到 |
| 10 | **说明手机号用途** | 必填但不解释 | "仅用于配送更新" | 49% 没做到 |

### 减少摩擦

| 方向 | 做法 |
|---|---|
| 最少字段 | 只收集必要信息 |
| 自动填充 | 浏览器原生 autofill，邮编识别城市 |
| 即时验证 | 输入时验证格式 |
| 多支付方式 | 信用卡 + PayPal + Apple Pay + BNPL |
| **避免隐藏费用** | 尽早显示运费/税费（**弃购第一原因**） |
| 移动端 | 大按钮(44x44px+)、匹配虚拟键盘 |

### 信任信号

| 类型 | 位置 |
|---|---|
| 安全认证（SSL） | 支付表单附近 |
| 退换政策 | CTA 附近 |
| 安全支付 logo | 页脚 |
| 客服联系方式 | 底部 |

### 重要说明

**Checkout Page 不建议作为普通 Elementor Page 从零生成。** 它由 WooCommerce Checkout 模板 + 支付网关 + 主题控制。本节定位为 **WooCommerce Checkout 配置优化清单**。

## 6. 转化率基准数据

> 来源：Shopify、IRP Commerce、Dynamic Yield（2026）

### 整体基准

| 指标 | 数值 |
|---|---|
| Shopify 商店中位数 | **1.4%** |
| 全球电商平均 | **2.5–3%** |
| 头部电商 | 5%+ |

### 品类差异

| 品类 | 转化率 | 特点 |
|---|---|---|
| 食品饮料 | 4–6% | 复购高、决策轻 |
| 美妆个护 | 3–4% | 视觉驱动 |
| 宠物用品 | 2–3% | 需求稳定 |
| 服装鞋帽 | 1.5–2.5% | 退换率高 |
| 家具家居 | ~1% | 高客单价、决策长 |

### 流量来源差异

| 来源 | 转化率 | 说明 |
|---|---|---|
| Direct | 5–10% | 品牌认知强 |
| Email | 3–6% | 精准触达 |
| 有机搜索 | 2–4% | 意图明确 |
| 社交媒体 | 0.5–1.5% | 冲动消费但信任低 |
| 付费广告 | 0.5–2% | 取决于匹配精度 |

### 漏斗诊断法

| 漏斗环节 | 关注点 | 常见瓶颈 |
|---|---|---|
| 浏览 → 加购 | 产品页说服力 | 价格/信任/描述不足 |
| 加购 → 结账 | 购物车体验 | 运费/优惠/强制注册 |
| 结账 → 支付 | 支付流程 | 步骤多/支付方式少/隐藏费用 |

> **诊断口诀**：哪一段掉最多，先优化哪一段。

## 7. 数据来源规则（所有页面通用）

| 内容类型 | 来源 | AI 能否生成 |
|---|---|---|
| 利益标题 | 业务输入 + 竞品分析 | 可辅助，需人工确认 |
| 痛点/场景 | 用户调研/评价分析 | 可辅助提炼 |
| 卖点文案（FABE） | 产品资料 | AI 可生成文案，证据需真实 |
| **社会证明** | **真实素材库** | **禁止 AI 虚构** |
| **价格/优惠** | **业务配置** | **禁止 AI 编造** |
| **保障承诺** | **业务实际政策** | **必须与实际一致** |
| **CTA 链接** | **站点实际 URL** | **必须人工确认** |
| **团队照片** | **真实拍摄** | **禁止图库照片** |

## 8. 落地页参考库建设

### 收集渠道

| 渠道 | 方法 |
|---|---|
| 被动收集 | 竞品调研时看到好的布局/交互直接截图 |
| 主动搜索 | `{行业词} landing page template` |
| 设计网站 | Dribbble、Behance、Canva、站酷、花瓣 |

### 模仿什么、不模仿什么

| 模仿 | 不模仿 |
|---|---|
| 内容区块排列顺序 | 竞品文案和品牌元素 |
| CTA 位置和频率 | 竞品图片素材 |
| 社会证明呈现形式 | 竞品配色和字体 |
| 信息密度节奏 | — |

### 学习路径

```
充分了解自己的产品 → 选中一个欣赏的案例 → 模仿内容结构并迁移
```

> 迁移的是**结构和布局逻辑**，不是照抄文案和图片。
