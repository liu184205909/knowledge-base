## 一、先纠正"沙盒"这个词

### 1.1 谷歌官方明文立场

谷歌发言人 John Mueller 等多次公开否认存在名为 "Sandbox" 的独立算法。官方对新站排名滞后的解释是"缺乏信号"——外链、品牌搜索、内容深度、历史数据。

### 1.2 业内观察（推断级）

| 来源 | 关键数据 |
|---|---|
| Ahrefs（140 亿页分析, 2023.12） | 96.55% 页面零流量；仅 **1.74%** 新页进入 Top 10 |
| Search Engine Land / LinkNow | 新站 3–6 个月内排名受限是统计现象 |
| Marie Haynes / Lily Ray | 持续观察到 "trust-building phase" 现象 |

### 1.3 关键认知（核心论点）

> **谷歌没有"沙盒过滤器"，但 NavBoost + PRNS + 索引评估的多个算法组件的合成结果，对新站产生了等效抑制。**

两者并不矛盾。把"沙盒"重新表述为**"多个算法组件的合成效应"**，才能落到可操作层。

## 二、信任期的三个算法组件

### 2.1 NavBoost 与"曝光作为分母"

**来源档位**：DOJ 反垄断证词（宣誓级）+ 2024 API Leak（字段名）

#### 核心机制

NavBoost 是**重排系统**，工作单元是 **点击 / 期望点击** 的比值，不是"点击"本身。

> **API Leak 字段**：`CrapsClickSignals` 模块同时包含 `unsquashedClicks` 与 `unsquashedImpressions`——同规格处理（原始值一份 + 归一化值一份）。如果曝光只是附属元数据，不会有自己的"未压缩"版本。

曝光在系统中承担三件事：
1. **当分母**（点击 / 期望）
2. **与位置共同构成期望值**（决定该位置本该拿多少点击）
3. **决定置信度门槛**（曝光量小时，比值波动 > 真实信号 → 该数据行进不了评估）

13 个月滚动窗口（DOJ 证词确认）。

#### 对新站的直接推论

**推论：0 状态网站在商业词上"拿不到分母"**（来源：鸭老师SEO《且看且珍惜》2026.07）

> "这不是分数低，是不在评价系统里。"
>
> 商业词特征：查询量少、竞争最高、SERP 被已建立的站坐死。0 状态的站排不进 → 拿不到曝光 → 数据行不存在。
>
> 区分：**没有曝光**（系统对你无话可说）vs **有曝光但 0 点击**（仍在场上，分数低）。后者可修复，前者需要先入场。

**入口不由漏斗位置决定，由 SERP 可进入性决定**。信息型内容的作用不在转化，在于它是 0 状态站唯一能真正拿到曝光的地方。

#### 同时废掉的两个流行指标

| 指标 | 为什么无效 |
|---|---|
| **页面级 CTR** | 被各查询曝光占比加权后的平均值，查询池一变它就变，**页面没改也会变** |
| **页面级平均位置** | GSC 取最高位置跨查询平均，A 词 3→30 + B 词 30→3 = 平均位置不变，而实际处境已天翻地覆 |

诊断只在**单查询层级**成立。跨查询的 CTR 比较、跨查询的平均位置，都是无效数。

#### 与 goearthward.com 的对照

| GSC 观察 | 算法解释 |
|---|---|
| 平均位置 48.3 | 不在 NavBoost 评估池 |
| quick_wins 返回空（无 4–15 位关键词） | 商业词拿不到曝光 = 数据行不存在 |
| 28 天曝光仅 4665 | 刚跨过置信度门槛 |
| 5 项健康检查全 PASS | 未被标记，处于正常信任期爬升 |
| 流量在 3–30 倍增长 | 信息型内容正在拿"分母" |

### 2.2 PRNS 链接最短路径

详见 [16-PRNS链接权威与最短路径模型](./16-PRNS链接权威与最短路径模型.md)。本节只列对新站相关的核心结论：

- 算法计算的是**到种子站的最短路径**（DOJ 工程师宣誓证词）
- Web 2.0 / 站群互链 = **距离无穷大**，不参与计算
- 新站天然距离远，需通过"准种子界面"（中等权威站）缩短
- 同主体多站互链极易被识别为站群，**不在最短路径上**

### 2.3 索引评估的置信度门槛

**来源档位**：API Leak 字段名推断（**未经谷歌证实**）

- 曝光量小时，点击自身的波动幅度大于要测量的变化
- 这一行数据进不了 NavBoost 评估
- 解释了 Ahrefs 统计中 "96.55% 页面零流量" 的成因——大多数页面根本没机会被评估

## 三、缩短信任期的可操作信号（按 ROI 排序）

### 3.1 信息型内容优先突破（拿"分母"）

- **商业词先放弃**：SERP 可进入性 = 0，硬刚等于浪费资源
- **信息型内容是 0 状态站唯一能拿到真实曝光的入口**
- 一旦页面稳定拿曝光 → 进入 NavBoost 评估池 → 反哺整站信任
- 操作要点：长尾 + 真实需求 + 内容深度，避免触发 SpamBrain 的 AI 内容阈值

### 3.2 准种子外链建设（缩短 PRNS 距离）

- 不是"高 DA"而是"**接近种子集**"
- 详见 [17-PRNS 文档 7.2 节](./16-PRNS链接权威与最短路径模型.md)
- **警告**：luckycrystals.org 这类同主体老站互链可能根本不在最短路径上，留着无用

### 3.3 品牌搜索量积累

- 用户主动搜索品牌名是强信任信号
- Machine Relations 研究（680 品牌分析）：品牌搜索量是 AI 引用的最强预测因子（详见 [14-AI搜索研究](./13-AI搜索研究与Prompt执行库.md)）
- 实操：社媒、PR、客座文章保持品牌名露出一致

### 3.4 多语言版本的合理部署

- goearthward.com 已部署 `/pl/ /nl/ /pt/ /zh/ /de/`，首页 referringUrls 显示这些版本已索引
- **警告 1**：hreflang 必须正确，否则视为重复内容
- **警告 2**：自动翻译质量低 → 触发 SpamBrain 标记 → 同主题内容排名下降 5–8 位（**中文 SEO 圈观察，未经谷歌证实**）

## 四、案例诊断：goearthward.com 2026-07-27

### 4.1 数据快照（近 28 天 vs 上一周期）

| CTR | 0.77% | 0.08% | +818% |
| 平均位置 | 48.3 | 59.9 | 前进 19 位 |

### 4.2 五项健康检查全 PASS

- 流量下降页：`[]` 空
- GSC 异常警报（14 天）：`[]` 空
- 内容衰减（3 期对比）：`[]` 空
- 关键词自相竞争：`[]` 空
- 首页索引状态：✅ PASS（已索引，canonical 一致，最近爬取 2026-07-25）

### 4.3 结论

- **未被标记/惩罚**（5 项证据）

- 策略方向：保持信息型内容输出节奏，让"分母"持续累积；商业词布局留给信任期结束后

## 五、老站资源处理决策树（luckycrystals.org 类）

### 5.1 决策矩阵

| 老站特征 | 推荐方案 | 理由 |
|---|---|---|
| 同主体 + 同 IP + 互链 | **直接下线（410）** | 已被识别为站群，不在 PRNS 最短路径 |
| 同主体 + 干净独立 IP | 保留 6–12 月作过渡外链 | 短期可能提供少量信任信号 |
| 干净 + 有真实流量 + 不同主体 | 评估 301 重定向到新站相关页面 | 可传递 PageRank_NS |
| 有历史惩罚 / 低质量 | **立即下线，不 301** | 301 会传递负面信号 |

### 5.2 luckycrystals.org → goearthward.com 的处理建议

- 首页 referringUrls 显示该链接存在
- **推断（未经证实）**：若两站同主体、同 IP 段，该链接按 PRNS 最短路径可能已被压低或忽略，下线无实质损失
- **不建议 301**：老站→新站整体重定向，谷歌可能视为不自然链接传递
- **建议方案**：直接下线（A 方案），让链接在 2–6 个月内自然失效
- **不需要在 goearthward.com 端主动删除链接**：referringUrls 是 GSC 报告层信息，链接的物理位置在 luckycrystals.org 上

## 六、来源分层与方法论

### 6.1 三档来源严格区分

| 档位 | 内容 | 可信度 |
|---|---|---|
| **第一档（宣誓证词）** | DOJ 反垄断案：NavBoost 存在、Glue 分管 SERP、13 个月滚动窗口 | 高 |
| **第一档（官方明文）** | 谷歌发言人否认 Sandbox 算法；Google Search Central 文档 | 高 |
| **第二档（API Leak）** | `CrapsClickSignals` 字段名（`unsquashedClicks` / `unsquashedImpressions` / `goodClicks` / `badClicks` / `lastLongestClicks`） | 文档真实，**任何解读未经谷歌确认** |
| **第二档（统计研究）** | Ahrefs 140 亿页 1.74% / 96.55% 数据 | 数据可信 |
| **第三档（业内推测）** | "0 状态站拿不到分母" / "曝光决定置信度门槛" / Marie Haynes / Lily Ray 的 trust-building phase | 推断级，引用必须标注 |
| **第三档（社区推测）** | CRAPS = Click and Results Prediction System | 无任何官方确认 |

### 6.2 写作纪律

- **核心判断只依赖第一档 + 第二档的字段名本身**
- "曝光是分母、点击是分子"是**结构判断**
- "Google 拿实际点击除以期望点击、据此下调位置"属于**实现细节**，**没有任何公开信息**，本知识库不作此主张
- 第三档用于解释现象，不作为结论依据
