# 内容生产实操 SOP

> **定位**：从 Brief 到发布的完整操作清单。只管"做什么"，不管"为什么"——理论依据见 [01-内容质量与可检索性标准.md](./01-内容质量与可检索性标准.md)。执行版决策骨架 §3.3（gate / 门槛 / 路由）。

## 1. 写作前

### 1.1 SERP 深研产物准入
> 深研工序本体（拉数/逐页档案/增益规划）见 [关键词调研与SERP深研SOP](../01-竞品研究/关键词调研与SERP深研SOP.md)；本节只管单篇执行层的产物准入与框架产出。
1. 开写前必须有该词深研档案（`03-内容策略/关键词深研/`）：必选元素（≥6/10 共性）、字数区间（P25-P75）、共同缺口=差异化点、差异化资产清单 ≥3 项（无 → 降级 800 字短文或并入 hub 页，见 §1.2）
2. AIO 占位词：答案前置段必做且 40-60 词可引用长度（档案 SERP 特征列）
3. 产出文章框架（H1/H2/H3 骨架，存 `03-内容策略/文章框架/`）——由深研档案直接生成，不在写作会话内重新拆 SERP
4. pSEO 矩阵篇走轴级框架模板+单篇增量复核（抽 2-3 篇确认无漂移，漂移单篇微调）；新题/种子篇必须全流程 top 10（两级复用规则见深研SOP §六）

### 1.2 Brief 锁定（7 门槛全过才能开写）
- [ ] 关键词 + 意图 + 数据来源已声明
- [ ] Volume / KD / CPC 已标注
- [ ] 竞品内容已复核——以深研档案为准入证据：单篇新题=全流程前 10 逐页拆档案；pSEO 矩阵篇=轴级框架模板+2-3 篇增量复核
- [ ] URL + 承接页面已确定
- [ ] 内链规则已规划
- [ ] DREAM 至少 1 项差异化
- [ ] **差异化资产清单**：列出本篇 3-5 个竞品 top10 没有的具体信息点（5-to-7 Rule 前置到 Brief），每点标注来源分级（官方文档 / 实测库 / 工厂经验 / 推断）。无 ≥3 项资产 → 降级为 800 字短文或并入 hub 页，不立独立 URL

### 1.3 DREAM 5 维快速检查
| 维度 | 检查 |
|------|------|
| D 需求 | H2 是否说明了"为什么需要" |
| R 理由 | 是否给出"为什么选这个" |
| E 证据 | 是否有数据/案例/来源 |
| A 优势 | 是否展示具体差异化 |
| M 动机 | 是否给"现在行动"的理由 |

## 2. 写作中

### 2.1 写作原则
- **answer-first**：每段第一句 = 核心结论
- **独立可提取段落**：每段离开上下文也能读懂（不用"它""这个"开头）；答案和证据在同一段
- **5-to-7 Rule**：每篇提供 5-7 个竞品 top 10 没有的信息点

### 2.2 避免 AI 写作特征（前 4 条必查，第 5 条句式级扫描）
> 层级定位：本节与 §2.3 为**文笔卫生层——最弱因子**（句式层去 AI 味后强检测器仍 98% 检出），继续执行但别当差异化；增量与叙事层规则见 §2.4，优先级更高。
1. ❌ Pub Test 失败（读起来像"任何博客都能发"）
2. ❌ First 10% 冗余（开头是废话引入，应直接进结论）
3. ❌ Kill List 命中（delve / leverage / tapestry / navigate / unveil）——**语境限定**：仅限动词/修辞用法；工程名词合法用法豁免（"hinge leverage" 铰链杠杆、"cure time" 固化时间、化工 "cures"、"guarantee one dye lot" 工艺确定性），机械扫描命中后人工复核语境再判
4. ❌ Human Sandwich 缺失（没有真人语气夹击 AI 段落）
5. ❌ **句式级特征**命中 ≥2（管句法层）：①段首定义句——连续段落以 "X is a..." 开头 ②三段式排比——"not only A, but also B, and C" ③段末总结废话——"X plays a crucial role in..." ④句长节奏单一——全篇 15-20 词中长句无长短交替 ⑤零自然瑕疵——通篇无碎片句/反问/语气词。命中超标按 §2.3 技术表改写

### 2.3 六大去 AI 化技术
| 技术 | 操作 |
|------|------|
| First 10% Deletion | 删开头冗余，直接进结论（quick-answer blockquote 是落地形式） |
| Kill List | 扫描禁用词（合规向 heal/cure/guarantee + AI 风格向 delve/leverage/tapestry）；项目级清单见项目 `03-内容策略/品牌语调配置.md §4` |
| Human Sandwich | AI 客观段之间夹入"真实体验 / 个人观察 / 品牌故事" |
| Pub Test | 读出来像不像真人写的 |
| High-Low | 信息密度交替（深分析段 → 简明要点段） |
| Anti-Pattern | 用反例 prompt 让 AI 避开模板 |

### 2.4 活人感注入：增量与叙事层（优先级高于句式级）
> 判定原理与实证数据见 [01-内容质量与可检索性标准](./01-内容质量与可检索性标准.md)「AI 内容规模化反模式」章。核心判据：Google 判定轴是"目的 + 同题 SERP 增量"，与生成方式无关；AI 内容靠质量信号系统性沉底，不靠 AI 检测器。

**A. 增量层（开写前判据——答不出不开写）**
- 每篇 **5-7 条可归因原创单元**：第一方数据 / 事故失败记录 / 逐字用户语言 / **SME 引语 ≥1**（实测最强手法，+42.6% AI 引用可见性）/ 原创截图
- 素材只准取自**经历语料池**（事故档案 / GSC 实测数据 / 工程细节 / 客户原话），**禁 AI 现编**——现编的 personal note 本身就是新 AI 味
- **判断层语料**（2026-10-12 增，希声《AI 时代的捷径》）：语料池条目除"发生过什么"外，尽量补"**当时为什么这么做 + 后来结果怎么样**"（如：为什么选这个题/哪段改了几遍/发布后读者问了什么/下次怎么调）——判断层在，AI 下一次的产出才有你的决策而非通用逻辑
- 反 experience theater 五要素：具体日期时长 + 原始凭证 + 精确数值 + **失败与成功并列** + 可验证身份引语

**B. 叙事结构层（写作中——检测分界层）**

| 规则 | 操作 |
|------|------|
| SWBST | 至少一处"行动者+目标+障碍+响应+结果"叙事，替代知识罗列 |
| 主语对齐 | 句子主语 = 真正话题，禁错位（主语是 readers 句子却在讲结构） |
| 具体性强制 | 专有名词/日期/实测数字 ≥5 处；many/several 清零 |
| 真让步 | 具体局限 + 适用边界 + 量化代价。⚠️ 模板化"当然也有挑战"段 = AI 假让步强特征，删 |
| register 漂移 | 全篇一个温度是 AI 特征；人会分析→激动→平静 |
| 勿机械清洗 | 有意重复/平行结构/em dash 是好模式勿误删——作用于信息层，非表层 |

**验收与红线**：贡献与长度成正比（读者读完觉得值）；**禁用 AI 检测器分数做验收**（强检测器宁可漏检不误判）。语料池供每篇引用 5-7 条合规，"每词一页 + 每页贴同一段经历"违反 scaled content abuse；词汇黑名单有时效性，定期对照 [Wikipedia: Signs of AI writing](https://en.wikipedia.org/wiki/Wikipedia:Signs_of_AI_writing) 刷新。

## 3. 写作后

### 3.1 Commodity Content 自检（AI prompt，Marie Haynes 原版）
```
What are 10 concepts discussed in this page?
For each, tell me whether this topic has been widely written about online.
Does this content add anything truly uniquely interesting?
Be brutally honest, don't flatter me.
```

### 3.2 规模化内容风险自查（命中 ≥3 个需重设计多样性）
> 与 Lily Ray 220+ AI 内容站监测的八大危险模板一致（54% 此类站丢失峰值流量 30%+，真源见 01 号）。存活判据：**页面能否被竞品用同一个 prompt 明天复刻**；过滤滞后 3-6 个月，当前无恙≠安全。站点级信号纪律见 §5.4。
- [ ] 规模化对比页 `/blog/[A]-vs-[B]`（横跨所有组合）
- [ ] 术语页 `/glossary/[term]`（程序化多语言版本）
- [ ] "Best X for Y" 清单（affiliate 起源）
- [ ] 自推清单（自己排第一，无真实测评）
- [ ] 竞品替代页 `/blog/[competitor]-alternatives`
- [ ] 程序化地理/语言页（无真实物理地点）
- [ ] FAQ 农场（一页一问）
- [ ] 离题内容（与业务无关的高搜索量内容）

### 3.3 事实核查三级风控
> 发布前逐段扫描，标记所有事实性声明并分级：

| 等级 | 声明类型 | 处置 |
|------|---------|------|
| 🔴 高风险 | 统计数据（% / 数字）、研究引用（"研究表明"）、医疗/功效声明 | **不核实不发布**——找到原始来源或删除/改写 |
| 🟡 中风险 | 产品规格、价格对比、第三方评测结论 | 核实但不阻塞；价格改区间或加"截至 X 年 X 月"标注 |
| 🟢 低风险 | 常识性描述、方法论论述 | 免核 |

**配套写作纪律**：AI 初稿所有数据引用处带 `【需要核实数据】` 或 `*(pending verification)*` 标记，核查完成后统一清除——残留标记 = 未完成核查，不得进 §4。

### 3.4 编辑完成检查清单
- [ ] 关键词与意图匹配
- [ ] 内链 3-5 条指向已有页面
- [ ] Meta 三件套（Title / Description / H1）含目标关键词
- [ ] 无 CJK 残留 + 无合规禁用词
- [ ] **事实核查标记清零**（发布硬门）：`grep -ri "pending verification\|需要核实数据" 文章/` 返回 0 行——🔴 高风险数据（下单级尺寸/价格/SKU）残留即阻塞发布，处置三选一：对真源台账核实 → 改区间表述 → 删该数据行（宁删勿存疑）

### 3.5 承诺接力四问（转化型内容必查）
> 转化型内容（品类页/礼品指南/评测）编辑完成时过四问。原则：承诺越往下游越具体，未验证的效果不承诺。

| 问 | 检查 | 不过的修法 |
|---|------|-----------|
| ①入口承诺是什么 | 本文最响的卖点+目标场景 | — |
| ②留下什么问题 | 用户信任该承诺前需知的条件/边界（尺码/洗后/版本） | 补 H2/FAQ（对接 VOC 三张表证据需求） |
| ③在哪回答 | 每个疑问有明确承接位（本文段/产品页/尺码表） | 补内链/段落 |
| ④能否兑现 | 版本=售卖版本？效果有验证依据？ | 无依据承诺降级为边界表述或删 |

## 5. 发布后

### 5.1 上线验证
- [ ] HTTP 200 + canonical 正确
- [ ] 无 CJK 残留（grep head / title / description）
- [ ] Schema 校验（Google Rich Results Test）
- [ ] 内链生效（打开文章看链接）
- [ ] 动态区接真实数据

### 5.2 GSC 监控（上线 4 周后）
- 收录状态（`site:` 搜索 / URL Inspection）
- 排名信号（position 4-15 = striking distance 机会）
- 掉量检测（GSC Insights → Trending down pages）
- CTR 异常（高曝光低 CTR → 标题/meta 问题）

### 5.3 更新处置三选一（§5.2 检测出问题后的处置）
> 三套口径按场景选，不混用：本节=GSC 信号快速处置（单页/小批量）；批量全量审计用 [04-内容审计与优化工具包](./04-内容审计与优化工具包.md) 行动动词七分法；战略层判断见 [01-内容质量与可检索性标准](./01-内容质量与可检索性标准.md) 存量内容审计框架。

| 信号 | 处置 | 动作 |
|------|------|------|
| 排名稳定但停滞（striking distance 4-15 位） | **A 小幅更新** | 刷新过时数据/补充新角度/优化标题 → 改 `dateModified` → GSC URL Inspection → Request Indexing 触发重爬 |
| 排名下滑或内容质量不足 | **B 大幅重写**（50%+ 内容） | 重跑关键词深研（深研SOP §四起，档案超 3 个月必须重拉）→ 重写 → 同 A 触发重爬 |
| 零流量 + 内容薄 | **C 合并/下线** | 与主题相近文章合并，旧 URL 301 到合并目标；无合并价值直接下线 |

> 判断依据：内容是否还有搜索需求（有 → A/B，无 → C）。三类信号都要**先复查 SERP 现状**再动手——排名下滑可能是 SERP 格式变了（新增 AIO/视频），此时重写内容不如改格式。

### 5.4 站点级信号纪律（执法在站点级，非页面级）
> Google 泄露文档实锤的 Firefly 站点信号（`QualityCopiaFireflySiteSignal`）四字段：

| 字段 | 含义 | 纪律 |
|------|------|------|
| `numOfUrlsByPeriods` | 逐 30 天 URL 增速曲线 | future 随机时间发布防尖峰（✅ 已执行） |
| `numOfArticles8` / URL 总量 | 高质量文章比率 | 宁降速率保比率（§2.4 增量密度决定此值） |
| `dailyGoodClicks` 比率 | 点击后不返回搜索的比例 | 内容真实留人；标题党点击是负资产 |
| `latestBylineDateSec` vs `latestFirstseenSec` | 署名日期 vs 首次发现时间 | 禁回溯篡改日期装新鲜 |

- 发布速率与可查证编辑人力不匹配是检测信号；过滤滞后 3-6 个月（"Mount AI"曲线），当前无恙 ≠ 安全
- 存活画像（Zyppy 400 站，3→4 特征胜率 30.7%→**68.1%**）：工具任务完成 + 实物产品 + 紧 topical 已占 3 特征；第 4 特征补**专有资产**（逐站盘点"只有我们有的数据"并显式化）
- 站外同权：Reddit 引用 2025 年 +450% 成 AI 引擎第一引用源——经历素材一半投第三方平台

## 6. 批量场景验收（批量生产必读）
> 来源：配电柜站 1,058 篇骨架薄文事故 + 矫直机站断崖复盘。**词数达标 + HTTP 200 全绿 ≠ 无事故**——三项纪律独立执行，缺一不可。

### 6.1 发布前：独立门禁七项（每篇必过，即 §1.2 Brief 七门槛）
批量生产不得因量大跳过 §1.2 七门槛——§1.2 是独立关卡，不因批量放大而豁免（薄文事故漏网根因正是"理论有、操作无"）。

### 6.2 发布后：验收三查（每批次必做）
| 查 | 做法 | 判据 |
|---|------|------|
| ① 前端图渲染数 | 打开线上页面，数实际渲染出的图片数 | 渲染数 = 插入数（HTTP 200 不代表图片渲染成功） |
| ② 块完整性 grep | 对线上 HTML grep 关键块标记（表格 / FAQ / H2 结构） | 块缺失 = 0（批量写入偶发静默丢块） |
| ③ 词数变化量核对 | 抽查线上页词数 vs 草稿词数 | 截断/空壳页 = 0；薄文复核每批另抽 2-3 篇 |

### 6.3 分批纪律：每批 ≤15 篇
- **每批上线 ≤15 篇 + 批间观察窗口 3-5 天、GSC 观察一周**（矫直机站实证：批量上线引发蚕食）
- 单日 100-200 篇的**生产**节奏与 ≤15 篇/批的**上线**节奏不矛盾：生产可以快，上线必须分批放
- 上线后 SERP 蚕食监控与归并处置见 [04-SEO全链路与审计/01-SEO全链路工作流.md](../04-SEO全链路与审计/01-SEO全链路工作流.md) 第 II 部分 §1.3 自相竞争检测
