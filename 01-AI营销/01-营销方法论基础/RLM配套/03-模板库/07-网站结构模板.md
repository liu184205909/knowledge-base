## 模板

### 一、网站整体结构（导航层级图）

```text
首页
├── 一级类目 1（如 healing-crystals-jewelry）
│   ├── 二级类目（如 bracelets / necklaces / earrings）
│   └── 按意图分类（如 love / protection / abundance）
├── 一级类目 2（如 crystals-stones）
├── 百科/博客 Hub
│   ├── Crystal Meaning（单品百科）
│   ├── Crystals for X（功效页）
│   └── [其他主题线]
├── 互动工具
├── About / Contact / FAQ / Shipping / Returns
└── Hidden Pillar 页（如 intention / zodiac / chakra）
```

> **必填**：层级不超过 3 层；每个一级类目有明确的"为什么这样分"理由（来自 1E 观察 + 1H 策略）。

### 二、URL 规则

| 页面类型 | URL 模式 | 层级深度 | 关键词出现 | 示例 |
|---------|---------|---------|-----------|------|
| 产品单品 | `/product/{slug}/` | 2 | 是 | `/product/amethyst-bracelet/` |
| 百科单品 | `/{entity}/` 或 `/{topic}/{entity}/` | 1-2 | 是 | `/amethyst/` 或 `/crystals/amethyst/` |
| 功效页 | `/crystals-for-{condition}/` | 1 | 是 | `/crystals-for-anxiety/` |
| 类目页 | `/{category}/` | 1 | 是 | `/bracelets/` |
| 按意图分类 | `/{intention}/` | 1 | 是 | `/love-relationships/` |
| 博客文章 | `/blog/{slug}/` | 2 | 是 | `/blog/crystal-gifts-for-couples/` |
| 工具页 | `/tools/{tool-name}/` | 2 | 是 | `/tools/crystal-quiz/` |
| 运势类 | `/{type}/{sign}-{month}-{year}/` | 2 | 是 | `/horoscope/leo-july-2026/` |

**URL 命名规则**：
- 全小写，连字符分隔（不用下划线）
- 不含 stop words（the/a/an/of）
- 关键词前置（`/amethyst-bracelet/` 不写 `/bracelet-amethyst/`）
- 复数 vs 单数在 2A 统一决定（如 `chakras-crystals` vs `chakra-crystals`，水晶项目踩过坑）

### 三、内部链接规划

| 内链类型 | 规则 | 示例 |
|---------|------|------|
| 上下层级 | 百科 → 分类 → 产品，各层级互链 | Crystal Meaning → Crystal Category → Product |
| 主题关联 | 同 Topic Pillar 下的内容互链 | 同一产品线的百科 ↔ 使用指南 |
| 意图递进 | 信息型 → 商业型 → 交易型 | "什么是 X" → "最好的 X 推荐" → 产品页 |
| 锚文本 | 描述性，不用"点击这里" | "X 的核心功效" |
| 工具联动 | 互动工具 CTA 双向链接 | 文章 → Crystal Quiz，Quiz 结果 → 相关文章 |
