## 一、采购问题还原法

### 1.1 六要素公式

每个真实采购问题都可拆解为六要素：**产品 + 角色 + 阶段 + 任务 + 限制条件 + 最终判断**。反向使用：用六要素校验一篇内容是否踩在真实采购决策上——缺要素的内容是科普，不是采购支撑。

### 1.2 决策链拆解

采购不是一个动作，是一条链：**每个环节一个决策，每个决策一组问题**。内容应按决策组织，而不是按问题堆砌——200 个零散问题背后可能只有 30 个决策。

### 1.3 连续追问链

买家的真实追问顺序：**初始 → 补充 → 比较 → 限制 → 风险 → 决策**。页面结构与 FAQ 排序照此链组织，比按关键词密度组织更贴近真实评估路径。

### 1.4 数据源五级排序

| 级 | 数据源 | 说明 |
|---|--------|------|
| 1 | **真实询盘**（当期） | 最高优先级，买家亲手写的需求 |
| 2 | 历史询盘统计 | 第二方存量，需归并去噪 |
| 3 | GSC / 自动补全 / PAA | 第三方搜索行为数据（我们现有主线） |
| 4 | 行业社区 | Reddit/论坛，噪声多 |
| 5 | 招标文件 | 低频但规格密度高 |

排序含义：**上级数据源可推翻下级结论**。当询盘证据与词工具数据冲突时，采购价值判断以询盘为准。

### 1.5 六维评分模型

每个候选问题/选题按六维打分（各 1-5 分）：**商业价值 / 决策权重 / 项目明确度 / 风险 / 证据强度 / 内容缺口**。总分排序进选题队列。配电柜站执行口径见 15-记录表 §三月度汇总。

### 1.6 页面颗粒度原则

**提示词颗粒度 ≠ 页面颗粒度**。采购问题（Prompt）是需求的最细粒度，页面按采购决策组织：**约 200 个问题 → 归并 30 个决策 → 15 篇文章 → 5 个落地页**。不是一问一页，也不是全部塞一页。

## 二、后进入者工具页打法

### 2.1 根本逻辑

低权重站抢大词的根本不是外链堆砌，而是**页面真正满足搜索意图**——工具页（计算器/换算器/生成器）是意图满足度最高的页型之一：用户在页面上直接完成任务，无需跳转。

### 2.2 首屏免注册

文章案例：工具页首屏**免注册直接可用**，改版后流量翻倍（明文：案例数据来自原文）。注册墙在第一屏 = 意图满足中断 = 排名与传播双输。

### 2.3 取舍账

| 放弃 | 得到 |
|------|------|
| 留资转化（部分） | 排名（意图满足度信号） |
| 数据独占性（部分） | 自然传播（免费被分享/收藏） |
| | 免费外链（工具页是天然外链磁铁） |
| | 品牌词增长 |

### 2.4 阶段论

不是永远免费：**品牌与排名起来之后再加注册墙/留资门槛**。先用免注册换流量资产，再收割。顺序反了 = 双输。

## 三、与我们实践的映射（推断，本笔记增量）

### 3.1 现状核对：我们卡在第 1 级数据源的空白上

electricalcabinet.net 现状（02 诊断，2026-09-08）：DA 7 / 引用域 627 / organic keywords 908 / 近 90 天 945 clicks。03/08 两个选题库（合计 203 项选题）数据源声明 **100% 为 Ubersuggest + GSC**——即五级排序里只用了第 3 级。**询盘数据源完全空缺**，而我们握有第 1 级（实际卖家身份），这是 eabel 式内容工厂结构性拿不到的。

### 3.2 已落地动作与该方法的暗合（先做了，本笔记补认知）

- **34 篇 BOFU 双线排期**（配电柜 15 + 变压器 19，12 排期总表）：manufacturers/suppliers/builders 词簇本质是采购决策链终点（1.2 决策链）的页面承接。
- **F 簇配套采购决策页**（lead-times / cost-breakdown / moq / audit-checklist / type-test-verification）：03 选题库 F 簇的选题维度（交期/成本/MOQ/验厂/验真）与"核心决策"枚举几乎重合——已是按决策组织的选题，非偶然。
- **BOFU 写作的限制条件增强**：对应六要素中的"限制条件"要素（1.1）。
- **3 个计算器/换算类工具页**（任务背景给定：温升计算、kVA↔A 换算等）：工具页打法（§二）已落地，且符合 2.2 免注册口径。

### 3.3 批判保留：双目标并行，不切换

原文从 GEO/询盘视角出发，**弱化了 SEO 流量逻辑**——倾向"直接回答采购问题"，轻视词量/SD 判据与流量规模。我们的立场：**词量主线 + 采购价值修正，双目标并行**。理由（推断）：DA 7 站当前阶段流量资产本身稀缺，词工具证伪成本（一次 serp_analysis ≈0）远低于询盘等待成本（3-6 个月积累期）；先用词量起量、询盘数据积累后逐步给采购价值加权（15-记录表 §四 的两源交叉口径）。不因方法论新潮而推翻已排产的词量主线。

### 3.4 落地接口

15-询盘问题记录表九列 = 六要素的执行化：产品线（产品）/ 采购角色（角色）/ 项目阶段（阶段）/ 核心决策（任务+最终判断）/ 限制条件 / 目标国家 / 证据频次（证据强度维度的计数化）/ 处理状态（内容缺口闭环）。
