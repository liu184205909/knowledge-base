> **定位**：词池到手后的一道漏斗——**粗判**（值不值得做，群口径低成本）→ **深研**（怎么做赢，单词口径逐页拆）→ Brief 准入。与竞品分析SOP+深档模板（域名级）构成 01-竞品研究 三级颗粒度的词池级+单词级。
> **合并说明**（2026-10-09）：本 SOP = 原《关键词调研与搜索意图判定手册》+原《单关键词SERP深研SOP》合并简化版——两者本质是同一次 SERP 数据的两个深度出口，合并后一次拉数逐级下钻，消除两次拉数与触发接缝。1C 工具手册（RLM 体系）已废弃归档。
> **来源**：意图实判+页型映射+两问测试 = 公众号《你真的理解关键词的搜索意图么?》（2026-08，转引 Wix Studio 7.5 万 AI 答案研究 + WordStream，行业专家分析级）；深研工序 = 2026-10-09 收口（原散内容SOP §1.1/竞品SOP §5 门禁/全链路工作流）。

## 〇、漏斗总览

```
词池（四查/自查/主题矩阵来）
  ├─ 第一阶段 粗判（§二-三）：每页型 8-16 词抽样实测，同群继承结论
  │     三判 → 4 字段 → 对账编 G 号 → 不做 ✕ / 进排产 ✓
  └─ 第二阶段 深研（§四-六）：仅对过粗判的词，排产 → 开写之间
        同份 SERP 续拆 → 逐页档案 → 增益规划 → NO-GO ✕ 回排产 / Brief 准入 ✓
```

| 级 | 口径 | 成本 | 死亡出口 |
|---|------|------|---------|
| 粗判 | 群抽样（8-16 词实测，同群其余继承） | serp_analysis 订阅内≈0 | 三判任一不过 → 不做/降级 |
| 深研 | 单词前 10 逐页 webReader 实拆 | 贵（每页一次抓取）——故漏斗收窄后才跑 | 竞争格局不可争 / 差异化资产 <3 项 → NO-GO 回排产 |

**深研唯一时点**：过三判、编 G 号进排产之后、开写之前——它是必经工序，不存在"要不要深研"的犹豫；不值得做的词在粗判就死了。**改进场景**（GSC 阶段 2 / 内容SOP §5.3 处置 B）跳过粗判直接进深研，档案追加不新建。

**词池来源与盲区**（"顺便"的边界：竞对驱动不能是唯一来源——否则永远追着竞对打存量）：

| 来源 | 性质 | 盲区 |
|------|------|------|
| 竞对四查（`domain_keywords`+top_pages 主词） | 存量已验证，最便宜（研究竞对时顺手拿） | **竞对视野锁死**——市场有量但竞对没做的词全看不到；混入竞对品牌词与长尾噪声 |
| `keyword_suggestions` 自查（每批 3 种子） | 种子扩展，半独立（拓词技法真源：[02-关键词挖掘实操手册](../../04-选品库/00-选品方法论/02-关键词挖掘实操手册.md)——种子词三源/字母挖矿/修饰词组合公式） | 种子质量依赖 |
| word-radar 趋势新词 | 增量（竞对还没做） | 量小需验证 |
| GSC 自家数据 / 询盘 VOC | 第一方已验证（最高级，五级排序见尾部 B2B 节） | 仅已上线站 / 样本少 |

**四查词级数据 = 原料不是结论**：竞对有排名 ≠ 词有量（可能只是目录行为）≠ 值得做（量级/页型/形态还要过三级杀）——顺手拿数据可以，跳过漏斗不行。新站冷启动与扩量阶段必须至少一个非竞对来源（suggest 自查 / word-radar / GSC）补盲。

# 第一阶段：粗判（三判）

## 二、第 1 判：意图实判——SERP 为准，标签只作初筛

工具标签是猜的，SERP 是 Google 亲自定的（每天几十亿次搜索的行为结论），冲突时 SERP 赢。操作：`serp_analysis` 一次 → 看前 10 页型分布：

| SERP 前排页型 | 实判意图 | 己方机会 |
|--------------|---------|---------|
| 权威科普（Mayo/NIH 级） | 纯信息 | 产品页零机会；post 也难打 |
| 产品类目页占多数 | 购买 | 品类页直接上 |
| 清单/对比文占多数 | 商业调查 | 对比/清单 post |
| 本地包 | 本地意图 | GBP + 本地页 |
| 论坛帖（Reddit 占位） | 经验/讨论 | 真实经验内容缺口 |

**判例**：`hyperbaric chambers` → 前排全医学科普 → 产品页零机会；`hyperbaric chambers for sale` → 前排全设备商类目页 → 上得去。**措辞陷阱**：`多少钱`可能真问价（可做）vs `平均多少钱`一个区间就被满足（零点击不做）——别看词面猜，去搜。

## 三、第 2+3 判：增长性与页型强制映射

### 3.1 两问测试（防被 AI 吃掉）

1. 搜这个词的人最后是否需要**真实商家**收尾（付款/发货/装机/售后）？
2. 有没有一条路**完全不联系任何人**就解决？——答"有"→ AI 直接答完零点击 → 不做

判例：`chambers`（是什么）AI 答完；`for sale`（几万美金设备）AI 无法代付代装 → 商家收尾型 = 当前最安全。数据底座：意图×AIO 频率矩阵（见 03-AI Citation优化策略）。

### 3.2 意图→页型映射（意图对不上格式，写得再好也进不了排名）

| 实判意图 | 强制页型 |
|---------|---------|
| 是什么/为什么/教程 | post（≥2000 词长文） |
| 最好的 X / vs / alternatives | post（清单对比体） |
| for sale / buy / custom / replacement / price | **product/category（文章互哺不算承接）** |
| 平均多少钱/区间查询 | 不做（3.1 已杀） |

page 走 HTML→Elementor 流水线，post 走 MD→Gutenberg（竞品SOP §10 本地生产契约）。

### 3.3 SERP 承接审计（页型终判）+ 三级不匹配全杀

前 10 逐条标承接类型，**多数派 = 该建的页型**（承接跟着 SERP 走，不跟着建站方便走）：

| 承接类型 | 识别特征 | 我方对应（WP+Woo） |
|---------|---------|------------------|
| 产品页 | 单 SKU 落地（价格/变体/加购） | Woo product |
| 类目页 | 多产品聚合 | Woo category |
| 文章 | 长文/清单/对比 | WP post |
| 工具页 | 计算器/生成器/换算器 | 工具页（custom post 或独立栈） |
| 平台 listing | Etsy/Amazon 商品页 | （平台店，非站内页型） |
| 品牌×品类限定 | {brand} brake lever 式混排 | 类目页变体：品牌集合页 |
| 型号/兼容限定 | {model} fit 式适配页 | 类目页变体：型号适配页（PartSeed 模式） |

**三级不匹配全杀**（任一不过 → 不建）：
1. **量级**：词 0 量不建任何页（birthstone 交叉词 14 个全 0 → 46 页删的教训）
2. **页型**：SERP 全产品页你建内容页（或反之）→ 进不了排名
3. **形态**（最隐蔽）：页型对但 SERP 卖的产品形态与你不同 → 别人的市场放弃——`mother birthstone necklace` 12,100/月全是传统多石款，摩斯珠串接不住；**词里不含你的品类词 = 大概率形态是别人的**，一律先验 SERP 形态

### 3.4 决策输出（4 字段，词群归并后同群继承）

意图（SERP 实判）｜增长性（商家收尾/AI 可答）｜页型（product/category/post/工具/不做）｜优先级（P1 >3K / P2 1-3K / P3 <1K，变体归并后口径，同竞品SOP §6 缺口判定）→ 进竞品SOP §6 对账表编 G 号。

# 第二阶段：深研（单词全拆）

## 四、逐页档案（前 10 全拆，11-30 轻量）

**输入**：主词（变体归并后）+ locId + 承接页型（粗判产物）。页型未定回 §3.3 重判，不在深研内补判。

**衔接规则（粗判数据复用，禁重拉）**：
- 粗判**实测过**的词：SERP 数据已在手，直接续拆成深研档案
- **继承结论**的词：深研首次拉数，同时复核继承的页型结论（多数派是否一致），漂移则改判并回写对账表

前 10 逐页字段（每页一行，全拆不留空）：

| 字段 | 来源 |
|------|------|
| 排名/域名/DA | serp_analysis |
| 页型（3.3 七类口径） | URL+标题 |
| 标题模式（变量化，如 {产品} {属性}: {利益点} \| {品牌}） | SERP title |
| 字数 / 格式特征（表格/图/视频/计算器/schema） | webReader |
| H2 结构 / 覆盖点摘要（一行）/ 强弱判断（各一短语） | webReader |

**拆解侧重分表**（页型不同，看的东西不同）：

| 承接页型 | 加重必拆项 |
|---------|-----------|
| 文章词 | H2/H3 全结构、answer-first、E-E-A-T 信号（署名/实测/引用） |
| 产品词 | 价格暴露、变体/SKU 结构、FAQ、评论信任资产、规格表深度、CTA 成交路径 |
| 类目词 | 过滤/分面机制、产品卡数量与密度、类目导语、内链深度、品牌×品类处理 |
| 工具词 | 工具类型、首屏免注册与否、输入输出形态、工具↔内容互链 |
| 品牌/型号变体 | 集合页 vs 单品页分布、兼容矩阵表、品牌导航 |

**混排 SERP**：各页型都拆不跳过，多数派定承接，混排本身是意图信号（产品词 SERP 混 3 篇评测 = 评测内容有位）。**11-30 轻量行**：只记排名/域名/页型，用于竞争格局尾部判断 + 多数派复核。

## 五、增益规划（六项产出）

1. **必选元素**：≥6/10 篇共性的段落/模块进基本盘，不到 6 票进可选池不硬凑
2. **字数区间**：前 10 的 P25-P75（不取极值）
3. **共同缺口 = 差异化点**：头部 10 篇**共同**缺口才算，单篇缺失不算（多页交叉验证）
4. **差异化资产清单**：3-5 个竞品前 20 没有的信息点，逐点标来源分级（官方文档/实测库/工厂经验/推断）；**无 ≥3 项 → 降级 800 字短文或并入 hub，不立独立 URL**
5. **SERP 特征承接**：AIO 占位 → 答案前置段必做且 40-60 词可引用长度；PAA → FAQ 问法池（问法可参考，答案自写）；featured snippet → 结构化段落/表格
6. **竞争格局**：开放/半开放/品牌集中/平台集中/不可争（枚举同深档 §5）——不可争时档案照存，标 NO-GO 回排产

## 六、产物与复用

档案落 `{项目}/03-内容策略/关键词深研/{keyword-slug}.md`：

```markdown
# {keyword} SERP 深研
- 主词｜变体归并｜locId｜承接页型｜触发场景（新建/改进）
- 查询日期（数据源）｜SERP 特征（AIO/PAA/snippet）｜竞争格局（五枚举）
## 逐页档案（§四表）
## 增益规划（§五六项）
```

**pSEO 两级复用**：轴级框架模板（同轴 N 篇只对头部词跑一次全流程定稿：必选元素/字数区间/内链位/差异化位）+ 单篇增量复核（写该篇抽 2-3 篇验轴模板无漂移）；新题/种子篇无轴模板，必须全流程 top 10。

## 七、纪律

1. **SERP 终判覆盖一切标签**；一词实测 ≠ 词群结论（8-16 词抽样，变体归并后判量级）
2. **P1 词与建 page 词必须实测**——省 $0.002 漏一个 8K 词族（sofa 教训）；两问测试在排产前跑，不发布后复盘
3. **前 20 默认口径，前 10 逐页全拆是硬底线**；逐页档案是必产物（不留档 = 临时发挥无沉淀）
4. **产品词/类目词与文章词同一工序**，不允许"只查不拆"
5. **建站前页型对账**：默认假设"我方内容页"，证据必须推翻它——**竞对词池页活着 ≠ 词有量（可能只是目录行为）**；页型歧义一律从严（该 product 的不建 page）
6. 粗判实测词续拆禁重拉；继承词深研时复核页型；档案超 3 个月重写必重拉
7. **竞对词池只是词池来源之一**——竞对研究时"顺便拿数据"可以，"顺便替代关键词研究"不行（跳漏斗=目录行为词/品牌词/形态错配全放行，见 §〇 盲区表）

# B2B 采购问题还原法与工具页打法

> 2026-09-14 并入（社区讨论级来源：跨境万元户/Chloe 两篇公众号文章）。本节=选题**第一方数据源方法论**（需求从哪来），前文管"词池到手后逐词判定与深研"。配电柜站实践映射见 [16-B2B采购问题还原法-配电柜实践映射](../../04-选品库/B端/11-配电柜/16-B2B采购问题还原法-配电柜实践映射.md)。

## 一、采购问题还原法

- **六要素公式**：产品+角色+阶段+任务+限制条件+最终判断——反向校验内容是否踩在真实采购决策上，缺要素=科普不是采购支撑
- **决策链拆解**：每个环节一个决策、每个决策一组问题；内容按决策组织不按问题堆砌（200 个问题背后可能只有 30 个决策）
- **连续追问链**：初始→补充→比较→限制→风险→决策——页面结构与 FAQ 排序照此组织
- **数据源五级排序**：真实询盘（当期）> 历史询盘 > GSC/补全/PAA > 行业社区 > 招标文件；**上级数据源可推翻下级结论**（询盘证据与词工具冲突时以询盘为准）
- **六维评分**：商业价值/决策权重/项目明确度/风险/证据强度/内容缺口（各 1-5 分）总分排序进选题队列
- **页面颗粒度**：提示词颗粒度 ≠ 页面颗粒度——约 200 问题 → 30 决策 → 15 文章 → 5 落地页

## 二、后进入者工具页打法

- **根本逻辑**：低权重站抢大词靠页面真正满足意图——工具页（计算器/换算器/生成器）用户在页内直接完成任务，是意图满足度最高页型之一
- **首屏免注册**：注册墙在第一屏=意图满足中断=排名传播双输（案例站改免注册后流量翻倍）
- **取舍账**：放弃部分留资与数据独占 → 换排名（意图满足信号）+ 自然传播 + 免费外链（工具页是外链磁铁）+ 品牌词增长
- **阶段论**：先用免注册换流量资产，品牌排名起来后再加注册墙收割；顺序反了双输
