# 竞品分析 SOP v5.2（情报生产执行版）

**状态**：执行版｜读者：主=Claude（执行竞研），次=人（审核产出）｜全史与规则溯源见 git｜v5.2 深度压缩+横向口径进工序节+横向分析/新路径（2026-10-12）
**核心原则**：竞研回答三问——①他们的钱从哪来②哪些页面值得我方进入③进入采用什么页面机制；URL slug 本身即信息（主题/类型/层级/pSEO 引擎）。**默认不批量读正文**，仅 4 类场景读页：动态工具/交互确认｜成交方式判定｜特殊页型抽样（每类 ≥1 页）｜内容质量抽查（固定样本见 §4）；抽查结论不外推全站。
**证据分级（强制）**：观察（sitemap 存在某类 URL）→推断（URL 呈现某模式）→验证（SERP/关键词/页面流量/实测兑现）；三清单每条+深档关键发现用证据块 `结论｜等级(验证/推断/观察，可分位写)｜证据(数据源+日期+关键数值+URL)｜限制｜对我方动作(模板/页面/排产/质检断言)`；仅"验证"级进"可复用机制"清单；URL 推断单独不得证明页面质量/流量/转化。

## 0. 铁律
1. **真实 SERP 驱动**：竞对发现/意图实判只用 Ubersuggest `serp_analysis`（主）/DataForSEO（备），禁 web_search_prime/WebSearch
2. **发现即登记，深研前必筛**：发现层全量登记不筛选；深研前过重点池筛选（真实竞对四条件收紧+五维：需求重叠/规模/模式相关/学习价值/词域在位，收敛 ≤30 家），池外档案+按域名数据文件清除留 git——发现层防漏，深研层防散
3. **sitemap 全量不抽样**：raw json 落档核验，深档提炼完成后即删（深档=唯一长期留存；季度 diff 用重抓新版 vs 深档统计行）。**提炼完成=数值+结构双标准**：①统计数值入档 ②类目树/页型分布/slug 模式以可横向对照粒度入档；跨家 IA 对照与品类版图对照=删 raw 前必完成的聚合分析，漏做不得删。品类版图**不限我方词池交集**；IA 从 sitemap 路径结构+导航层**双源推导**，禁词池分组叙事平移
4. **范围判断必须全量核实**："几家有博客"类判断必须 Python 扫全量 sitemap，不凭印象
5. **敏感词脚本层过滤**：研究文档只计数不落词面；过滤规则版本+数量+时间落 `过滤日志.txt` 随数据留档
6. **研究→生产闭环+需求范围纪律**：每个结论指向生产侧对应物（模板/排产/质检断言）；改 X 只动 X，顺手发现只报不动
7. **分档完成情报三问**：每个真实竞对必做 **Q1 基础版**；主对标站（2-3 家）与模式级深研对象必做 **Q1 深研版+Q2+Q3**（§0.5）；仅统计页面数量不算完成

## 0.5 情报三问（Q1-Q3 唯一定义处，其余章节只引用）
**Q0 他们在卖什么（每家必答）**：一级导航清单（header 实抓，非推断）+核心品类线（sitemap 目录/类目 term 全景）+各线规模信号，**不限我方词池交集**——跨家聚合成《品类版图对照表》（删 raw 前必完成，铁律 3）；邻品空白（≥3 家有供给+我方零覆盖）逐条上浮为发现并附主查词表。
**Q1 他们的钱从哪来（两档）**：

| 档 | 对象 | 数据 | 产出 |
|----|------|------|------|
| **基础版**（每个真实竞对必做） | 全名单 | `domain_overview`（步骤④）+ `domain_keywords(limit=10)` + `domain_top_pages(limit=10，月访>5K 家)` | Top 页面初筛（有效返回最多 10 行，不足如实记录） |
| **深研版**（主对标站 2-3 家+模式级深研对象必做） | 主对标/模式级 | 全量 `domain_keywords` 翻页至取尽（"≥200 词"=数据可得时目标量，不足如实记录不算失败）+每词绑定排名 URL | Top 20 页面清单+Q2 判定表 |

**Top 20 口径**（基础版不承担 Top 20 识别与 Q2 页面级决策）：按 `domain_top_pages` **页面级自然流量估算**排序，禁按关键词搜索量相加推算；列定义以模板 §4.1 为准（P-ID=页面主键，与页型无关）；主词月量≠页面流量，两列分开；深研版 `domain_top_pages` 用 **limit=20**。词级取数主通道=Ubs `domain_keywords`（自带 `url`+`sd` 列）；DFS Labs `ranked_keywords` 仅限季度词级快照（§8）与额度尽兜底（§9）。**品牌词口径**：词表=域名品牌+母品牌+产品品牌+常见拼写变体；占比注明按词数还是按流量算；多品牌站分品牌记录。
**Q2 值不值得进（八因子 × 五档）**：

| 因子 | 过线判据 |
|------|---------|
| 需求 | 非品牌有效月量达阈值（词族变体归并口径） |
| 意图 | 我方可承接（§6 两轨分流有对应承接页型） |
| SERP 机会 | 我方以目标资源可进（前十结构可争） |
| 竞争 | 前十构成记录口径：**开放｜半开放｜品牌集中｜平台集中｜不可争**（记前十中平台/头部品牌数+是否存在独立站站位） |
| 产品 | 我方有对应产品或服务 |
| 证据 | 价格/规格/评论/案例可得 |
| 生产 | 可规模化差异化生产 |
| 架构 | 不与已有页面自相残杀 |

逐因子判定，缺项标 ✳（待查）不得默认 ✓/✗；需求+SERP 机会不足以单独定 GO；行级判定可复用四查留档，仅 GO-P0 决策行要求实测 SERP。**五档**：GO-P0=直接进排产｜GO-P1=补证据或小规模测试后进排产｜HOLD=依赖（产品/架构）满足后复评｜NO-GO=不做记录原因｜WATCH=季度锚定复查复评。**GO 矩阵产出格式**：`主词｜月量｜SD｜他们排名｜我们现状｜建议 slug｜判定档｜优先级`。
**Q3 进了长什么样（模块契约）**：每个 GO 页类一套，列定义 `模块｜页面目的｜必需数据字段｜证据件｜可变生产变量｜质检断言`；**只复用机制、结构、数据字段、验证标准，不得复制竞对文字、视觉、评论素材**；契约到手即可生产，不需再看竞对页面。**辅助六问**（加分项）：Q4 增长触发点（动作+剂量+见效周期）｜Q5 AI 引用份额｜Q6 定价锚｜Q7 评论/信任体系｜Q8 产品矩阵拆法（pSEO 乘法逻辑）｜Q9 战略克制清单。

- **②发现参数**：`serp_analysis limit=20-50`，统一 `locId=2840`/en/desktop、记录查询日期、按注册域名去重（同集团多域名保留主站+备注）、品牌词 SERP 不作竞对来源。三类词族：品类词 3-5（{产品} replacement/custom）＋**工具/计价词 5-10**（calculator/instant quote）＋场景长尾 2-3；过滤大平台/OEM 官网/目录站/聚合页。**冻结双阈值**：≥20-30 家即冻结；不足 20 家继续加词族/渠道（SaaS Referral 榜反推），连续两轮新增 <2 家即冻结并记录原因（细分市场竞对天然少≠失败）。**真实竞对定义**（四条全满足才进名单）：相同客户群｜产品/服务高度替代｜目标市场实际成交｜至少 1 个相关非品牌词进 SERP 前 100；排除：纯媒体/目录站/平台聚合页/OEM 供应商官网。**种子站拓展**（词族饱和度不足时触发）：3 个业务方向不同种子站→Ubs `competitors` 拓展→三级清洗（相关性阈值+预估自然流量>100+商业模式三问）；原始域名数≠竞对数
- **③成交方式验证参数**：三问=谁能买/买什么/怎么成交；SERP 计价词族命中+webReader 实抓确认交互，**禁止凭首页定类型**。价格可见性判据（=§4 纪律 7）：在售价=数字与商品绑定+能选规格+能加购；仅展示数字=标价展示；纯 RFQ≠在线计价；专业渠道口径="普通消费者无购买资格"非"无价格"；跨性质不算平均价；不过门槛=REJECTED 不进名单
- **⑤sitemap 参数**：降级链 ①`robots.txt` 全部 `Sitemap:` 声明→②常见路径探测（`/sitemap.xml` `/sitemap_index.xml` `/wp-sitemap.xml` 等）→③内页页脚找链接→④全失败标"无 sitemap"，仅目录推断+抽样（不产出 URL 底册）；工具=`02-自动化工具库/12-sitemap定位器/`。URL 口径：去重后 HTML 页面；排除 image:loc/视频/新闻/附件/参数 URL；多语言按独立页统计标语言维度；lastmod 缺失不剔除
- **状态码+失败分支**：流程状态（四选一）READY=输入完整可继续｜PARTIAL=数据不完整允许降级并标注缺口｜BLOCKED=关键数据缺失禁输出强结论｜REJECTED=非真实竞对不进名单留档原因；证据状态（与流程状态正交）=关键结论最高证据等级观察级｜推断级｜验证级。失败分支一行一场景：sitemap 读不到→降级链走完仍无→仅目录推断+抽查（PARTIAL）｜Ubsuggest 无数据→按 §9 备用列分流，有备用切 DataForSEO、无备用仅记录缺口禁跨源拼接对比（PARTIAL/BLOCKED）｜top pages 有效数据 <10→不做流量排序结论，侧重意图与内容类型分析（月访<5K 家豁免属正常分支，记"不适用"）｜JS 动态渲染→Playwright 限定 §9 场景｜无公开价格→按标价展示口径记录｜只有品牌词有排名→品牌护城河定性，学习对象降级｜无非品牌词进前 100→REJECTED 候选｜页面被多词族重复承接→变体归并口径（§4 纪律 5）

## 2. 产出标准
**落点目录制**：每竞对一夹 `竞品研究/竞品站点/{domain}/`，夹内唯一长期文件=`{domain}-深档.md`——结构见《竞品深度拆解模板》v6.0（九节）；按必需字段完整度验收，不以行数作完成标准（普通竞对以基础版字段为准，深研对象以 Q1-Q3 完整度为准）；深档=竞对事实层不承载我方状态，我方承接一律=G 号指针指向 02 号。
**数据分层+批次治理**：raw/json（sitemap/四查/DFS 词表/blog_split）=中间产物，深档提炼/回填完成后即删（铁律 3，删前确认数值已入档）；单竞对专项分析一次性并入深档对应节不留独立文档；跨竞对聚合分析落横向分析层（见下表）；深档以"数据源+日期"记已清除 raw 的查询留痕。竞品研究根目录结构=**规格层+横向分析层+归档层**：根目录只留现行建站规格（模板/布局/视觉规格）+00-总览.html，决策真源与聚合分析在 `横向分析/`；批次工作文档（方案/审计/对照/盘点类）批次完毕且结论被真源吸收后 3 日内处置——同批同主题合订一册（原件删）或移 `归档/`，处置前 diff 补遗（开放待办与数字级信息先补入下游真源），处置后引用链修复（合订本保留原编号原节号）。
**两层文档架构**（单家深档=纵向采集层，跨家聚合=横向分析层，两层不混）：

| 层 | 载体 | 职责 |
|---|---|---|
| **纵向采集层** | 单家深档（`竞品站点/{domain}/`） | 该家事实的采集与登记：§1.1 进入词/§4.1 Top 页/§7 IA/§8 博客——**只记竞对事实+我方承接指针列**（不展开分析，不承载我方状态） |
| **横向分析层** | 五维横向真源 `竞品研究/横向分析/`（集中去重+集中判承接） | ①**词与页承接**（§1.1+§4.1+§5 全部词/页跨家汇入去重）→ **02 号** G 号表（全站词-页对账唯一真源；各家主词集中判承接，无承接 ≥1K 上浮 G 号——单家不各自判）②**页面模板**→ 09 号类目框架+05 号八轴框架 ③**IA/页型/pSEO**→ 26 号品类版图+归档/27 号（IA 批次定案已吸收进 25 号/categories.json，维持归档位）④**内容博客**→ 03 号 §7b 容器总表 ⑤**决策输出**→ 00 号对比总表+§七三清单矩阵（功能同类即归并不另设） |

**执行纪律**：深档产出的词/页/机制**不留档内等吸收**——当批汇入对应横向真源（承接列=接口，漏汇=未完成）；横向真源吸收时注明来源家与日期；四查收尾"top_pages 主词强制对照"（§6）为集中工序：全部在研家主词汇总去重后统一过承接（防同词多家重复判/漏判）。
**情报必需节**（缺一=分析未完成；节号=模板 v6.0 九节）：所有档案必填 §1/§2；普通竞对（基础版）加 §4 Q1 基础版+§9（§5/§6 以"不适用（基础版路径）"占位不算缺失）；深研对象加 §4 Q1 深研版+§5 Q2（G 号指针式）+§6 Q3（横向对比式）+§9；**§1.1 与 §4.1 的"我方承接"列为必填**（无承接新词当场上浮 02 号）；REJECTED 档案=仅 §1/§2+排除原因。
**迁移档规则**：raw 可复核的数值一律以 raw 为准（v4 判读不可照搬）；原判定不合规降推断级并标注"迁移降级"；v4 八节映射：IA/页型/pSEO→§7、归因→§3 趋势行、三清单→§9、特有情报→§0+§9；档案头字段：域名/平台/URL 总数/流量（月访｜有机词｜DA｜24 月趋势｜top 词归属）/外链强度（DR 辅助粗筛，不与流量/词数横向等价）/活跃度；删旧档前 diff 补遗进迁移验收。
**三清单**（落模板 §9）：可复用机制/可超越缺口/风险与反例，有充分证据时各列 2-3 条；**证据不足允许少于 2 条并写"证据不足"，不得凑数**（可复用机制仅收验证级）；每条用证据块绑定 ≥1 可复核证据，无证据只列"待验证"不入清单。
**另产**：`横向分析/00-对比总表.md`（全竞对：域名/平台/URL 数/pSEO/页型/SERP/流量，同源工具出齐才可比；**附录 C=跨家可抄动作**）+《竞对决策级发现总汇》（随深档出初版、四查后回填定稿）：行业格局判断（5-8 条，**必含流量集中度**=同商业模式子集前 10/20 家流量占比）｜分战场发现｜决策溯源表｜空白与机会（含差评断层清单）｜档案索引。**特殊价值竞对追加**：同模式者（同供应链/同打法）加"模式级深研"七维度（品类定价/配置维度全集/信任构建/物流/冷启动/技术栈证据链），产出"它已解决而我方空白的能力清单"。**UI/导航增强层（触发式）**：主对标站（2-3 家）或出现可复用交互资产（mega menu/Finder/配置器）时触发：①header/mega 导航提取（=内链权重分发结构）②色板/字体快扫（curl 一次 CSS）③交互资产截图；落点=横向分析层（导航对照归 27 号 IA 批次归档/25 号 Header 规格项目层）；反爬带浏览器 UA。

## 3. slug 三维度
路径结构（URL 目录层级）→信息架构 IA｜命名模式（slug 命名规律）→pSEO 引擎 DNA｜页型分布（url_count 占比）→战略重心（产品/内容/pSEO/本地驱动）。
模式对照（**非封闭枚举**，无法归类即新增并记样本+数量）：`/{属性A}-{属性B}-{核心词}/`=双属性映射｜`/{规格}/{规格}/`=笛卡尔积｜`{实体}-for-{场景}`=场景导航｜`{实体}-vs-{实体}`=对比页｜`{实体}-alternatives`=替代页｜`{地区}/{核心词}`=地理 pSEO。**流量修正**：吃流量最多的页型≠页数最多的页型时，战略重心以流量数据为准。

## 4. 执行纪律
①页型级不是目录级；**工具页（calculator/quiz/converter/finder）单独归类**——漏扫=漏一条产品线 ②工具/成交判定不能只看 sitemap：SERP 计价词族命中+webReader 实抓确认交互 ③一词实测≠词群结论：页型级 SERP 意图/竞争结论需 8-16 词实测支撑；不要求每站每页型执行，词样本不足标 PARTIAL ④AI 抗性分页型统计（单值静态映射词 vs 多值决策词命运不同）⑤跨词变体意图归并（变体各自全量 vol 虚高 10-20 倍）⑥平台识别看源码（generator meta/静态资源域），XML 转义与 image:loc 兼容提取 ⑦页面有数字≠产品价格：判据同步骤③；跨性质不算平均价 ⑧B2B 计算器可剥离 DOM 留存逻辑本地重放（成本结构外泄情报），遇则采 ⑨内容驱动站主题与购买意图零交集=反例非学习对象；学习对象看词族集中度。
**页型判定树**（按序匹配，命中即归类；全不中→"待复核"不得强行归类）：①交互输入/计算/筛选输出→工具页 ②购物车/规格选择/成交路径→产品页 ③流式日期发布→blog post ④固定导航/服务说明→静态 page ⑤标签/作者/分页/筛选集合→归档技术页（不计内容统计）。产品页二分：**真 SEO 页**（对应词有排名支撑）vs **SKU 长尾堆砌**（无排名无流量）——供给量大≠有效页多。
**内容质量抽查固定样本**（每站 3-5 页）：top 流量产品/类目页 1｜top 流量文章页 1｜典型 pSEO 页 1｜工具/配置页 1（如有）｜转化路径页 1（如有）。检查项：搜索承接（主词/意图/SERP 类型）｜页面结构（H1H2/模块顺序/FAQ）｜商业承接（CTA/价格/加购/询价）｜证据（评论/规格/案例/认证）｜技术（schema/canonical/索引风险）｜差异化独特资产｜生产难度。

## 5b. 竞对差评 VOC（触发式，横向工序）
- **触发**：主对标站定档后（普通竞对不做）。**三空态禁混写**：未触发｜触发未采样（分析欠账）｜触发平台缺（平台不存在/无样本，如实记录）
- **采样**：每平台（Amazon/Trustpilot/站内）1-3 星差评 50-100 条；不足按可得样本执行并记录，**不得凑样本混其他来源**；样本不足只降信号强度不阻塞主分析；每条只计一个一级问题，跨平台去重，排除物流/客服投诉。采样字段：平台｜日期｜星级｜一级问题｜多标签｜与页面承诺对应｜我方可控程度｜是否进验证标准
- **断层对照**：页面主承诺 ↔ 差评高频问题——承诺集中+差评集中=差异化机会+验证标准来源；断层清单进总汇§空白与机会，每条走五步翻译（原话→具体问题→购买风险→产品标准→页面证据）落三张表（§10 步骤 5）；输出=问题**信号强度**非发生率，不做品牌质量排名
- **横向处理口径**：VOC 采样与断层分析汇入项目层三张表（购买风险/产品验证标准/页面证据需求），单家深档不承载

## 6. 词池承接对账（四查收尾=横向集中工序：全池在研家主词集中去重统一判承接——§2 两层架构的执行位）
**两轨分流（不许混淆）**：Transactional/Commercial 词（custom X/X replacement）→ 唯一承接=**page**｜Informational 词（how to/what/cost）→ 唯一承接=**post**。对账表：词族 ×「商业词量｜page 承接｜信息词量｜post 承接」逐行 ✅/❌。词池=四查词级+`keyword_suggestions` 自查（每批 3 种子）；**四查词级只是来源之一且必须过漏斗——竞对视野锁死与目录行为词风险见深研SOP §〇 来源盲区表**。
**缺口判定**（词族口径：变体归并去重、排除品牌词、统一 locId=2840）：缺页=商业词族有效月量 **≥1,000** 且无 page｜缺文=信息词族 **≥500** 且无 post｜优先级 **P1 ≥3,000｜P2 1,000-2,999｜P3 <1,000**｜同档平局用 `estimate_serp_clicks` 打破（词量+可争位次+SERP 特征→预估点击，纯本地计算不耗日额）——位次取实测 3-10 位（我方可争位），AI Overview/featured snippet 占位词族点击打折；缺口编 G 号（词族+实测词量+竞对实证+建议 URL+优先级）。
**纪律**：落 `04-内容生产/品类页覆盖盘点.md`；先登记再建页；季节词提前 6 个月建页；并入优先于新页；大规模四查后重跑；**竞对 top_pages 主词强制过承接对照**——四查收尾时每页主词逐词过"我方有无页"，无承接进 G 号评估。

## 8. 流量拐点归因（上升/下降双向）
**触发**（不限档位）：24 月趋势 3 个月内 ±40%，或连续两月同向 >25%；或季度复查锚定名单异动（**锚定名单每季度重跑 overview 一轮**——竞研从项目制变持续情报资产）。
**六步**（一步一行）：0 剥离季节性——品类季节先验+两年同月对比，同月同形态=季节型误报剔除→1 定位拐点月——domainTraffic 月度序列，拐点 ±1 月→2 算法更新对齐——Google Search Status Dashboard 主源，窗口 ±2 周=算法相关型（仅相关性证据非确定因果）→3 关键词分层变化——**前置=已有季度词级快照**，无快照标"部分归因（无词级历史）"禁输出词级变化；有则四层（top3/4-10/11-50/51-100）对比：分层下移=排名滑坡｜词数骤降=掉出前 100｜top 稳 mid 崩=中腰部失守→4 页面级定位——崩首页=站点级｜崩某类页=板块级｜散点=正常波动→5 反链增减性质——丢 spam>50=疑似良性排毒（结合自然链+目标页流量复核定性）；丢自然链+gained 归零=外链流失型→6 归因结论——类型枚举：算法相关｜板块崩塌｜外链流失｜竞争抢位｜季节（误报）｜品牌损毁。
**输出口径**（独立归因卡不设）：归因结论=**深档 §3 趋势行 1-2 句**（趋势定性+拐点+归因类型）；跨家可抄动作（**动作+剂量+见效周期**三项齐全才算一条）归 **00 号对比总表附录 C**。
**动作还原五源**（触发站必做，全部不读正文）：①lastmod 月度分桶（按页型聚合）→动作日历 ②`backlinks(order_by=first_seen)` 月度分桶→外链动作窗口 ③Wayback 快照（拐点前后各 1 张）→结构动作 ④`domain_top_pages` 类型分布→增长引擎定性 ⑤sitemap 季度重抓 diff→扩张/收缩实锤。**节奏三律**：①lastmod 分桶只是线索非结论 ②publishedTime 抽样 ≥3 篇门槛 ③字段冲突找第三锚点（图源 CDN 时间戳/hub 页 lastmod）。五源动作行 × 24 月流量行上下对齐，标注"动作先于拐点 N 月"=因果链；上升站因果链进"可复用机制"，下降站进"风险与反例"+我方抢位机会；时滞按站按页型实测（3-6 月为先验非定值）；lastmod 缺失站降级 Wayback+外链双源。
**数据缺口+DR 口径**：Ubsuggest 无词级历史——词级丢失清单用 DFS Labs `ranked_keywords` 季度快照自建 diff；DR 用 Ahrefs 免费接口 `curl -H "Authorization: Bearer $AHREFS_API_KEY" "https://api.ahrefs.com/v3/public/domain-rating-free?target={domain}"`（key 在 `.env`；免费不耗 units；**仅辅助粗筛**——可被 301/灌外链操纵，不判竞品质量/流量真实性，不与 DA/流量/词数横向等价；档案记录抓取日期）。

## 10. 本地生产契约（C 端落地）
研究产物先本地文件化，建站（WP+Woo，竞品 Shopify 不跟随）最后导入：**page 走 HTML→Elementor 流水线（禁 REST 塞整页 HTML）；post 走 MD→Gutenberg**；REST 只写元数据/媒体/状态/分类；schema 由 Woo+RankMath 自动生成。**布局层总原则**：Woo 只提供**数据层**渲染（产品网格/价格/加购/变体），**布局层一律由 Elementor Theme Builder 模板接管**——类目页、产品页各挂模板（产品页布局壳=图集/卖点/规格/FAQ/关联区，单品数据 Woo 渲染）；不存在"纯 Woo 默认渲染"页型，"不逐页产 HTML"=模板+结构化数据灌装。**页面类型 × 生产物 × 设计依据矩阵**（每层开产前先核对本行依据是否齐，缺哪个先补哪个）：

| 页面类型 | 生产物 | 设计依据 | 前置依赖 |
|---------|--------|---------|---------|
| 类目页 | 文案包 JSON+Ele 类目模板规格 | 词池对账粗判+类目页轴级深研（[SERP深研SOP](关键词调研与SERP深研SOP.md) §六两级复用，不逐词全流程） | 模板规格+视觉 tokens+**树 term parent 映射**（一级/二级明细+逐页归属——IA 定案必须落到 term 层颗粒度，只定"树一级+URL"=装机数据缺口）。**term 树两层封顶**（一级形态+二级品种/场景，竞品 8/8 单层扁平实证；URL 嵌套≠term 层级；确需三级须显式定案+给竞品实证） |
| 产品页 | Ele single product 模板规格（**壳先行，SKU 后灌**两段式） | SKU 规划+竞对产品页拆解+自家先例站参照 | 模板规格（SKU 未定不阻塞壳） |
| 静态页/首页 | **独立 HTML→Elementor 流水线**+布局规格 | 转化组件清单+竞对同位页模块拆解——**不走 SERP 深研**（非搜索承接页，流量来自站内导航） | 布局规格+视觉 tokens |
| 工具页 | 独立 HTML（交互内嵌）+布局规格 | **工具词 SERP 实判**（SERP深研SOP §四工具词侧重项）+对标工具页拆解 | 词层实判+布局规格 |
| post | MD→Gutenberg | SERP 深研档案（内容SOP §1.1 准入） | 深研档案（Brief 七门槛） |
| 模板/视觉层 | design tokens 定案（色板/字体/按钮/间距） | 竞品 CSS 快扫（§2 UI/导航增强层）——**建站启动前锁定，触发式工序升级为前置依赖** | 视觉规范文档 |

**六步产物**：①url-map 全站 URL 底册/nav IA→`站点结构/` ②词池/实体 JSON（页面生成真源）→`数据/` ③视觉 tokens+四类页布局规格（矩阵前四行依据）→竞研根目录 ④博客 MD（front matter+四层矩阵，H1 一次，每篇 ≥1 产品页内链；词量 how-to 2000+/gift 1800+/科普 1500+）→`文章/` ⑤VOC 三张表（购买风险表/产品验证标准表/页面证据需求表；顺序：风险→标准→证据；未过验证的承诺不进页面文案）→项目目录 ⑥建站（最后）：WP 装机→Ele 模板（Theme Builder）→HTML/MD 导入→REST 写 TKD/元数据→Rank Math——**TKD/robots 三断言**：title 与 slug 解耦（slug 规范名、title 按搜索词面写）｜FAQPage schema 单列进建站清单｜robots 白名单放行 Pinterestbot（限速反面=自断图片传播）。
生产纪律：数据驱动（JSON 底座每页文字差异化）｜事实零错（数据/价格逐项核对）｜agent 分工防冲突（独立目录）｜建站前全量本地质检，线上验证一次。

## 11. 页签式作战手册
竞研收尾产**单文件 HTML 作战手册**（`竞品研究/00-总览.html`）=md 数据层的作战视图；生成时机：词池对账（§6）+选题转化（§5）+总汇定稿三工序齐后生成 v1，每批次深档回填总汇后再生成，建站启动时锁定快照版+版本戳。**页签（12 张）**：①竞对全景（平台/URL 数/pSEO 引擎+流量集中度）②决策发现+决策溯源表 ③IA 蓝图（page/post 标注+内链权重注记）④页面规划与数量 ⑤内容体系 ⑥pSEO slug 模板库（验证级）⑦词池底册（G 号完整表+Tier 分层+季节窗口）⑧转化与信任层 ⑨生产契约 ⑩待办与数据缺口 ⑪建站节奏（死线倒排+质检断言+时滞基准）⑫页面级 GO/NO-GO 汇总（跨竞对 GO-P0/P1 页面池+模板骨架索引）。
**数据注入纪律**：md 为唯一真源，HTML 由脚本从 md 生成 rows JSON 内嵌禁手写数字｜清单类页签**完整表注入禁摘要化**｜每数字可溯源到 md+数据日期，md 与 HTML 冲突以 md 为准，HTML 不得呈现未落 md 的结论；头部带生成时间+数据截止批次戳。**总览=单页锚点章节制速览手册**（80-150KB）：章节按主题跨文档重组，每章=结论清单+核心决策表截取+"全文见 xx.md"注；交互原型类默认**折叠嵌入**（防 iframe/sticky 遮挡正文）；横向分析层新文档产出同步融入总览对应章，批次文档处置后刷新；深档不进总览；总览为摘要层非真源，编辑永远改 md 后重产。
**注入度双向+用户视角验收**：①**决策级内容完整注入禁摘要化**——结论/定案/数字/判定档不得省 ②**全文镜像禁入**——源文档全文/全量大矩阵/过程叙述不进总览，密度锚=一屏到两屏/章；验收=模拟"用户第一次打开"过一遍——首屏可读/导航目标可达不被遮挡/单章滚动 1-2 屏/重型嵌入默认收起，四项过才算完成（断言全绿≠可用）。
