## 0. 铁律（每轮执行前过一遍）

1. **真实 SERP 驱动**：竞对发现/意图实判只用 Ubersuggest `serp_analysis`（主）/DataForSEO（备），**禁 web_search_prime/WebSearch**（通用搜索对 B2B 极不准，塔罗翻车实证）。工具主次全表见 §9
2. **发现即全量深档**：每个真实竞对都值得深研，不按主观"对标价值"筛选（筛选=信息损失）
3. **sitemap 全量不抽样**；raw json 永久留档研究目录（非 tmp），重抓≠原数据
4. **全量核实不凭印象**："几家有博客"类范围判断必须 Python 扫全量 sitemap
5. **敏感词脚本层过滤**（防 agent 会话被杀）：研究文档只计数不落词面；过滤规则版本+过滤数量+时间落 `过滤日志.txt` 随数据留档（可审计不泄词面）
6. **研究→生产闭环**：每个结论必须指向生产侧对应物（模板/排产/质检断言）
7. **需求范围纪律**：改 X 只动 X，顺手发现只报不动

## 1. 七步主流程

| # | 步骤 | 要点与参数 | 完成标准 |
|---|------|-----------|---------|
| 1 | **SERP 发现竞对** | `serp_analysis limit=20-50`，**统一口径**：`locId=2840`/en/desktop、记录查询日期、按注册域名去重（同集团多域名保留主站+备注关联）、品牌词 SERP 不作竞对来源。至少**三类词族**：①品类词 3-5（{产品} replacement/custom）②**工具/计价词 5-10**（calculator/instant quote/quote online——工具型玩家只从计价词浮出，靠垫漏 8 家教训）③场景/长尾 2-3。过滤大平台/OEM 官网/目录站/聚合页 | **数量+饱和度双阈值冻结**：≥20-30 家即冻结；不足 20 家→继续加词族/渠道（SaaS Referral 榜反推），**连续两轮新增带来的合格竞对 <2 家**即冻结，记录不足原因（细分市场竞对天然少≠失败） |
| 2 | 定位 sitemap | **降级链**：①读 `robots.txt` 全部 `Sitemap:` 声明 →②无声明或明显不全→常见路径探测（`/sitemap.xml` `/sitemap_index.xml` `/wp-sitemap.xml` 等）→③仍无→内页页脚找 sitemap 链接→④全失败标"无 sitemap"降级处理（仅目录推断+抽样，不产出 URL 底册）。工具=`02-自动化工具库/12-sitemap定位器/`（自动走完 ①②+递归提取） | 每家记录发现方法（robots/探测/内页/失败） |

| 4 | slug 三维度分析 | 机器算分布，LLM 只看统计判读（全部 URL 不进 context） | 见 §3 |
| 5 | 产出深档 | 每家独立文档 | 见 §2 |
| 6 | 博客矩阵→选题 | 对所有含博客竞品（Python 核实） | 见 §5 |
| 7 | Ubersuggest 四查 | 每竞对必做，两段式 | 见 §7 |

**真实竞对定义**（须全部满足才进名单）：面向相同客户群｜相同或高度替代的产品/服务｜在目标市场实际成交｜至少 1 个相关非品牌词进 SERP 前 100。排除：纯媒体/目录站/平台聚合页/OEM 供应商官网。

**发现补充通道·种子站拓展**（词族 SERP 饱和度不足时触发；阿木②）：选 3 个业务方向不同的种子站 → Ubersuggest `competitors` 沿关键词重合拓展候选域名 → 三级清洗后入库：①相关性阈值剔除弱相关 ②预估自然流量>100 ③逐站商业模式分类（§4 纪律 2 三问）。原始域名数≠竞对数。

## 2. 产出标准

**每竞对 1 份深档**（`竞品研究/竞品站点/{domain}.md`，300-500 行，八节缺一即未完成）：

| 节 | 内容 |
|---|------|
| 1 档案头 | 域名/平台/URL 总数（按 §1 步骤 3 口径）/流量（月访 X｜有机词 Y｜DA Z｜24月趋势｜top 词归属）/外链强度（**辅助粗筛**：DR(Ahrefs) W——不与流量/词数横向等价，不判质量规模）/活跃度 |
| 2 信息架构 IA | 目录层级树+顶级导航推断 |
| 3 pSEO 引擎 | 核心 slug 模式+维度组合 DNA+代表 URL 10 条 |
| 4 页型分布 | **页型级**统一口径（产品/类目/blog post/静态 page/工具页/教程页；判定树见 §4）；区分真 SEO 页 vs SKU 长尾 vs tag 归档；无法判定的入"待复核"不强行归类 |
| 5 page vs post 判定 | 固定层级页 vs 流式内容 → 自建 WP 架构映射 |
| 6 更新重心 | lastmod 月度分布→近期动作 |
| 7 特有情报 | 该竞对独有结构资产/模式（每家定制，非模板填充） |
| 8 三清单 | **可抄/可超/须避**各 2-3 条，**每条绑定 ≥1 可复核证据**（URL 数/关键词数/估算流量/排名/SERP 结果/实测行为，附数据日期）；无证据只列"待验证"不入三清单 |

**另产**：`00-对比总表.md`（全竞对：域名/平台/URL 数/pSEO/页型/SERP/流量，同源工具出齐才可比）+ **《竞对决策级发现总汇》**（随深档出初版、四查后回填定稿）：
- §行业格局判断（5-8 条决策级发现+支撑档案+我方对应决策；**必含流量集中度**：同商业模式子集前 10/前 20 家占子集预估流量 %，高=头部垄断切入难，低=分散可分食）｜§分战场发现（流量/产品/内容）｜**§决策溯源表（我方每个战略决策←支撑它的竞对发现，复盘复用载体）**｜§空白与机会（含差评断层清单，见 §5b）｜§档案索引

**完整范式**：研究层（深档）→ 综合决策层（总汇+溯源）→ 战略层（内容策略+网站结构）→ 执行层三工序（①网站规划 URL 底册 → ②页面内容规划 → ③文章生产，有依赖顺序）。

**特殊价值竞对追加**：与己方同模式者（同供应链/同打法）加"模式级深研"七维度（品类定价/配置维度全集/信任构建/物流/冷启动/技术栈证据链），产出"它已解决而我方空白的能力清单"。

**UI/导航增强层（2026-09-04 新增，触发式非必选）**：UI 不进八节主干（全量抓 DOM/截图成本上一个数量级，稀释 slug 层主干），但对**主对标站（2-3 家）或出现可抄交互资产时**（mega menu/Finder/配置器）触发：①header/mega 导航结构提取——本质是**内链权重分发结构=SEO 情报**（滤网项目实证：allfilters mega 的 By Brand 列即品牌 hub 首屏曝光位、"首列放自家品牌"对应平替定位，见 `12-滤网垂直站项目/02-pSEO架构/09-Header导航对比-allfilters.md`）②色板/字体快扫（curl 一次 CSS 提取，验证品牌视觉差异化）③交互资产截图留档。落点=深档"特有情报"节，不新增第九节；反爬带浏览器 UA。

## 3. slug 三维度（方法论核心）

URL 分析的三个**视角**（分布是统计结果，非 URL 自身属性）：

| 视角 | 看什么 | 得出什么 |
|------|--------|---------|
| 路径结构 | URL 目录层级 | 信息架构 IA |
| 命名模式 | slug 命名规律 | pSEO 引擎 DNA |
| 页型分布 | 页型 url_count 占比 | 战略重心（产品/内容/pSEO/本地驱动） |

模式对照（**常见模式非封闭枚举**——发现无法归类的模式即新增模式并记录样本+数量，如 品牌×品类/地区×服务/兼容型号/多语言路径）：`/{属性A}-{属性B}-{核心词}/`=双属性映射｜`/{规格}/{规格}/`=笛卡尔积｜`{实体}-for-{场景}`=场景导航｜`{实体}-vs-{实体}`=对比页｜`{实体}-alternatives`=替代页｜`{地区}/{核心词}`=地理 pSEO

**流量修正**：吃流量最多的页型 ≠ 页数最多的页型时，战略重心以流量数据为准（slug 分布只是供给面）。

## 4. 执行纪律（判读口径）

| # | 纪律 |
|---|------|
| 1 | 页型级不是目录级；**工具页（calculator/quiz/converter/finder…）单独归类**——漏扫=漏一条产品线 |
| 2 | **工具/成交判定不能只看 sitemap**：SERP 计价词族命中 + webReader 实抓确认交互（纯 RFQ 询盘不算在线计价）；成交方式过 1D 三问（谁能买/买什么/怎么成交），禁止凭首页定类型（阿木 186→179 家教训） |
| 3 | 一词实测≠词群结论：每页型 8-16 词 SERP 实测再下结论 |
| 4 | AI 抗性分页型统计（单值静态映射词 vs 多值决策词命运不同） |
| 5 | 跨词变体意图归并（变体各自全量 vol 虚高 10-20 倍） |
| 6 | 平台识别看源码（generator meta/静态资源域），XML 转义与 image:loc 兼容提取 |
| 7 | **页面有数字≠产品价格**：在售价判据=数字与商品绑定+能选规格+能加购物车；仅展示数字=标价展示；RFQ 表单=非在线计价；专业渠道口径="普通消费者无购买资格"非"无价格"；跨性质不算平均价 |
| 8 | B2B 计算器可剥离 DOM 留存逻辑本地重放（成本结构外泄情报），遇则采 |
| 9 | 内容驱动站若主题与购买意图零交集=反例非学习对象；学习对象看词族集中度 |

**页型判定树**（按序匹配，命中即归类；全不中→"待复核"不得强行归类）：
①有交互输入/计算/筛选输出 → 工具页 ②有购物车/规格选择/成交路径 → 产品页 ③流式日期发布体系 → blog post ④固定导航/服务说明 → 静态 page ⑤仅标签/作者/分页/筛选集合 → 归档技术页（不计入内容页统计）

## 5. 博客矩阵 → 选题转化

适用=全部含博客竞品（`/blog|/learning-center|/news|/resources|/articles` Python 全量扫）：
1. 每家拆 `{domain}_blog_split.json` 落 `站点sitemap数据/`
2. 统一主题轴聚类（测量教程/选购对比/材质/养护/DIY/品牌替换/行业应用/其他）。分类默认基于 slug+标题，**每篇只归一个主主题**；标题无法判断的标"待人工复核"
3. 主题×竞对篇数矩阵："多家有但量少"=可超越，"零覆盖"=空白
4. 对位自己 `posts/` 标三档（已覆盖/竞有我无/全空白）；**进 P0/P1 的选题过 SERP 框架复核后方可排产**（复核=该选题头部词 `serp_analysis` 取前 10 名文章页逐篇拆结构——≥6/10 共性段落才进必选元素、字数取 P25-P75、头部 10 篇共同缺口=真差异化点；2-3 篇主观抽样不足以定框架，2026-09-21 用户定调）
5. 产出 20-30 个 slug 级选题 → `01-博客主题矩阵与选题转化.md`
- **"其他">30% 须二次细分**（按标题词频聚类拆分）；**≥3 家覆盖=需求实证 P0**，1-2 家=P1，零覆盖=P2 自证需求

## 5b. 竞对差评 VOC：承诺↔差评断层（触发式）

> 触发：主对标站（§2 UI 层同口径 2-3 家）定档后，普通竞对不做。用途：供给侧分析之外的唯一用户侧信息源。

1. **采样**：主对标站 Amazon / Trustpilot / 站内 1-3 星差评各 50-100 条
2. **归类**：每条只记一个一级问题（加总=样本数，防重复计数），明细留多标签；排除物流/客服投诉
3. **断层对照**：竞对页面主承诺 ↔ 差评高频问题一一对应——承诺集中+差评集中=需求未被稳定满足=我方差异化机会+验证标准来源
4. **产出**：断层清单进总汇§空白与机会；每条走五步翻译（原话→具体问题→购买风险→产品标准→页面证据）落三张表（§10 步骤 5）

**纪律**：差评=已购者失望，不解释未购者转化率；不做品牌质量排名；差评占比≠市场投诉率。

## 6. 词池承接对账（四查收尾工序）

> 原则会漏，对账表不会（sofa 漏洞：17 页批次漏 sofa 8.1K+patio 8-10 万词池）。

**两轨分流（不许混淆）**：
- Transactional/Commercial 词（custom X / X replacement）→ 唯一承接=**page**，文章互哺不算
- Informational 词（how to/what/cost）→ 唯一承接=**post**

**对账表**：词族 ×「商业词量｜page 承接｜信息词量｜post 承接」逐行 ✅/❌。词池=四查词级+keyword_suggestions 自查（每批 3 种子）；**逐词判定先过《关键词调研与搜索意图判定手册》三判**，输出直接填表。

**缺口判定**（词族口径：变体归并后去重、排除品牌词、统一 locId=2840）：
- **缺页**：商业词族有效月搜索量 **≥1,000** 且无 page
- **缺文**：信息词族有效月搜索量 **≥500** 且无 post
- 优先级：**P1 ≥3,000｜P2 1,000-2,999｜P3 <1,000**；**同档内排序用 `estimate_serp_clicks`**（词量+可争位次+SERP 特征→预估点击，纯本地计算不耗日额）打破词量平局——输入位次取 `serp_analysis` 实测 3-10 位区间（我方可争位），AI Overview/featured snippet 占位词族有效点击打折；缺口编 G 号（词族+实测词量+竞对实证+建议 URL+优先级）

**纪律**：落 `04-内容生产/品类页覆盖盘点.md`；先登记再建页；季节词标旺季窗口（提前 6 个月建页）；并入优先于新页；每次大规模四查后重跑。

## 7. 四查（Ubersuggest MCP，每竞对必做）

> slug 分析=供给侧推断；四查=需求侧验证。单看 sitemap 知道"有什么"，交叉才知道"什么有效"。

**两段式**（默认）：
- ① `domain_overview` **随发现批次前置**（每批 <15 家）：摘要 3-5 行（月访/词数/DA/DR/趋势定性/top3 词）写入深档 brief——**"增长站/衰退站"定性决定该站被当学习对象还是反面样本写**；查完立即落盘
- ② `domain_keywords(limit=10)` + `domain_top_pages(limit=10, 月访>5K 的家)` **深档完成后置**：验证 pSEO 引擎推断与页面级兑现；判读有变补"判读修正行"
- ③ `backlink_opportunity` 建站后独立工序（需己方域名作 negative_target）

| 序 | 工具 | 全做？ | 看什么 |
|---|------|-------|--------|
| 1 | `domain_overview` | ✅ | 规模分级+24 月趋势+自带 top50 词排名 |
| 2 | `domain_keywords` | ✅ | **search_intent 标注**（Transactional/Informational 分布）+词级确认（limit=10 小查做判读；全量导出=可选工序见下） |
| 3 | `domain_top_pages` | 月访>5K 家 | **词层流量的页面级兑现**（词层 14K/页面层 138 的塌方只有此查暴露） |
| 4 | `backlink_opportunity` | 建站后 | 链竞对不链己方的 referring domains |
| 可选 | `domain_top_countries` / paid 字段 / `competitors` | B端/有付费信号/名单交叉时 | 国家布局｜投广告=需求验证｜竞对榜交叉 |

**可选追加工序：主对标站全量词表导出**（v4.2，触发式非默认）：
- **触发**：主对标站（§2 UI 增强层同口径 2-3 家）或模式级深研对象定档后；普通竞对不导（全量词表 90% 是噪音，判读用 limit=10 足够）
- **操作**：`domain_keywords limit=50` + `previousKey` 翻页至取尽（organic，locId=2840 统一口径）；翻页属大查，与其它查询交错防限流（见下限流操作法）
- **用途**：①词池承接对账（§6）种子来源 ②品牌词/非品牌词流量占比精确计量（小查只看首部统计）③主对标词层→我方页面映射底册（每词绑竞对承接 URL）
- **落盘**：`_ubersuggest_domain_keywords_full_raw_{日期}.md`，随落盘契约；翻页次数+总词数记入深档档案头

**限流操作法**：403 无文案+auth 正常=短时限流等 60-180s（转做落盘不空等）；报错含 "daily reports limit"=日额尽当日停。**限流按 payload 加权**：全量 overview 连续 ~15 次触发，limit=10 小查 46 次零触发——大批量时大小查交错。150 次/天：29 家四查一轮 ≈75 次足够。**额度够就全量不抽样**。

**落盘契约**（查完即写）：①raw 留档 `_ubersuggest_*_raw_{日期}.md` ②深档档案头一行（见 §2）③总汇回填。

**交叉判读**：
- 有页面无排名=无效堆砌（抄结构别抄这个）｜slug 模式+对应词有排名=引擎已验证直接复用（=证据分级到"验证"级）
- 流量趋势陡降=衰退，切入窗口
- **词层流量≠页面层兑现**（keywords 大流量+top_pages 水位低=怪词噪音或衰退站，成色打折）
- **品牌词 vs 非品牌词结构**：domain_keywords 首部统计品牌词流量占比——高品牌占比=护城河难抢（学品牌建设）；纯非品牌=pSEO 引擎驱动可复制（正面学习对象）
- **社交传播力**：serp_analysis 条目自带 shares——同词同位传播力对比，高分享=有传播基因，进"可抄"清单候选证据

## 8. 流量拐点归因（上升/下降双向）

> 四查=横截面快照；归因=纵向因果链。**上升站=学习对象（什么引擎驱动增长），下降站=反面样本+切入窗口——双向都归因**。归因结论区分"观察到的相关"与"已验证的因果"。

**触发**：24 月趋势 3 个月内 ±40%，或连续两月同向 >25%；或季度复查锚定名单异动（**锚定名单每季度重跑 overview 一轮**，竞研从项目制变持续情报资产）。

| 步 | 动作 | 判读 |
|---|------|------|
| 0 | **剥离季节性**（防误判） | 品类季节先验+两年同月对比；同月同形态=季节型误报剔除 |
| 1 | 曲线定位拐点月 | domainTraffic 月度序列，拐点 ±1 月 |
| 2 | 算法更新对齐 | vs 核心更新窗口（**Google Search Status Dashboard 官方主源**，Moz 更新史 `moz.com/google-algorithm-change` 备）；窗口 ±2 周=**算法相关型**（仅相关性证据，非确定因果——除非补页面级证据） |
| 3 | 关键词分层变化 | **前置条件：已有季度词级快照**（快照契约：按季度保存 domain/关键词/排名/URL/流量估算/数据源，工具参考 `02-自动化工具库/08-DR榜雷达/`）。无快照→跳过本步，结论标"部分归因（无词级历史）"，禁输出词级分层月度变化。有快照→searchKw+四层（top3/4-10/11-50/51-100）对比：词数不变分层下移=排名滑坡｜searchKw 骤降=掉出前100（索引/惩罚级）｜topTier 稳 thirdTier 崩=中腰部失守（竞对抢位） |
| 4 | 页面级定位 | 崩首页=站点级｜崩某类页=板块级（博客被砍/pSEO 失效）｜散点=正常波动 |
| 5 | 反链增减性质 | lost/gained 的 spam_score：丢 spam>50=**疑似良性排毒**（须结合自然链变化+目标页流量复核后定性）；丢自然链+gained 归零=外链流失型 |
| 6 | 归因结论+双向动作 | 见下 |

**输出**：每家一张归因卡（拐点月/归因类型/证据/我方动作）回填档案头+总汇溯源行。归因类型枚举：算法相关｜板块崩塌｜外链流失｜竞争抢位｜季节（误报）｜品牌损毁

**动作还原工序**（触发命中的站必做——归因类型只回答"哪层变了"，动作还原回答"**它做了什么导致流量起/落**"；五源证据全部不读正文）：

| 证据源 | 看什么 | 得出 |
|---|---|---|
| lastmod 月度分桶（sitemap 自带，按页型聚合） | 哪个月批量建/更了哪类页、停更点 | 动作日历（建页潮/改版潮/停更） |
| `backlinks(order_by=first_seen)` 月度分桶 | gained 链接爆发窗口 | 外链动作（数字公关/被报道/可疑采购） |
| Wayback 快照（拐点月前后各 1 张对比） | 导航/板块/模板增删 | 结构动作（新板块上线/砍板块） |
| `domain_top_pages` 类型分布+集中度 | 头部流量靠哪类页吃 | 增长引擎定性（pSEO/内容/品牌/单品驱动） |
| sitemap 季度重抓 diff（随锚定名单积累） | URL 进出清单 | 扩张/收缩实锤 |

输出**动作时间线卡**：动作行（五源汇总）× 流量行（24 月曲线）上下对齐，标注"动作先于拐点 N 月"→ 引擎动作因果链（例：2025-03 起月铺 400 张 city 页→3 个月后流量 3×；2026-01 停更→当季 -40%）。
- 上升站：因果链进"可抄"清单（**动作+剂量+见效周期**三项齐全才算一条）；下降站：进"须避"清单+我方抢位机会（它丢的词层=我方内容窗口）
- 时滞按站按页型实测记录（3-6 月为经验先验非定值）；lastmod 缺失站降级用 Wayback+外链双源

**数据缺口**：Ubersuggest 无词级历史——需词级丢失清单时用 DFS Labs `ranked_keywords` 季度快照自建 diff（工具参考 `02-自动化工具库/08-DR榜雷达/`）。

**DR 口径**：`curl -H "Authorization: Bearer $AHREFS_API_KEY" "https://api.ahrefs.com/v3/public/domain-rating-free?target={domain}"` 或 `kd_rank.py {domain}`（key 在 `.env`；免费不耗 units；**DR 可被 301/灌外链操纵，仅辅助粗筛**——不判竞品质量/流量真实性/业务规模/学习优先级，不与 DA/流量/词数横向等价；自家站不配合 AhrefsBot 爬取，DR 仅用于竞对；Ahrefs 免费接口以当前官方文档为准，档案记录抓取日期）。

## 10. 本地生产契约（C 端落地）

**研究→内容与建站解耦**：全部产物先本地文件化，建站（WP+Woo，竞品 Shopify 不跟随）只是最后导入。**page 走 HTML→Elementor 流水线（禁 REST 塞整页 HTML）；post 走 MD→Gutenberg**；REST 仅用于元数据/媒体/状态/分类等结构化字段，不用于绕过页面构建器注入整页 HTML。**类目页例外（2026-09-22 用户定调）：Woo taxonomy 类目页不建 HTML 原型**——默认模板自动渲染产品网格/筛选/排序，类目页生产物=**文案包 JSON**（TKD/导语/页底 SEO 文案/FAQ/兄弟链/支柱文配对/证据件绑定→WP term+描述+RankMath meta 录入）；schema 由 Woo+RankMath 自动生成；HTML 原型仅用于静态 page 与后续定制模板（如定制 single product）。

| 步骤 | 产物 | 位置 |
|------|------|------|
| 1 站点结构 | url-map 全站 URL 底册/nav IA | `站点结构/` |
| 2 数据层 | 词池/实体 JSON（页面生成真源） | `数据/` |
| 3 pSEO 页面 | HTML（目录名=slug，全页原型，TKD+schema 齐全） | `页面原型/` |
| 4 博客文章 | MD（front matter+四层矩阵，H1 一次，每篇≥1 产品页内链；词量 how-to 2000+/gift 1800+/科普 1500+） | `文章/` |
| 5 VOC 三张表 | 购买风险表/产品验证标准表/页面证据需求表（§5b 断层→五步翻译产出；顺序：风险→标准→证据；未过验证的承诺不进页面文案） | 项目目录 |
| 6 建站（最后） | WP 装机→Elementor 流水线→REST 写 TKD/元数据→Rank Math | 服务器 |

**生产纪律**：数据驱动（JSON 生成底座每页文字差异化）｜事实零错（数据/价格逐项核对）｜agent 分工防冲突（独立目录）｜建站前全量本地质检，线上验证一次。

## 11. 呈现层规范：页签式作战手册（2026-09-21 新增，仿真花站 73 家深档实战沉淀）

竞研收尾产**单文件页签式 HTML 作战手册**（`竞品研究/00-总览.html`），定位=md 数据层的"作战视图"——竞对深档/词池对账/选题矩阵/总汇四类 md 是数据真源，HTML 是建站执行期的随手可查面板（竞对列表不承载建站答案，答案在 IA/页面规划/文章体系/slug 模板等执行层页签）。

**生成时机**：词池对账（§6）+选题转化（§5）+总汇定稿三工序齐后生成 v1；此后每批次深档回填总汇即再生成；建站启动时锁定快照版并加版本戳。

**标配页签（11 张）**：①竞对全景（含平台/URL 数/pSEO 引擎列+流量集中度统计）②决策发现（叙事卡片）+**决策溯源表**（§2 总汇必含项的执行级反向索引，须全量注入禁摘要化）③IA 蓝图（类目树带 page/post 标注+内链权重注记：导航位序=权重分发结构）④页面规划与数量（四层结构表+静态页清单）⑤内容体系（文章轴×结构模板×**字数分配**×代表选题；**选题清单完整表**注入禁卡片摘要化——27 选题压 3 卡片=G 号三行摘要同构错误，2026-09-21 实证）⑥pSEO slug 模板库（验证级模板表）⑦词池底册（G 号**完整表**+Tier 分层+季节窗口，禁三行摘要）⑧转化与信任层（定价带/样品政策/评论体系/批发类目页模板）⑨生产契约（§10 六步流程+Woo 结构决策卡）⑩待办与数据缺口（overview 待补/G 号候选未实测/深档待做——防"把快照当全集"）⑪建站节奏（死线倒排+质检断言清单+时滞基准）。

**数据注入纪律**：**md 为唯一真源，HTML 由脚本从 md 生成数据数组内嵌**（rows JSON），禁手写数字；每数字可溯源到 md 文档+数据日期；md 与 HTML 冲突以 md 为准；**HTML 不得呈现未落 md 的结论**。多文档计数不同步（如深档 73 家 vs 总汇表 41 行）是此纪律要根治的场景——呈现层生成前先对齐 md 计数。

**维护节奏**：随批次即时再生成；季度锚定复查（§8）后集中再生成；头部带生成时间+数据截止批次戳。
