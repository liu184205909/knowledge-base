# 竞品分析 SOP v5.0（情报生产执行版）

> 状态：执行版｜生效 2026-10-09｜替代 v4.3（v3.x 全史见 git）｜历史审核版 HTML 已删（git 历史可溯），不作执行规范
> 读者：主=Claude（执行竞研），次=人（审核产出）

**核心原则**：竞研必须回答三问——①他们的钱从哪来？②哪些页面值得我方进入？③进入采用什么页面机制？URL slug 本身即信息（主题/类型/层级/pSEO 引擎），足以推断架构+内容矩阵。**默认不批量读正文**，仅 4 类场景读页：①动态工具/交互确认 ②成交方式判定 ③特殊页型抽样（每类 ≥1 页）④内容质量抽查（固定样本见 §4）。抽查结论不外推全站。

**证据分级（强制）**：观察（sitemap 存在某类 URL）→ 推断（URL 呈现某模式）→ 验证（SERP/关键词/页面流量/实测兑现）。三清单每条+深档关键发现用**证据块**：`结论｜等级(验证/推断/观察，复合结论可分位写如"模式=验证+判断=推断")｜证据(数据源+日期+关键数值+URL)｜限制｜对我方动作(模板/页面/排产/质检断言)`。仅"验证"级可进"可复用机制"清单；URL 推断单独不得证明页面质量/流量/转化。

**版本**：v4.1 口径锁定+降级链+证据三级｜v4.2 全量词表+estimate_serp_clicks｜v4.3 种子站拓展+差评 VOC+流量集中度｜v5.0 情报三问+Q1 两档+GO 五档+证据块+目录制落点。

## 0. 铁律

1. **真实 SERP 驱动**：竞对发现/意图实判只用 Ubersuggest `serp_analysis`（主）/DataForSEO（备），禁 web_search_prime/WebSearch
2. **发现即登记，深研前必筛**：发现层全量登记不筛选（信息不损失）；**进入深研前必须过重点池筛选**（真实竞对四条件收紧+五维：需求重叠/规模/模式相关/学习价值/词域在位，收敛至 ≤30 家），池外档案与按域名数据文件清除留 git——发现层防漏，深研层防散
3. **sitemap 全量不抽样**：raw json 先落档核验，**深档提炼完成后即删**（2026-10-09 定调：raw=中间产物用完即删，深档为唯一长期留存；季度 diff 用重抓新版 vs 深档统计行）
4. **范围判断必须全量核实**："几家有博客"类判断必须 Python 扫全量 sitemap，不凭印象
5. **敏感词脚本层过滤**：研究文档只计数不落词面；过滤规则版本+数量+时间落 `过滤日志.txt` 随数据留档
6. **研究→生产闭环**：每个结论指向生产侧对应物（模板/排产/质检断言）
7. **需求范围纪律**：改 X 只动 X，顺手发现只报不动
8. **分档完成情报三问**：每个真实竞对必须完成 **Q1 基础版**；主对标站（2-3 家）与模式级深研对象必须完成 **Q1 深研版+Q2+Q3**（§0.5）。仅统计页面数量不算完成

## 0.5 情报三问（Q1-Q3 唯一定义处，其余章节只引用）

### Q1 他们的钱从哪来（两档）

| 档 | 对象 | 数据 | 产出 |
|----|------|------|------|
| **基础版**（每个真实竞对必做） | 全名单 | `domain_overview`（步骤④）+ `domain_keywords(limit=10)` + `domain_top_pages(limit=10，月访>5K 家)` | Top 页面初筛（记录 top_pages 有效返回页面，最多 10 行；不足如实记录） |
| **深研版**（主对标站 2-3 家+模式级深研对象必做） | 主对标/模式级 | 全量 `domain_keywords` 翻页至取尽（"≥200 词"=数据可得时目标量；不足 200 如实记录实际数，不视为失败）+ 每词绑定排名 URL | Top 20 页面清单+Q2 判定表 |

基础版不承担完整 Top 20 识别与 Q2 页面级决策。

**Top 20 口径**：按 `domain_top_pages` **页面级自然流量估算**排序，禁按关键词搜索量相加推算（多词承接会重复计算）；列定义以模板 §4.1 为准（九列+排名+页面 ID；**产品页同占 P 号**——P-ID=页面主键，与页型无关）；主词月量≠页面流量，两列分开。**词级取数主通道=Ubs `domain_keywords`**（2026-10-09 实测：返回含 `url` 排名链接+`sd` 难度列，绑定与 SD 一次到位）；DFS Labs `ranked_keywords` 仅限季度词级快照（§8）与 Ubs 额度尽兜底（计费与慎用口径见 §9）；深研版 `domain_top_pages` 用 **limit=20**。
**品牌词识别口径**：品牌词表=域名品牌+母品牌+产品品牌+常见拼写变体；品牌/非品牌占比注明按词数还是按流量计算；多品牌站分品牌记录。

### Q2 值不值得进（八因子 × 五档）

| 因子 | 过线判据 |
|------|---------|
| 需求 | 非品牌有效月量达阈值（词族变体归并口径） |
| 意图 | 我方可承接（§6 两轨分流有对应承接页型） |
| SERP 机会 | 我方以目标资源可进（前十结构可争） |
| 竞争 | 前十构成记录口径：**开放｜半开放｜品牌集中｜平台集中｜不可争**（记前十中平台/头部品牌数+是否存在独立站站位） |
| 产品 | 我方有对应产品或服务 |
| 证据 | 价格/规格/评论/案例可得 |
| 生产 | 可规模化差异化生产 |
| 架构 | 不与已有页面自相残杀 |

逐因子判定，缺项标 ✳（待查）不得默认 ✓/✗；需求+SERP 机会不足以单独定 GO。**SERP 因子预算纪律**：行级判定可复用四查留档；仅 GO-P0 决策行要求实测 SERP。

| 档 | 动作 |
|----|------|
| GO-P0 | 直接进排产 |
| GO-P1 | 补证据或小规模测试后进排产 |
| HOLD | 依赖（产品/架构）满足后复评 |
| NO-GO | 不做，记录原因 |
| WATCH | 季度锚定复查时复评 |

**GO 矩阵产出格式**：`主词｜月量｜SD｜他们排名｜我们现状｜建议 slug｜判定档｜优先级`——直接可排产。

### Q3 进了长什么样（模块契约）

每个 GO 页类一套模块契约，列定义：`模块｜页面目的｜必需数据字段｜证据件｜可变生产变量｜质检断言`。**只复用机制、结构、数据字段、验证标准；不得复制竞对文字、视觉、评论素材**。契约到手即可生产，不需再看竞对页面。

**辅助六问**（加分项）：Q4 增长触发点（动作+剂量+见效周期）｜Q5 AI 引用份额（GEO 格局）｜Q6 定价锚（SERP 价格位竞争力）｜Q7 评论/信任体系（rich snippet 差距）｜Q8 产品矩阵拆法（pSEO 组合维度乘法逻辑）｜Q9 战略克制清单（他们做了但我们不该跟的）。

## 1. 十步主流程

| # | 步骤 | 完成标准 |
|---|------|---------|
| ① | 业务范围界定（来自项目启动包，前置确认，非本 SOP 产出） | 边界已确认；未界定→回启动包补齐，不进② |
| ② | SERP 发现与筛选真实竞对（参数见下） | 双阈值冻结达成；每家记录词族来源与去重备注 |
| ③ | 成交方式验证=入库门槛（参数见下） | 每家过三问+商业类型定档；REJECTED 家数+原因留档 |
| ④ | domain_overview 前置分级（每批 <15 家） | 每家有摘要（月访/词数/DA/DR/趋势定性/top3 词）落盘 |
| ⑤ | sitemap 全量提取+页型识别（参数见下） | URL 底册+页型/slug 统计落竞对目录；记录发现方法（robots/探测/内页/失败）。**名单 >30 家时，⑤ 收尾即执行重点池筛选**（铁律 2 五维收敛 ≤30 家，产出《重点竞对池筛选定案》落竞品研究根目录；池外档案+按域名数据清除留 git；跨家聚合 raw 保留不拆） |
| ⑥ | Q1 赚钱页面识别 | 按 §0.5 Q1 两档；基础版覆盖全名单，深研版 Top 20 落盘 |
| ⑦ | Q2 页面级 GO/NO-GO | 按 §0.5 八因子×五档；深研对象逐页判定，GO-P0/P1 页面池成形 |
| ⑧ | Q3 页面模板拆解 | 按 §0.5 模块契约；每个 GO 页类一套契约 |
| ⑨ | 深档+博客矩阵+词池对账（§2/§5/§6） | 深档按十三节结构生成；**触发式章节（§10 归因/§11 VOC）未触发时保留标题填"未触发"+判定依据，不得空白**（空白无法区分未触发与漏填）；情报必需节缺一=分析未完成（REJECTED 档案除外，见 §2）；选题矩阵+对账表落盘 |
| ⑩ | 归因+VOC+总汇+HTML 手册（§8/§5b/§2/§11） | 触发站归因卡齐；主对标 VOC 三张表；总汇定稿；手册生成 |

**②发现参数**：`serp_analysis limit=20-50`，统一口径 `locId=2840`/en/desktop、记录查询日期、按注册域名去重（同集团多域名保留主站+备注关联）、品牌词 SERP 不作竞对来源。三类词族：品类词 3-5（{产品} replacement/custom）＋**工具/计价词 5-10**（calculator/instant quote/quote online）＋场景长尾 2-3。过滤大平台/OEM 官网/目录站/聚合页。**冻结双阈值**：≥20-30 家即冻结；不足 20 家继续加词族/渠道（SaaS Referral 榜反推），**连续两轮新增合格竞对 <2 家**即冻结并记录原因（细分市场竞对天然少≠失败）。

**真实竞对定义**（四条全满足才进名单）：相同客户群｜产品/服务高度替代｜目标市场实际成交｜至少 1 个相关非品牌词进 SERP 前 100。排除：纯媒体/目录站/平台聚合页/OEM 供应商官网。

**种子站拓展**（词族饱和度不足时触发）：选 3 个业务方向不同的种子站 → Ubersuggest `competitors` 沿关键词重合拓展候选域名 → 三级清洗（①相关性阈值剔除弱相关 ②预估自然流量>100 ③逐站商业模式三问分类）。原始域名数≠竞对数。

**③成交方式验证参数**：三问=谁能买/买什么/怎么成交；SERP 计价词族命中+webReader 实抓确认交互，**禁止凭首页定类型**。价格可见性判据（=§4 纪律 7）：在售价=数字与商品绑定+能选规格+能加购；仅展示数字=标价展示；纯 RFQ 询盘≠在线计价；专业渠道口径="普通消费者无购买资格"非"无价格"；跨性质不算平均价。不过门槛=REJECTED 不进名单。

**⑤sitemap 参数**：降级链 ①读 `robots.txt` 全部 `Sitemap:` 声明→②常见路径探测（`/sitemap.xml` `/sitemap_index.xml` `/wp-sitemap.xml` 等）→③内页页脚找 sitemap 链接→④全失败标"无 sitemap"，仅目录推断+抽样（不产出 URL 底册）。工具=`02-自动化工具库/12-sitemap定位器/`。URL 统计口径：去重后 HTML 页面 URL；排除 image:loc/视频/新闻/附件（.pdf/.jpg 等）/参数 URL；多语言按独立页统计标语言维度；lastmod 缺失不剔除。slug 三维度见 §3；页型判定树见 §4。

**状态码**（双字段，每竞对标注）：
- **流程状态**（四选一）：READY=输入完整可继续｜PARTIAL=数据不完整允许降级并标注缺口｜BLOCKED=关键数据缺失禁输出强结论｜REJECTED=非真实竞对不进名单留档原因
- **证据状态**（关键结论最高证据等级）：观察级｜推断级｜验证级（验证级=可进"可复用机制"清单；与流程状态正交，不互斥——READY 档案的证据状态可以是三级中任一）

**失败分支表**：

| 场景 | 处理 | 状态 |
|------|------|------|
| sitemap 读不到 | 四级降级链走完仍无→仅目录推断+抽查 | PARTIAL |
| Ubsuggest 无数据 | 按 §9 备用列分流：有备用（SERP/词级）切 DataForSEO；无备用（如 overview 横向口径）仅记录缺口，禁跨源拼接对比 | PARTIAL/BLOCKED |
| top pages 有效数据 <10 | 不做流量排序结论，侧重意图与内容类型分析（月访<5K 家豁免 top_pages 属**正常分支**非缺失，记"不适用"） | PARTIAL |
| JS 动态渲染 | Playwright 限定 §9 场景 | — |
| 无公开价格 | 按标价展示口径记录（§4 纪律 7） | — |
| 只有品牌词有排名 | 品牌护城河定性，学习对象降级 | — |
| 无非品牌词进前 100 | — | REJECTED 候选 |
| 页面被多词族重复承接 | 变体归并口径（§4 纪律 5） | — |

## 2. 产出标准

**落点目录制**：每竞对一夹 `竞品研究/竞品站点/{domain}/`：

| 产物 | 说明 |
|------|------|
| `{domain}-深档.md` | 按《竞品深度拆解模板》v5.0 十三节，参考 200-500 行；**按必需字段完整度验收，不以行数作为完成标准**（普通竞对以基础版字段为准，深研对象以 Q1-Q3 完整度为准）——**夹内唯一长期文件** |

**目录制数据分层**（2026-10-09 定调：结果进深档，中间产物用完即删）：
- **夹内唯一长期文件=深档 md**；raw/json（sitemap raw/四查 raw/DFS 词表/blog_split）=中间产物，**深档提炼/回填完成后即删**（铁律 3；git 不可溯项目尤须笃行——删前确认数值已入档）
- **单竞对专项分析**（blog 分析/页面框架深研/成交走查等）→ **一次性并入深档对应节**，不留夹内独立二次分析文档——分析真源唯一
- **跨竞对聚合分析**（对比总表/博客矩阵/词池对账/VOC 总表/归因卡集/重点池筛选）→ 竞品研究根目录（总汇层），**同样不留聚合 raw 层目录**
- 深档 §2 数据表以"文件名+日期"记录已清除 raw 的查询留痕（溯源语义保留，文件不留）

**情报必需节**（按档位分档，缺一=分析未完成）：所有档案必填 §1/§2/§13；**普通竞对（基础版）**加 §4 Q1 基础版+§12（§5/§6 以"不适用（基础版路径）"占位不算缺失）；**深研对象**加 §4 Q1 深研版+§5 Q2+§6 Q3+§12。**REJECTED 档案例外**：只需完成模板 §1/§2/§13+排除原因，不进入深研产出统计。
**迁移档规则**（旧档迁 v5.0 时）：raw 可复核的数值一律以 raw 为准（v4 判读不可直接照搬）；原判定不合规（如仅凭首页定成交方式）降推断级并标注"迁移降级"。原 v4 八节信息点已全部映射进十三节（IA/页型/pSEO→模板 §7，更新重心→§10，三清单→§12，page vs post→§12.4，特有情报→§0+§12 自由落位）。档案头字段保留：域名/平台/URL 总数/流量（月访｜有机词｜DA｜24 月趋势｜top 词归属）/外链强度（DR 辅助粗筛，不与流量/词数横向等价）/活跃度。删旧档前做 diff 补遗检查（旧档有而深档无的数字级信息先补入再删；"删档前 diff"进迁移验收）。

**三清单**（落模板 §12）：可复用机制/可超越缺口/风险与反例，有充分证据时各列 2-3 条；**证据不足允许少于 2 条并写"证据不足"，不得凑数**（可复用机制仅收验证级，无验证级证据可空+说明原因）。每条用证据块绑定 ≥1 可复核证据（URL 数/关键词数/估算流量/排名/SERP 结果/实测行为+日期）；无证据只列"待验证"不入清单。

**另产**：`00-对比总表.md`（全竞对：域名/平台/URL 数/pSEO/页型/SERP/流量，同源工具出齐才可比）+《竞对决策级发现总汇》（随深档出初版、四查后回填定稿）：行业格局判断（5-8 条决策级发现，**必含流量集中度**=同商业模式子集前 10/20 家流量占比）｜分战场发现（流量/产品/内容）｜决策溯源表（我方决策←支撑发现，复盘载体）｜空白与机会（含差评断层清单）｜档案索引。

**特殊价值竞对追加**：与己方同模式者（同供应链/同打法）加"模式级深研"七维度（品类定价/配置维度全集/信任构建/物流/冷启动/技术栈证据链），产出"它已解决而我方空白的能力清单"。

**UI/导航增强层（触发式）**：主对标站（2-3 家）或出现可复用交互资产（mega menu/Finder/配置器）时触发：①header/mega 导航结构提取（=内链权重分发结构）②色板/字体快扫（curl 一次 CSS）③交互资产截图留档。落点=该竞对深档对应节；反爬带浏览器 UA。

## 3. slug 三维度

| 视角 | 看什么 | 得出 |
|------|--------|------|
| 路径结构 | URL 目录层级 | 信息架构 IA |
| 命名模式 | slug 命名规律 | pSEO 引擎 DNA |
| 页型分布 | 页型 url_count 占比 | 战略重心（产品/内容/pSEO/本地驱动） |

模式对照（**非封闭枚举**，无法归类即新增并记样本+数量）：`/{属性A}-{属性B}-{核心词}/`=双属性映射｜`/{规格}/{规格}/`=笛卡尔积｜`{实体}-for-{场景}`=场景导航｜`{实体}-vs-{实体}`=对比页｜`{实体}-alternatives`=替代页｜`{地区}/{核心词}`=地理 pSEO。
**流量修正**：吃流量最多的页型≠页数最多的页型时，战略重心以流量数据为准。

## 4. 执行纪律

| # | 纪律 |
|---|------|
| 1 | 页型级不是目录级；**工具页（calculator/quiz/converter/finder）单独归类**——漏扫=漏一条产品线 |
| 2 | 工具/成交判定不能只看 sitemap：SERP 计价词族命中+webReader 实抓确认交互；成交验证按步骤③执行 |
| 3 | 一词实测≠词群结论：对该页型下 SERP 意图/竞争结论时，需 8-16 词实测支撑；**不要求每站每页型执行**，词样本不足标 PARTIAL |
| 4 | AI 抗性分页型统计（单值静态映射词 vs 多值决策词命运不同） |
| 5 | 跨词变体意图归并（变体各自全量 vol 虚高 10-20 倍） |
| 6 | 平台识别看源码（generator meta/静态资源域），XML 转义与 image:loc 兼容提取 |
| 7 | 页面有数字≠产品价格：判据同步骤③；跨性质不算平均价 |
| 8 | B2B 计算器可剥离 DOM 留存逻辑本地重放（成本结构外泄情报），遇则采 |
| 9 | 内容驱动站主题与购买意图零交集=反例非学习对象；学习对象看词族集中度 |

**页型判定树**（按序匹配，命中即归类；全不中→"待复核"不得强行归类）：①交互输入/计算/筛选输出→工具页 ②购物车/规格选择/成交路径→产品页 ③流式日期发布→blog post ④固定导航/服务说明→静态 page ⑤标签/作者/分页/筛选集合→归档技术页（不计内容统计）。产品页二分：**真 SEO 页**（对应词有排名支撑）vs **SKU 长尾堆砌**（URL 存在但无排名无流量）——供给量大≠有效页多。

**内容质量抽查固定样本**（每站 3-5 页）：top 流量产品/类目页 1｜top 流量文章页 1｜典型 pSEO 页 1｜工具/配置页 1（如有）｜转化路径页 1（如有）。检查项：搜索承接（主词/意图/SERP 类型）｜页面结构（H1H2/模块顺序/FAQ）｜商业承接（CTA/价格/加购/询价）｜证据（评论/规格/案例/认证）｜技术（schema/canonical/索引风险）｜差异化独特资产｜生产难度。

## 5. 博客矩阵 → 选题转化

适用=全部含博客竞品（`/blog|/learning-center|/news|/resources|/articles` Python 全量扫；`{domain}_blog_split.json` 落 `站点sitemap数据/`）：

1. 统一主题轴聚类（测量教程/选购对比/材质/养护/DIY/品牌替换/行业应用/其他），每篇只归一个主主题，标题无法判断标"待人工复核"；主题轴命名**跨批次统一轴表**（实战出现两代命名"测量教程"vs"手工教程"，跨家对比前先归一）
2. 主题×竞对篇数矩阵+对位我方 `posts/` 三档（已覆盖/竞有我无/全空白）
3. ≥3 家覆盖=P0；1-2 家=P1；零覆盖=P2 自证需求（本节 P0/P1/P2 仅指博客选题优先级，不与 §6 词池优先级混用）
4. P0/P1 过 SERP 深研（工序本体见 [关键词调研与SERP深研SOP](关键词调研与SERP深研SOP.md) §四-六：前 10 逐页拆+增益规划六项产出，产品词/类目词/文章词统一），并同备四条件：**主题证据+SERP 证据+商业承接+生产可行性**
5. 排产选题登记：主词与变体归并｜搜索意图｜目标 URL｜文章→产品页内链｜目标 CTA｜转化事件
6. 产出 20-30 个 slug 级选题 → `01-博客主题矩阵与选题转化.md`；"其他">30% 按标题词频二次细分

## 5b. 竞对差评 VOC（触发式）

**触发**：主对标站定档后（普通竞对不做）。**三种空态区分**（禁混写）：未触发（条件未满足）｜触发未采样（应做未做，分析欠账）｜触发平台缺（平台不存在/无样本，如实记录）。**采样**：目标每平台（Amazon/Trustpilot/站内）1-3 星差评 50-100 条；平台不存在或样本不足时按可得样本执行并记录平台缺失，**不得为凑样本混入其他来源**；样本不足只影响 VOC 信号强度，不阻塞主分析。每条只计一个一级问题，跨平台去重，排除物流/客服投诉。

**断层对照**：竞对页面主承诺 ↔ 差评高频问题——承诺集中+差评集中=需求未被稳定满足=差异化机会+验证标准来源。断层清单进总汇§空白与机会；每条走五步翻译（原话→具体问题→购买风险→产品标准→页面证据）落三张表（§10 步骤 5）。

**采样字段表**：来源平台｜评论日期｜星级｜一级问题（每条一个）｜多标签明细｜跨平台去重｜与页面承诺对应（是/否）｜我方可控程度（高/中/低）｜是否进验证标准（是/否）。
**输出定位**：问题**信号强度**，非发生率（差评占比≠市场投诉率）；不做品牌质量排名。

## 6. 词池承接对账（四查收尾工序）

**两轨分流（不许混淆）**：Transactional/Commercial 词（custom X/X replacement）→ 唯一承接=**page**｜Informational 词（how to/what/cost）→ 唯一承接=**post**。

对账表：词族 ×「商业词量｜page 承接｜信息词量｜post 承接」逐行 ✅/❌。词池=四查词级+`keyword_suggestions` 自查（每批 3 种子）；**四查词级只是来源之一且必须过漏斗——竞对视野锁死与目录行为词风险见深研SOP §〇 来源盲区表**；逐词判定与深研过《关键词调研与SERP深研SOP》（粗判三判→深研一道漏斗）。

**缺口判定**（词族口径：变体归并去重、排除品牌词、统一 locId=2840）：缺页=商业词族有效月量 **≥1,000** 且无 page｜缺文=信息词族 **≥500** 且无 post｜优先级 **P1 ≥3,000｜P2 1,000-2,999｜P3 <1,000**｜同档排序用 `estimate_serp_clicks`（词量+可争位次+SERP 特征→预估点击，纯本地计算不耗日额）打破词量平局——位次取 `serp_analysis` 实测 3-10 位（我方可争位），AI Overview/featured snippet 占位词族点击打折；缺口编 G 号（词族+实测词量+竞对实证+建议 URL+优先级）。

**纪律**：落 `04-内容生产/品类页覆盖盘点.md`；先登记再建页；季节词提前 6 个月建页；并入优先于新页；大规模四查后重跑。

## 7. 四查（Ubersuggest，每竞对必做）

> Q1 两档业务口径见 §0.5（本节不重复）；overview 已前置为步骤④。本节=工具执行细节。

| 序 | 工具 | 全做？ | 看什么 |
|---|------|-------|--------|
| 1 | `domain_overview` | ✅（步骤④） | 规模分级+24 月趋势+自带 top50 词排名 |
| 2 | `domain_keywords` | ✅ | search_intent 标注+词级确认（基础版 limit=10 判读；深研版全量翻页见下） |
| 3 | `domain_top_pages` | 月访>5K 家（基础版 limit=10；**深研版 limit=20**） | 词层流量的页面级兑现+Q1 排序口径数据源 |
| 4 | `backlink_opportunity` | 建站后 | 链竞对不链己方的 referring domains（需己方域名作 negative_target） |
| 可选 | `domain_top_countries`/paid 字段/`competitors` | 条件触发 | 国家布局｜投广告=需求验证｜竞对榜交叉 |

**深研版全量翻页操作**：`domain_keywords limit=50` + `previousKey` 翻页至取尽（organic，locId=2840）；翻页属大查，与其它查询交错防限流。落盘 `_ubersuggest_domain_keywords_full_raw_{日期}.md` 落竞对目录；翻页次数+总词数记深档档案头。用途：①词池对账（§6）种子 ②品牌词占比精确计量 ③主对标词层→我方页面映射底册（每词绑竞对承接 URL）。

**限流操作法**：403 无文案+auth 正常=短时限流等 60-180s（转落盘不空等）；报错含 "daily reports limit"=日额尽当日停。限流按 payload 加权：全量 overview 连续 ~15 次触发，limit=10 小查 46 次零触发——大批量大小查交错。150 次/天：29 家四查一轮 ≈75 次。额度够就全量不抽样。

**落盘契约**（查完即写）：①查询结果即时写入深档对应表（含数据日期）②raw 文件为过程留痕落竞对目录，**回填完成并核验后清除**（铁律 3）③深档档案头一行 ④总汇回填 ⑤top_pages 查询**逐页全量核验落档**（raw 自述页数与明细数可能不符，迁移实测 2 家自述 10 列 9；禁只落判读摘要）。

**交叉判读**：有页面无排名=无效堆砌（勿复用其结构）｜slug 模式+对应词有排名=引擎已验证（升"验证"级）｜流量趋势陡降=衰退，切入窗口｜**词层流量≠页面层兑现**（keywords 大流量+top_pages 水位低=怪词噪音或衰退站，成色打折）｜高品牌词占比=护城河难抢（学品牌建设）；纯非品牌=pSEO 驱动可复制（正面学习对象）｜serp_analysis 条目自带 shares——高分享=有传播基因，进"可复用机制"候选证据。

## 8. 流量拐点归因（上升/下降双向）

归因区分相关性与因果性。**触发**：24 月趋势 3 个月内 ±40%，或连续两月同向 >25%（触发不限档位，普通竞对也可触发）；或季度复查锚定名单异动（**锚定名单每季度重跑 overview 一轮**，竞研从项目制变持续情报资产）。**产出分档**：主对标站/深研对象触发→独立归因卡落竞对目录；普通竞对触发但五源数据不足→深档 §10 内嵌"部分归因"，不强制独立卡。

| 步 | 动作 | 判读 |
|---|------|------|
| 0 | 剥离季节性（防误判） | 品类季节先验+两年同月对比；同月同形态=季节型误报剔除 |
| 1 | 曲线定位拐点月 | domainTraffic 月度序列，拐点 ±1 月 |
| 2 | 算法更新对齐 | Google Search Status Dashboard 官方主源（Moz 更新史备）；窗口 ±2 周=算法相关型（仅相关性证据，非确定因果） |
| 3 | 关键词分层变化 | **前置：已有季度词级快照**（按季保存 domain/关键词/排名/URL/流量估算/数据源）。无快照→跳过，结论标"部分归因（无词级历史）"，禁输出词级分层月度变化。有快照→searchKw+四层（top3/4-10/11-50/51-100）对比：词数不变分层下移=排名滑坡｜searchKw 骤降=掉出前 100（索引/惩罚级）｜topTier 稳 thirdTier 崩=中腰部失守（竞对抢位） |
| 4 | 页面级定位 | 崩首页=站点级｜崩某类页=板块级（博客被砍/pSEO 失效）｜散点=正常波动 |
| 5 | 反链增减性质 | lost/gained 的 spam_score：丢 spam>50=疑似良性排毒（须结合自然链变化+目标页流量复核后定性）；丢自然链+gained 归零=外链流失型 |
| 6 | 归因结论+双向动作 | 类型枚举：算法相关｜板块崩塌｜外链流失｜竞争抢位｜季节（误报）｜品牌损毁 |

**输出**：每家一张归因卡（拐点月/归因类型/证据/我方动作）落 `竞品站点/{domain}/`，回填档案头+总汇溯源行。

**动作还原**（触发站必做，五源全部不读正文）：

| 证据源 | 得出 |
|--------|------|
| lastmod 月度分桶（sitemap 自带，按页型聚合） | 动作日历（建页潮/改版潮/停更点） |
| `backlinks(order_by=first_seen)` 月度分桶 | 外链动作窗口（数字公关/被报道/可疑采购） |
| Wayback 快照（拐点月前后各 1 张） | 结构动作（新板块上线/砍板块） |
| `domain_top_pages` 类型分布+集中度 | 增长引擎定性（pSEO/内容/品牌/单品驱动） |
| sitemap 季度重抓 diff（随锚定名单积累） | 扩张/收缩实锤 |

输出**动作时间线卡**：动作行（五源汇总）× 流量行（24 月曲线）上下对齐，标注"动作先于拐点 N 月"→ 引擎动作因果链。上升站因果链进"可复用机制"（**动作+剂量+见效周期**三项齐全才算一条）；下降站进"风险与反例"+我方抢位机会（它丢的词层=我方内容窗口）。时滞按站按页型实测记录（3-6 月为经验先验非定值）；lastmod 缺失站降级用 Wayback+外链双源。

**数据缺口**：Ubsuggest 无词级历史——词级丢失清单用 DFS Labs `ranked_keywords` 季度快照自建 diff。

**DR 口径**：Ahrefs 免费接口 `curl -H "Authorization: Bearer $AHREFS_API_KEY" "https://api.ahrefs.com/v3/public/domain-rating-free?target={domain}"`（key 在 `.env`；免费不耗 units；**仅辅助粗筛**——可被 301/灌外链操纵，不判竞品质量/流量真实性/业务规模，不与 DA/流量/词数横向等价；档案记录抓取日期）。

## 10. 本地生产契约（C 端落地）

研究产物先本地文件化，建站（WP+Woo，竞品 Shopify 不跟随）最后导入：**page 走 HTML→Elementor 流水线（禁 REST 塞整页 HTML）；post 走 MD→Gutenberg**；REST 只写元数据/媒体/状态/分类等结构化字段。**Woo 类目页例外：不建 HTML 原型**——默认模板自动渲染产品网格/筛选/排序，类目页生产物=**文案包 JSON**（TKD/导语/页底 SEO 文案/FAQ/兄弟链/支柱文配对/证据件绑定→WP term+描述+RankMath meta 录入）；schema 由 Woo+RankMath 自动生成。

| 步 | 产物 | 位置 |
|----|------|------|
| 1 | url-map 全站 URL 底册/nav IA | `站点结构/` |
| 2 | 词池/实体 JSON（页面生成真源） | `数据/` |
| 3 | pSEO 页面 HTML（目录名=slug，全页原型，TKD+schema 齐全） | `页面原型/` |
| 4 | 博客 MD（front matter+四层矩阵，H1 一次，每篇 ≥1 产品页内链；词量 how-to 2000+/gift 1800+/科普 1500+） | `文章/` |
| 5 | VOC 三张表（购买风险表/产品验证标准表/页面证据需求表；顺序：风险→标准→证据；未过验证的承诺不进页面文案） | 项目目录 |
| 6 | 建站（最后）：WP 装机→Elementor 流水线→REST 写 TKD/元数据→Rank Math | 服务器 |

生产纪律：数据驱动（JSON 生成底座每页文字差异化）｜事实零错（数据/价格逐项核对）｜agent 分工防冲突（独立目录）｜建站前全量本地质检，线上验证一次。

## 11. 页签式作战手册

竞研收尾产**单文件页签式 HTML 作战手册**（`竞品研究/00-总览.html`）=md 数据层的作战视图。生成时机：词池对账（§6）+选题转化（§5）+总汇定稿三工序齐后生成 v1；每批次深档回填总汇后再生成；建站启动时锁定快照版+版本戳。

**页签（12 张）**：①竞对全景（平台/URL 数/pSEO 引擎+流量集中度）②决策发现+决策溯源表 ③IA 蓝图（page/post 标注+内链权重注记）④页面规划与数量 ⑤内容体系（文章轴×结构模板×字数分配）⑥pSEO slug 模板库（验证级）⑦词池底册（G 号完整表+Tier 分层+季节窗口）⑧转化与信任层 ⑨生产契约 ⑩待办与数据缺口 ⑪建站节奏（死线倒排+质检断言+时滞基准）⑫页面级 GO/NO-GO 汇总（跨竞对 GO-P0/P1 页面池+模板骨架索引）。

**数据注入纪律**：①md 为唯一真源，HTML 由脚本从 md 生成 rows JSON 内嵌，禁手写数字 ②清单类页签**完整表注入禁摘要化**（卡片摘要=G 号三行摘要同构错误）③每数字可溯源到 md 文档+数据日期；md 与 HTML 冲突以 md 为准；HTML 不得呈现未落 md 的结论；生成脚本输入路径=`竞品站点/{domain}/` 各竞对目录。头部带生成时间+数据截止批次戳；季度锚定复查后再生成。
