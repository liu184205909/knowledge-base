4 页型分布页型级统一口径（产品 / 类目 / blog post / 静态 page / 工具页 / 教程页；判定树见 §4）；区分真 SEO 页 vs SKU 长尾 vs tag 归档；无法判定的入"待复核"不强行归类
5 page vs post 判定固定层级页 vs 流式内容 → 自建 WP 架构映射

3slug 三维度（方法论核心）

URL 分析的三个视角（分布是统计结果，非 URL 自身属性）：

路径结构
看什么：URL 目录层级
得出：信息架构 IA
命名模式
看什么：slug 命名规律
得出：pSEO 引擎 DNA
页型分布
看什么：页型 url_count 占比
得出：战略重心（产品 / 内容 / pSEO / 本地驱动）

六种模式对照（常见模式非封闭枚举）

/{属性A}-{属性B}-{核心词}/双属性映射
/{规格}/{规格}/笛卡尔积
{实体}-for-{场景}场景导航
{实体}-vs-{实体}对比页
{实体}-alternatives替代页
{地区}/{核心词}地理 pSEO

发现无法归类的模式即新增模式并记录样本 + 数量（如 品牌×品类 / 地区×服务 / 兼容型号 / 多语言路径）——不强行塞入六类。

流量修正：吃流量最多的页型 ≠ 页数最多的页型时，战略重心以流量数据为准（slug 分布只是供给面）。

4执行纪律（判读口径）

#纪律
1页型级不是目录级；工具页（calculator / quiz / converter / finder…）单独归类——漏扫 = 漏一条产品线
2工具 / 成交判定不能只看 sitemap：SERP 计价词族命中 + webReader 实抓确认交互（纯 RFQ 询盘不算在线计价）；成交方式过 1D 三问（谁能买 / 买什么 / 怎么成交），禁止凭首页定类型（阿木 186→179 家教训）
3一词实测 ≠ 词群结论：每页型 8-16 词 SERP 实测再下结论
4AI 抗性分页型统计（单值静态映射词 vs 多值决策词命运不同）
5跨词变体意图归并（变体各自全量 vol 虚高 10-20 倍）
6平台识别看源码（generator meta / 静态资源域），XML 转义与 image:loc 兼容提取
7页面有数字 ≠ 产品价格：在售价判据 = 数字与商品绑定 + 能选规格 + 能加购物车；仅展示数字 = 标价展示；RFQ 表单 = 非在线计价；专业渠道口径 = "普通消费者无购买资格"非"无价格"；跨性质不算平均价
8B2B 计算器可剥离 DOM 留存逻辑本地重放（成本结构外泄情报），遇则采
9内容驱动站若主题与购买意图零交集 = 反例非学习对象；学习对象看词族集中度

页型判定树

按序匹配，命中即归类；全不中 → "待复核"不得强行归类：① 有交互输入 / 计算 / 筛选输出 → 工具页 ② 有购物车 / 规格选择 / 成交路径 → 产品页 ③ 流式日期发布体系 → blog post ④ 固定导航 / 服务说明 → 静态 page ⑤ 仅标签 / 作者 / 分页 / 筛选集合 → 归档技术页（不计入内容页统计）

5博客矩阵 → 选题转化

适用 = 全部含博客竞品（/blog|/learning-center|/news|/resources|/articles Python 全量扫）：

  1. 每家拆 {domain}_blog_split.json 落 站点sitemap数据/
  2. 统一主题轴聚类（测量教程 / 选购对比 / 材质 / 养护 / DIY / 品牌替换 / 行业应用 / 其他）。分类默认基于 slug + 标题，每篇只归一个主主题；标题无法判断的标"待人工复核"
  3. 主题 × 竞对篇数矩阵："多家有但量少" = 可超越，"零覆盖" = 空白
  4. 对位自己 posts/ 标三档（已覆盖 / 竞有我无 / 全空白）；进 P0/P1 的选题人工抽样复核后方可排产
  5. 产出 20-30 个 slug 级选题 → 01-博客主题矩阵与选题转化.md
"其他" >30% 须二次细分（按标题词频聚类拆分）
≥3 家覆盖 = 需求实证 P0　1-2 家 = P1，零覆盖 = P2 自证需求

6词池承接对账（四查收尾工序）

原则会漏，对账表不会（sofa 漏洞：17 页批次漏 sofa 8.1K + patio 8-10 万词池）。

两轨分流（不许混淆）

Transactional / Commercial 词
custom X · X replacement
唯一承接 = page，文章互哺不算
不许混淆
Informational 词
how to · what · cost
唯一承接 = post

对账表

词族 ×「商业词量｜page 承接｜信息词量｜post 承接」逐行核对（原表记法为逐行 ✅/❌）。词池 = 四查词级 + keyword_suggestions 自查（每批 3 种子）；逐词判定先过《关键词调研与搜索意图判定手册》三判，输出直接填表。

缺页判定：商业词族 ≥1,000 无 page = 缺页
缺文判定：信息词族 ≥500 无 post = 缺文

词族口径：变体归并后去重、排除品牌词、统一 locId=2840。缺口编 G 号（词族 + 实测词量 + 竞对实证 + 建议 URL + 优先级 P1≥3,000 / P2 1,000-2,999 / P3<1,000）。

  • 403 无文案 + auth 正常 = 短时限流，等 60-180s（转做落盘不空等）；报错含 "daily reports limit" = 日额尽当日停

交叉判读

  • 有页面无排名 = 无效堆砌（抄结构别抄这个）｜slug 模式 + 对应词有排名 = 引擎已验证直接复用（= 证据分级到"验证"级）
  • 流量趋势陡降 = 衰退，切入窗口
  • 词层流量 ≠ 页面层兑现（keywords 大流量 + top_pages 水位低 = 怪词噪音或衰退站，成色打折）
  • 品牌词 vs 非品牌词结构：domain_keywords 首部统计品牌词流量占比——高品牌占比 = 护城河难抢（学品牌建设）；纯非品牌 = pSEO 引擎驱动可复制（正面学习对象）
  • 社交传播力：serp_analysis 条目自带 shares——同词同位传播力对比，高分享 = 有传播基因，进"可抄"清单候选证据

8流量拐点归因（上升 / 下降双向）

四查 = 横截面快照；归因 = 纵向因果链。上升站 = 学习对象（什么引擎驱动增长），下降站 = 反面样本 + 切入窗口——双向都归因。归因结论区分"观察到的相关"与"已验证的因果"。
触发 A：24 月趋势 3 个月内 ±40%，或连续两月同向 >25%
触发 B：季度复查锚定名单异动（锚定名单每季度重跑 overview 一轮，竞研从项目制变持续情报资产）

六步归因流水线

0
剥离季节性防误判

品类季节先验 + 两年同月对比；同月同形态 = 季节型误报剔除

1
曲线定位拐点月

domainTraffic 月度序列，拐点 ±1 月

2
算法更新对齐

vs 核心更新窗口（Google Search Status Dashboard 官方主源，Moz 更新史 moz.com/google-algorithm-change 备）；窗口 ±2 周 = 算法相关型（仅相关性证据，非确定因果——除非补页面级证据），否则下钻

3
关键词分层变化

前置条件：已有季度词级快照（快照契约：按季度保存 domain / 关键词 / 排名 / URL / 流量估算 / 数据源）。无快照 → 跳过本步，结论标"部分归因（无词级历史）"，禁输出词级分层月度变化。有快照 → searchKw + 四层（top3 / 4-10 / 11-50 / 51-100）对比：词数不变分层下移 = 排名滑坡｜searchKw 骤降 = 掉出前 100（索引 / 惩罚级）｜topTier 稳 thirdTier 崩 = 中腰部失守（竞对抢位）

4
页面级定位

崩首页 = 站点级｜崩某类页 = 板块级（博客被砍 / pSEO 失效）｜散点 = 正常波动

5
反链增减性质

lost / gained 的 spam_score：丢 spam >50 = 疑似良性排毒（须结合自然链变化 + 目标页流量复核后定性）；丢自然链 + gained 归零 = 外链流失型

10本地生产契约（C 端落地）

研究 → 内容与建站解耦：全部产物先本地文件化，建站（WP + Woo，竞品 Shopify 不跟随）只是最后导入。page 走 HTML→Elementor 流水线（禁 REST 塞整页 HTML）；post 走 MD→Gutenberg；REST 仅用于元数据 / 媒体 / 状态 / 分类等结构化字段，不用于绕过页面构建器注入整页 HTML。
步骤产物位置
1 站点结构url-map 全站 URL 底册 / nav IA站点结构/
2 数据层词池 / 实体 JSON（页面生成真源）数据/
3 pSEO 页面HTML（目录名 = slug，全页原型，TKD + schema 齐全）页面原型/
4 博客文章MD（front matter + 四层矩阵，H1 一次，每篇 ≥1 产品页内链；词量 how-to 2000+ / gift 1800+ / 科普 1500+）文章/
5 建站（最后）WP 装机 → Elementor 流水线 → REST 写 TKD / 元数据 → Rank Math服务器
