## 一、2026-10 现状快验结果（3 处基线修正）

### 修正 1：HubPages 已死（02/04 基线剔除）

- 2025-11-14 Maven 宣布关站，**11-19 起停止新内容/编辑/新注册**；账号访问保留至 2026-02 底供作者导出内容；discover.hubpages.com 一并关闭，FeltMagnet 等垂直站早在此次关站前已被 Maven 收编进 Discover。[I：The Hub Publication 2025-11-17 报道 + hubpages.com 官方闭站公告 2025-12]
- **行动含义：02 资源库 Tier1 #2（HubPages/FeltMagnet）与 04 矩阵 P1 对应行全部作废**，任何流程里不要再投入。家居手工艺长文的承接平台空缺由 Instructables + Medium 补位。

### 修正 2：Vocal Media 存活但重构（降级观望）

- 2026-06-30 平台公告 "A New Vocal"：重建编辑器 + **verified publishing**（发布验证制）；Vocal+ 付费会员收益机制不变，免费层发布模式有变化（新流程细节未完全公开）。[O：vocal.media/resources 官方公告]
- 行动含义：从 02 库 Tier1 #5 降为**第二批观望**——verified publishing 对带外链内容的影响未知，等 1-2 个月社区反馈再决定是否入场。

### 修正 3：Flipboard dofollow 口径存疑（03 基线标 dofollow，2026 社区口径称 largely nofollow）

- 03 指引称 Flipboard dofollow；本次快验检索到的 2025-2026 社区/行业口径称 Flipboard 链接基本 nofollow，价值在 referral 流量。[C，矛盾未决]
- 平台本身在上升：2026-02 onboard 数十家独立出版商对抗 Google Zero，referral 通道在变强。[I：PPC Land 2026-02]
- 行动含义：**保留 RSS 自动聚合（零成本无所谓链接属性），但不计入 dofollow 外链 KPI**；首次收录后可用 Ahrefs 免费外链查询实测属性。

## 三、Top 5 启动步骤（每平台一句话）

1. **Medium**：直接执行 05 SOP §3.2——品牌名真人画像专号、首月 8-12 篇不进付费墙、每篇 1-2 链指向 /custom-{type}-cushions/ 品类页，第 3-5 篇起带链。
2. **WordPress.com**：注册品牌语义子域（如 cushionguides.wordpress.com）→ REST API + OAuth2 打通自动发布 → 首批 3 篇家居选购指南（选料/尺寸测量/保养）挂链品类页。
3. **Tumblr**：邮箱注册垂直主题博客 → API v2（PyTumblr）接入 → 产品图 + 150 字短文 + 链接的图文帖模板日更，纯内容帖与带链帖 3:1。
4. **Instructables**：Autodesk 账号 → 首篇教程选 "How to Measure for Custom Cushions"（测量教程=定制前置动作，链接相关性天然最高）→ ≥5 步骤配图，材料清单段落放品类页链接。
5. **BuzzFeed Community**：邮箱注册即时发布 → 首篇做 "15 Custom Cushion Ideas for Your Home" 型 listicle（节令版跟 Q4 假日季），每项配图 + 简述 + 链接。

## 四、内容纪律（Top5 共用，继承 03/05）

1. **改写而非搬运**：主站文 → AI 换标题换角度改写后再分发（03 核心）；Medium 严禁剪裁文（05 §1.3 官方红线）。
2. **链接密度**：每篇 1-3 条高度相关外链；定制靠垫的语境落点优先品类页（/custom-{type}-cushions/）与深度指南文，不链首页。
3. **主次分工**：Medium/Instructables 承载"内容为主"的完整选题（GEO 优先），WordPress.com/Tumblr/BuzzFeed 承载改写分发（SEO 外链优先）——同一选题在两类平台不重复出现。
4. **节令线对齐**：BuzzFeed/Pinterest 的 gift guide 按节令线纪律提前一季产出（memory：节令内容随首批批次上目标下一季，不当季死线）。
5. **验收指标**：第 1 个月不考核排名/权重，只考核**发布件数与索引**（site: 查收录）；第 2-3 个月看品牌词 AI 引用频率（05 §3.2 口径）与 Ahrefs 免费 API 的 referring domains 增量（验 WordPress.com/Tumblr 链接属性）。
