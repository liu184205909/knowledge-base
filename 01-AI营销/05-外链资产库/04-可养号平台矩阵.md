## 2. 重点研究发现

### 2.1 Gmail 别名（user+1@gmail.com）注册接受度

- **Google 官方支持无限 + 别名**，全部进同一收件箱 [S9][O]——技术上限不存在。
- **平台侧反制是真实存在的**：屏蔽原因有四类——防重复注册薅羊毛、防封号绕过、防作弊归一化（服务端把 `user+1` 归一为 `user`）、老式邮箱校验regex直接拒收 `+` [S10][C]。XenForo 社区有公开讨论如何封杀 sub-addressing 绕过邮箱ban [S10][C]。
- **实测数据点**：Tumblr 接受 + 别名（本库基线实测）；Reddit 官方甚至允许同一邮箱注册多账号 [S6][I]。
- **结论**：+ 别名是"宽容平台"的快捷通道，但不能当默认策略——**风控严的平台（Reddit/Quora/LinkedIn/Google系）大概率有归一化逻辑**，+ 别名在那里的隔离效果为零甚至为负（暴露批量意图）。
- **catch-all 是否更优**：是。自有域名 catch-all（Cloudflare Email Routing，免费）每个别名都是真实独立格式（`reddit@domain.com`、`quora@domain.com`），无 `+` 特征可被归一化 [S11][O]。代价是域名本身成为关联维度——同一域名注册 20 个号，域名被标记则全部连坐。缓解：多域名轮换（域名成本 $5-10/年/个）。

### 2.2 注册 IP 风控强度分级

**必死级（同 IP 批量注册 = 高封号率）**：
- **Reddit**：IP 信誉是 shadowban 首要因子；数据中心 IP/被滥用过的 VPN IP 上注册的新号经常"注册即隐身"（发帖无人可见）；Tor 出口 IP 必死 [S6][C/I]。被封后同 IP 再注册 = 判定 ban evasion，连坐 [S6][C]。
- **Quora**：ban 后新建号违反 Real Names 政策；引流外部站的账号是重点打击对象 [S8][O/C]。
- **LinkedIn**：实名+手机验证强风控，多号操作在LinkedIn属于高危（推断，[C]级证据）。

**中风险（同 IP 少量多号可行，批量有阈值）**：
- Pinterest（设备指纹+IP 混合判定，推断[C]）、Medium（同 IP 批量注册有风险，推断[C]）。

**宽松（邮箱即可，IP 几乎不卡）**：
- Tumblr、WordPress.com、Dev.to、Hashnode、Telegra.ph（无账号）、Google Sites（随 Google 号风控）、HackerNews、Buzzfeed Community、Issuu、Vocal、DeviantArt。

**操作含义**：矩阵号分两档——**"主号"（Reddit/Quora/LinkedIn/Pinterest）一项目一号、独立邮箱+干净住宅IP、手机验证齐备**；**"内容号"（博客/文档型平台）可用 catch-all + 常规IP 批量注册**，封了重建成本低。

### 2.3 Medium / Quora / Reddit 2025-2026 政策变化

**Medium**：
- 发布 API 状态修正：**第三方发布 API 2019 年 1 月就已砍掉**（并非基线所写"2025年关闭"），2023 年 12 月官方支持账号再次确认"任何第三方 API 发布工具都不会工作"，官方 API 文档 repo 挂出"no longer supported，不推荐使用" [S7][O]。现状 = CDP/手工，无回归迹象。
- 全站外链 nofollow [S12][I]——SEO 价值走"平台内排名+AI引用"而非权重传递。

**Quora**：
- **变现体系全灭**：Partner Program 2022-09（英语）/2023-03-24（全语言）终结，末次付款 2023-04-03 [S8][O]；2024-11-18 起 Space Subscriptions 和 Ads Revenue Sharing 也停 [S8][C]。含义：Quora 上只剩纯内容玩家，spammer 比例反升，平台对带外链回答的打击只会更严。
- 对我们的含义不变：Quora 价值= SERP 占位 + AI 引用，不是分成渠道。

**Reddit**：
- API 定价落地（2023-07 生效）：$0.24/千次调用；免费档 100 QPM（OAuth）[S5][O]。Apollo 等第三方客户端死亡。
- 养号工具现状：**云端正版 API 做养号自动化 = 账号封号**（开发者社区共识）；anti-detect 浏览器方案（Morelogin/GoLogin）存在但违反 Reddit ToS，且 Reddit 对"多号同指纹"的检测在加强 [S6][I/C]。2025-2026 现实：Reddit 养号只能**人工+半自动（CDP辅助人工节奏）**，全自动化路线基本关闭。
- 2025-09 ChatGPT 突然大幅下调 Reddit/Wikipedia 引用频率（研究期内最大单平台调整）[S2][I]——GEO 红利期进入波动阶段，勿把全部筹码押 Reddit。

### 2.4 GEO 价值排序（AI 引擎引用频率，2025-2026 研究数据）

| 排名 | 平台 | 证据 |
|------|------|------|
| 1 | **Reddit** | 30M 引用研究全引擎第1；Perplexity top 引用约 46.5%；15 域名吃掉 68% 引用中的领跑者（约40%综合份额）[S1][S3] |
| 2 | **YouTube** | 30M 研究第2；社交引用份额 5 个月翻倍 18.9%→39.2%；2026-01 起 Google AI 引用超 Reddit [S1][S4] |
| 3 | **LinkedIn** | 30M 研究第3，B2B 类目突出 [S1] |
| 4 | **Wikipedia/Wiki类** | ChatGPT 最被引单一源（7.8-12%），Claude 几乎不引（0.1%）——引擎差异极大；Fandom 作为可编辑wiki间接蹭此偏好 [S3] |
| 5 | Quora/Medium/StackExchange | 长尾信息查询稳定被引（各研究均在前20被引域）[S2][S3] |

三个结构性结论：
1. **只有 ~15 个域名吃掉全部 AI 引用的 ~68%**，且 DA 80-100 站被引最多 [S1][I]——本矩阵 P0 全部落在这 15 域名生态内，方向正确。
2. **ChatGPT 与 Perplexity 的引用域重合度仅 ~11%** [S3][I]——不要用一个平台打所有引擎；Reddit 打 Perplexity、YouTube 打 Google AI、Wikipedia类打 ChatGPT 需分头布局。
3. **引用格局月度级波动**（Reddit 份额 5 个月 44.2%→20.3%，YouTube 反超）[S4][I]——GEO 策略要按季度复核，矩阵中多平台分散是唯一稳健解。

## 3. 注册邮箱策略建议

### 三种方案对比

| 方案 | 成本 | 隔离度 | 风险点 | 适用平台 |
|------|------|--------|--------|----------|
| **A. Gmail + 别名**（user+pinterest@gmail.com） | 0 | 低 | 平台归一化识破；`+` 被部分注册表单直接拒收 [S10] | 仅宽容平台：Tumblr（实测过）、WordPress.com、Dev.to、Issuu、Vocal、DeviantArt、Buzzfeed |
| **B. 自有域名 catch-all**（Cloudflare Email Routing → 转发进 Gmail） | 域名 $5-10/年，转发免费 [S11][O] | **中高** | 域名成为新关联维度；域名信誉连坐 | **主力方案**：博客/文档/Profile 型平台的批量内容号矩阵；2-3 个域名轮换 |
| **C. 独立真实邮箱**（每号一个真实邮箱：Gmail/Outlook/iCloud） | 时间成本高 | **最高** | 管理复杂度线性增长 | 风控严平台的主号：Reddit、Quora、LinkedIn、Pinterest |

### 按场景推荐

1. **P0 平台主号（Reddit/Quora/LinkedIn/Pinterest）**：方案 C。每项目每平台一号，独立邮箱+独立手机号+注册后 2-4 周纯养号不碰链接。这些平台封号=沉没整个养号周期，隔离成本远低于重建成本。
2. **博客型内容号矩阵（Medium/WP.com/Dev.to/Hashnode/Tumblr/Substack）**：方案 B。自有域名 catch-all（如 `medium01@assets-domain.com`），每平台按项目分前缀。封号重注册成本近零，catch-all 的效率优势压倒隔离劣势。
3. **快速测试/一次性 Profile（About.me/Gravatar/Telegra.ph/Google Sites）**：方案 A 或现有邮箱直接注册，不值得为此建基础设施。
4. **域名卫生**：catch-all 域名**不要用主站域名**（外链资产域名与主站关联=给 Google 画箭头），用专门的 assets 类域名；单域名下挂的号不超过 10-15 个，超了加域名轮换。
5. **收件侧统一**：catch-all 全部转发进一个专用 Gmail（非个人主邮箱），打标签自动分流——注册验证邮件不丢，主邮箱不暴露。
